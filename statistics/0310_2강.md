## 1강 복습

### 개념 체크리스트

| 개념 | 한 줄 요약 |
|------|------------|
| **통계량 vs 모수** | 통계량 = 표본에서 나온 수치, 모수 = 모집단의 (보통 미지의) 수치 |
| **표본오차** | 모수 − 통계량; 표본조사에서 필연적으로 생김 |
| **기술통계 vs 추론통계** | 기술 = 요약·정리, 추론 = 표본으로 모집단 추정·검정 |
| **로우데이터 vs 하이데이터** | 로우 = 자동 수집·대량, 하이 = 직접 조사·높은 관여도 |
| **DIKW** | Data → Information → Knowledge → Wisdom |
| **통계학의 오차 4가지** | 설명, 근거·요인 밝힘, 줄이기, 크기 계산(신뢰구간 등) |

### 표본조사의 위기

- 응답률 저하로 **인원수(표본 수)를 채우기 어려움**.
- 무응답·선택편향으로 **비표본오차** 증가, 표본의 **대표성** 약화.

### 나이팅게일의 로즈 다이어그램

- **플로렌스 나이팅게일**: 크림 전쟁 당시 병원 사망 원인(전투상처 vs 위생·질병)을 **원형(폴라) 차트**로 시각화.
- 통계·시각화로 정책·제도 개선을 이끌어낸 상징적 사례.

**인용** (출처: 《세계를 삼킨 숫자 이야기》 등):  
> 법률과 정부의 부적절성, 정치체계의 무능함, 우리 사회를 이끄는 자들의 답답한 몽매함을 줄곧 보아왔기에, 오직 통계연구만이 정부를 바르게 이끌 수 있다고 생각하게 되었다. 나라를 운영하는 이들은 통계 활용법을 배워야 옳을 것이다.

### 통계학의 활용: 미인도 위작 사건

- **뤼미에르 감정팀**: 미술 작품의 **과학 감정(진위·연대·재료 분석)**.
- **눈·코·입 등 특정 부위**를 **약 1,600개 단층**으로 나누어 픽셀·색·붓질 패턴을 수치화한 뒤 **통계·패턴 분석**으로 진위 검토.
- 통계학이 **미술 감정** 등 여러 분야에서 사용되는 사례.

### 1. 통계학이란

**정의:** 통계학은 **관심의 대상이 되는 집단**으로부터 자료를 수집하고, 이를 **과학적으로 정리·분석**하여 **최적의 의사결정**을 할 수 있도록 **정확한 정보**를 제공하는 방법론을 **체계적으로 연구하는 학문**이다.

#### 현시대 통계: 민간 ≫ 데이터

- 오늘날 **통계·데이터**의 주체는 **민간**(빅테크, 플랫폼, 기업)이 **국가(공공)**보다 훨씬 우위에 있다.
- 데이터 양·실시간성·상업적 활용에서 민간이 앞서며, 1강에서 다룬 “통계의 주체 이동”과 연결된다.

#### 지식·과학·판단과의 관계 (관점 정리)

| 관점 | 한 줄 요약 |
|------|------------|
| **지식과 역사** | 모든 지식은 잘 분석해보면 **역사**라고 할 수 있다. |
| **과학과 수학** | 모든 과학은 추상적으로 보면 **수학**이다. |
| **판단과 통계학** | 모든 판단은, 그 의(意)의 바탕이 되는 **논리적 추론**에서 볼 때 **통계학**이다. |

- **판단 → 통계학**: 의사결정·판단의 논리적 근거는 “데이터·불확실성·추론”으로 이어지며, 그 체계가 곧 통계학이다.

### 2. 통계학의 구분

#### 기술통계학 (Descriptive Statistics)

**정의:** 방대한 자료를 **그래프**, **표**, 또는 **요약 숫자**로 요약하여, 주어진 자료의 **핵심 내용**을 **쉽고 빠르게** 파악할 수 있게 하는 방법. (다루는 것: 평균, 분산, 빈도, 히스토그램 등.)

#### 추측통계학 (Inferential Statistics)

**정의:** 관심 대상인 **전체 집단(모집단)**에서 **일부(표본)**를 추출하고, 표본에서 관측한 **통계량**을 근거로 **모집단의 특성(모수)**을 **추측·검정**하는 방법.

#### 기호·단위·명칭 (그리스어 등)

| 기호 | 읽기 | 의미 |
|------|------|------|
| **μ** | 뮤 (mu) | 모집단 평균 |
| **σ**, **σ²** | 시그마 | 모집단 표준편차·분산 |
| **N** | — | 모집단 크기 |
| **x̄** | 엑스 바 | 표본 평균 |
| **s**, **s²** | — | 표본 표준편차·분산 |
| **n** | — | 표본 크기 |
| **p**, **p̂** | 피, 피 햇 | 모집단 비율, 표본 비율 |

- **모수**: 그리스 문자(μ, σ, p). **통계량**: 로마자·햇 표기(x̄, s, p̂).

#### 모집단과 표본 / 표본추출과 통계적 추론

- **모집단** → **표본** 추출 → 표본에서 **통계량** 계산 → **모수** 추정·검정.
- **표본추출**이 타당해야 **통계적 추론** 결과를 신뢰할 수 있다. (표본추출 방법 ↔ 추론의 타당성)

### 3. 자료의 형태

#### Garbage In, Garbage Out (GIGO)

- 잘못된·품질 나쁜 데이터를 넣으면(**Garbage In**) 결과도 잘못 나온다(**Garbage Out**). 데이터 품질이 분석·통계 결과의 신뢰도를 좌우한다.

#### 데이터 테이블 구조

| 구조 | 동의어 | 의미 |
|------|--------|------|
| **컬럼** | 변수(Variable)·속성(Attribute)·필드(Field) | 한 측정/특성 (나이, 성별, 점수 등) |
| **로우** | 개체(Entity)·레코드(Record) | 한 관측 단위 (한 사람, 한 사건) |

#### 오류값·결측값·특이값 / NA

| 용어 | 설명 |
|------|------|
| **오류값** | 수집·입력 과정에서 생긴 잘못된 값 |
| **결측값** | 값이 비어 있거나 수집되지 않은 경우 |
| **특이값(이상치)** | 나머지와 크게 다른 값 |
| **NA (Not Available)** | 수집 과정에서 오류·무응답·의미 없는 값으로 인해 값이 없거나 쓸 수 없는 경우 |

#### 양적자료 vs 질적자료

| 구분 | 설명 | 예시 |
|------|------|------|
| **양적** | 숫자로 측정·계산 가능 | 나이, 키, 점수, 금액 |
| **질적** | 범주·이름·순서로 구분 | 성별, 지역, 혈액형, 등급 |

**질적 세부:** **명목형**(성별·지역·혈액형) / **순서형**(순위·성적 등급) → 둘을 통틀어 **범주형(Categorical)**. 분석은 **빈도·퍼센트** 위주.

**양적 세부:** **구간형**(상대영점, 덧뺄셈 가능: 온도·국어점수) / **비율형**(절대영점, 곱나눗셈 가능: 몸무게·길이·소요시간). **연속형**(키·몸무게) / **이산형(계수형)**(인원·횟수).

#### 척도별 0의 해석 (예제 2건씩)

| 척도 | 0의 의미 | 예제 |
|------|----------|------|
| **명목** | 코드일 뿐, “없음” 아님 | 성별(0/1), 지역코드 |
| **서열** | 순서만, 절대 0 아님 | 만족도 1~5, 순위 |
| **등간** | 상대영점(기준점) | 섭씨 온도, 시험점수 |
| **비율** | 절대영점(진짜 없음) | 몸무게(kg), 소요시간(초) |

#### 독립변수(X) vs 종속변수(Y) / 데이터 유형과 분석 방법

- **X**: 독립변수·설명변수 (범주형 또는 연속형)
- **Y**: 종속변수·반응변수 (범주형 또는 연속형)
- **(Y, X)** 조합에 따른 분석: **범주–범주** → 교차분석·χ² 검정 / **범주–연속** → 로지스틱·판별분석 / **연속–범주** → t검정·ANOVA / **연속–연속** → 상관·회귀분석

#### 정제된 데이터

- 오류·결측·중복을 보정·정리한 데이터. 국가통계포털 통계표는 대부분 정제·가공된 형태, 공공데이터포털은 원시·반가공·정제가 혼재.

#### 공공·통계 포털 비교

| 구분 | 국가통계포털 (KOSIS) | 공공데이터포털 (data.go.kr) |
|------|----------------------|-----------------------------|
| **성격** | 공식 국가통계 집계·공개 | 공공데이터 전반 개방 |
| **데이터** | 통계표·지표 위주(정제됨) | 통계표+원시·API 혼재 |
| **강점** | 신뢰도·정제도·일관성 | 다양성·세부·API·실시간 |
| **단점** | 범위·세분화 제한 | 품질·표준화·검색 난이도 |

**추가 포털:** 보건의료 통합포털 / 한국은행 경제통계시스템(ECOS) / 문화통계포털 / ICT 통계포털 / 방송통신통계포털 / 미디어통계포털 — 분야별 정제·집계 통계 제공.

### 4. 엑셀 사용법

#### 입력 (Input)

- 셀에 값·수식·함수를 입력해 데이터와 계산을 관리한다.
- 한 번 입력한 값은 복사·채우기로 재사용할 수 있어, 반복 작업을 줄이는 것이 엑셀 사용의 기본이다.

#### 복사: 엑셀의 뛰어난 지점

- **복사·채우기**: 같은 수식·서식을 여러 셀에 빠르게 적용할 수 있다.
- **상대 참조**: 복사 시 셀 주소가 자동으로 바뀌어(예: A1 → A2, B1) 패턴 반복에 유리하다.
- **절대 참조**: `$`를 붙이면 복사해도 주소가 고정되어, 기준 셀(상수·기준값)을 일정하게 쓸 수 있다.

#### 달러 표시($)와 절대 참조

| 표기 | 의미 | 복사 시 동작 |
|------|------|----------------|
| **A1** | 상대 참조 | 행·열 모두 이동 (상대적으로 변함) |
| **$A$1** | 절대 참조 | 행·열 모두 고정 |
| **$A1** | 열만 절대 | 열은 A로 고정, 행만 변함 |
| **A$1** | 행만 절대 | 행은 1로 고정, 열만 변함 |

- **절대 참조**는 “고정할 부분”에 **달러 표시($)**를 붙이는 것이다.  
  예: 단가가 `$B$2`에 있을 때, 여러 행에서 `=수량*$B$2`로 쓰면 복사해도 항상 B2를 참조한다.

### 5. 엑셀 데이터 분석 기능(분석 도구)

#### 분석 도구 켜는 법

- **분석 도구(Data Analysis / Analysis ToolPak)**는 **추가 기능(Add-in)**이라 기본 비활성화일 수 있음.
- **켜는 방법:** **파일** → **옵션** → **추가 기능** → 하단 **이동** → **분석 도구** 체크 → **확인**.  
  (Excel 버전에 따라 **데이터** 탭에 **데이터 분석**이 나타남.)

#### 분석 도구에서 쓰는 통계 분석

| 메뉴(대표명) | 내용 | 비고 |
|--------------|------|------|
| **분산분석: 일원배치법** | One-way ANOVA. 한 요인(그룹 변수)에 따른 집단 평균 차이 검정. | 그룹 1개, 연속형 반응변수 |
| **분산분석: 반복 있는 이원배치법** | Two-way ANOVA with replication. 두 요인 + 각 셀에 반복 관측. | 요인 2개, 반복 측정 있음 |
| **분산분석: 반복 없는 이원배치법** | Two-way ANOVA without replication. 두 요인, 셀당 관측 1개. | 요인 2개, 반복 없음 |
| **상관분석** | Correlation. 두 연속변수 간 선형 관계의 방향·강도(상관계수). | 연속–연속 |
| **공분산 분석** | Covariance. 두 변수의 공분산(함께 변하는 정도). | 연속–연속 |
| **기타** | t-검정, 회귀분석, 히스토그램, 기술통계 등 | 분석 도구 목록에서 선택 |

- **일원배치** = 요인 1개(예: A, B, C 세 그룹). **이원배치** = 요인 2개(예: 성별×연령대). **반복 있음** = 각 조합에 관측 여러 개, **반복 없음** = 조합당 1개.
