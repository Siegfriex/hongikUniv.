# Statistics (통계)

## 과목 목표
- 데이터로 보는 통계학: 모집단·표본, 기술/추론 통계, 오차, 빅데이터·ML과의 관계를 정리한다.
- 하루치 강의는 `YYYYMMDD.md` 형식으로 누적·보강한다.

## 난이도
- 기초 개념부터 시작해, 데이터사이언스·딥러닝과의 연결까지 다룬다.

## 예제 스타일
- 정의·정리·예제·참고(출처) 블록을 사용. 수식은 코드블록 또는 인라인. 표는 markdown 테이블.
- 웹 그라운딩(학술·공식·백과) 참고를 최소 1개 이상 포함한다.

## 선행 과목 / 연관
- (선행 과목이 정해지면 링크 추가)
- 데이터사이언스·ML 과목과 연계 가능.

## 사용 언어
- 한글 중심, 용어는 한·영 병기.

## 파일 네이밍 예시
- 하루치 강의 파일 예: `statistics/20260304.md`

## 대표 키워드 / 토픽 리스트
- 확률, 분포, 추정, 검정, 회귀, 상관, 모수·통계량, 표본오차, 기술/추론 통계, 빅데이터, DIKW.

## 하루치 강의 1회 목표 분량
- 하루치 1회 목표: 개념 2–3개 + 간단 예제 또는 정리 1–2개.

## 브랜치
- `DS_statistics` 또는 `DS_-statistics`
