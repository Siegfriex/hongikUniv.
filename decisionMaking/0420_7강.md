## 2. 쌍대문제 쓰기(표준 규칙)

**원문제(primal)** 가 다음과 같을 때(교재 표기에 맞출 것):

- **max 문제** + \(\le\) 제약 → 쌍대는 **min** + \(\ge\) 제약, 목적계수·우변 **자리 바꿈**, 변수 **부호 제약** 쌍대 규칙 적용.
- **min 문제** + \(\ge\) 제약(식단형) → 쌍대는 **max** + \(\le\) 제약.

| Primal (대표) | Dual 대응 |
|---------------|-----------|
| 제약 \(i\) 가 **등식** | 쌍대 변수 \(y_i\) **부호 제약 없음**(교재 정의에 따름) |
| 제약이 \(\le\) (max primal) | \(y_i \ge 0\) |
| 제약이 \(\ge\) (min primal) | \(y_i \ge 0\) (쌍대가 max이면 \(\le\) 제약으로 전개) |
| 결정변수 \(x_j \ge 0\) | 쌍대 제약 \(j\) : **\(\ge\)** (max primal 기준 흔한 쌍) |

**시험 팁:** 행렬로 \(\max\; c^\top x\) s.t. \(Ax \le b,\; x\ge 0\) 이면 쌍대는 \(\min\; b^\top y\) s.t. \(A^\top y \ge c,\; y\ge 0\) 형태로 외운 뒤, **식단(min)** 은 **부호 뒤집기**로 재확인한다.

## 3. 식단 예제: primal ↔ dual 해석

`0413_6강.md` **§10.5** 와 동일 맥락:

- **Primal (식단):** 영양소 요구 **\(\ge\)** 를 만족하도록 **식품량**을 최소비용으로.
- **Dual:** “영양소 **단위당 가격(잠재가격)**”을 정해, 식품 가격을 **넘지 않게** 하면서 **영양소 ‘가치’ 합**을 **최대**.

**해석 한 줄:** 쌍대 최적값 = 원 최적값(강쌍대 성립 시)이며, **\(y^*\)** 는 “그 영양소 제약을 **1단위 완화**할 때 비용이 얼마나 줄어드는가”에 대응하는 **한계(그림자가격)** 해석을 갖는다.

## 4. 약쌍대·강쌍대·4가지 경우

- **약쌍대(weak):** primal **가능해** 목적값 \(\le\) dual **가능해** 목적값 (max primal 기준; 부호는 max/min 정의에 맞게 조정).
- **강쌍대(strong):** 둘 다 **가능해가 존재**하면 **최적값 동일**.

**4가지(기억용):**

1. 둘 다 최적 존재 → 최적값 일치  
2. primal **무한대**(unbounded) ↔ dual **비가능**  
3. primal **비가능** ↔ dual **무한대**  
4. 둘 다 비가능(이론상 가능)

## 5. 상보여유(complementary slackness)

**직관:** “제약이 **느슨**하면(여유 있으면) 그 제약의 **쌍대 변수는 0**”; “**원 변수가 양수**면 쌍대 해당 제약은 **딱 맞게** 활성”.

시험에서는 **최적해 검증**·**KKT형 서술**에 쓴다. (교재 §4.8 표기를 최우선.)

## 6. 민감도: 그림자가격·감소비용·허용범위

`0413_6강.md` **§10.7** 요약과 동일 축:

| 개념 | 타블로에서 읽는 위치(교재·슬라이드 기준) | 의미 |
|------|----------------------------------------|------|
| **감소비용 / reduced cost** | 최적 타블로 **목적행**, 원 변수 열 | 기저 밖 변수를 1단위 늘릴 때 목적 **변화율** |
| **그림자가격 / shadow price** | 최적 타블로 목적행의 **슬랙(여유) 변수** 계수 | 해당 제약 RHS 1단위 증가 시 **최적 목적값 변화**(해석은 max/min에 따라 부호 주의) |
| **허용증가·허용감소** | 기저 유지 가정 하 **계수·RHS 변동 범위** | 최적 **기저**가 바뀌기 전까지 선형 근사가 유효 |

**주의:** \(\min\) 문제와 \(\max\) 문제에서 **목적행 부호·해석**이 뒤집히므로, **항상 지금 푸는 문제가 max인지 min인지** 먼저 선언한다.

- **가변 셀·목표셀·제약**을 LP로 두고 푼 뒤 **민감도 보고서** 생성.
- 보고서의 **그림자 가격·허용 증가/감소·감소비용** 열이 위 §6과 **같은 정보**임을 대조한다.
