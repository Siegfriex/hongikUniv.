## 슬라이드 7 — GRAPH SHOWING CONSTRAINTS: D ≥ 0 AND W ≥ 0

- **제목:** GRAPH SHOWING CONSTRAINTS: **D ≥ 0 AND W ≥ 0**
- **문제 정리 (좌측):**
  - **목적함수:** Maximize \(P = \$300D + \$500W\)
  - **제약:** subject to \(D \leq 4\), \(2W \leq 12\), \(3D + 2W \leq 18\)
  - **비음 조건 (강조):** **D ≥ 0, W ≥ 0**
- **그래프 (우측):** 제1사분면(D ≥ 0, W ≥ 0)만 표시한 초기 단계 — 보라색 영역. 아직 \(D\leq4\), \(2W\leq12\), \(3D+2W\leq18\) 을 반영해 가능해 영역을 좁히기 전 상태.

## 슬라이드 8 — NONNEGATIVE SOLUTIONS PERMITTED BY D ≤ 4

- **제목:** NONNEGATIVE SOLUTIONS PERMITTED BY **D ≤ 4**
- **문제 (좌측):** Maximize \(P = \$300D + \$500W\), subject to **D ≤ 4**(강조), \(2W \leq 12\), \(3D + 2W \leq 18\), and \(D \geq 0, W \geq 0\).
- **그래프 (우측):** 비음 + **D ≤ 4** 반영. D축·W축과 **수직선 D=4** 로 둘러싸인 제1사분면 내 **세로 띠(직사각형)** — D가 0~4, W는 0 이상. → 제약을 **하나씩** 추가해 가능 영역을 좁히는 첫 단계.

## 슬라이드 9 — NONNEGATIVE SOLUTIONS PERMITTED BY 2W ≤ 12

- **제목:** NONNEGATIVE SOLUTIONS PERMITTED BY **2W ≤ 12**
- **문제 (좌측):** 동일 목적함수·제약, **2W ≤ 12**(강조) → \(W \leq 6\).
- **그래프 (우측):** 비음 + **2W ≤ 12** 반영. **수평선 W=6** 아래, 제1사분면 — W가 0~6, D는 0 이상. → 두 번째 제약만 켠 상태의 가능 영역.

## 슬라이드 10 — NONNEGATIVE SOLUTIONS PERMITTED BY 3D + 2W ≤ 18

- **제목:** NONNEGATIVE SOLUTIONS PERMITTED BY **3D + 2W ≤ 18**
- **문제 (좌측):** **3D + 2W ≤ 18**(강조), 나머지 동일.
- **그래프 (우측):** 직선 **3D + 2W = 18** 아래 + 비음 → **삼각형 형태** 가능 영역. 경계 위 점: (0,9), (1,7.5), (2,6), (3,4.5), (4,3), (5,1.5), (6,0). → 세 번째 제약만 켠 상태.

## 슬라이드 11 — CHANGING RIGHT-HAND SIDE CREATES PARALLEL CONSTRAINT BOUNDARY LINES

- **제목:** CHANGING RIGHT-HAND SIDE CREATES **PARALLEL CONSTRAINT BOUNDARY LINES**
- **내용:** 제약 \(3D + 2W \leq \text{상수}\) 에서 **우변(RHS)만** 바꾸면 경계선이 **평행이동**. 기울기는 동일.
- **그래프:** \(3D + 2W = 12\), \(3D + 2W = 18\), \(3D + 2W = 24\) 세 직선이 **평행**. 상수가 커질수록 직선이 오른쪽·위로 이동 → 자원(가용시간) 증감에 따른 **민감도** 직관.

## 슬라이드 12 — GRAPH OF FEASIBLE REGION

- **제목:** **GRAPH OF FEASIBLE REGION**
- **핵심 질문:** Feasible Region? Feasible Solution? Infeasible Solution?
- **문제 (좌측):** Maximize \(P = \$300D + \$500W\), subject to \(D \leq 4\), \(2W \leq 12\), \(3D + 2W \leq 18\), and \(D \geq 0, W \geq 0\) (전체 제약 한꺼번에).
- **그래프 (우측):** 세 제약 + 비음의 **교집합** = **가능해 영역(Feasible region)** — 오렌지색 다각형. 꼭짓점: (0,0), (4,0), (4,3), (2,6), (0,6). D=4 수직선, W=6 수평선, \(3D+2W=18\) 대각선으로 둘러싸임.

## 슬라이드 13 — OBJECTIVE FUNCTION (P = 1,500)

- **제목:** **OBJECTIVE FUNCTION (P = 1,500)**
- **그래프:** 가능해 영역 위에 **등이익선** \(P = 1{,}500 = 300D + 500W\) (검은 직선). (0,3)과 (5,0)을 지남. 이 직선이 가능해 영역과 **교차**하는 구간이 존재 → P=1500인 실행가능해가 있음. P를 더 키우면 직선이 위로 이동하다 **마지막으로 닿는 꼭짓점**에서 최적해.

## 슬라이드 14 — SUMMARY OF THE GRAPHICAL METHOD

- **제목:** **SUMMARY OF THE GRAPHICAL METHOD**
- **5단계 요약:**
  1. **각 제약의 경계선**을 그린다. 원점(또는 경계 위 아닌 한 점)으로 **어느 쪽이 허용 영역인지** 판단.
  2. **가능해 영역**을 찾는다 — 모든 제약을 동시에 만족하는 영역.
  3. **목적함수 직선 하나의 기울기**를 정한다. 같은 목적함수 값의 직선들은 모두 **같은 기울기**.
  4. 그 기울기의 **직선자**를 목적함수 개선 방향으로 가능해 영역 위를 움직여, **가능해 영역을 떠나기 직전**에 멈춘다. 그 직선이 **최적 목적함수선**.
  5. 최적 목적함수선 위의 **실행가능한 점**이 **최적해**.

# 중간점검 및 진행 — 슬라이드 간 관계와 추론

## 1. 제약 단계별 구축 (슬라이드 7 → 8 → 9 → 10)

| 단계 | 추가 제약 | 그래프상 가능 영역 |
|------|-----------|---------------------|
| 7 | \(D \geq 0, W \geq 0\) | 제1사분면 전체 |
| 8 | **D ≤ 4** | 제1사분면 ∩ D≤4 → 세로 띠(직사각형) |
| 9 | **2W ≤ 12** | 제1사분면 ∩ W≤6 → 수평 띠 (독립적으로 그렸을 때) |
| 10 | **3D + 2W ≤ 18** | 제1사분면 ∩ 반평면(직선 아래) → 삼각형 (독립 시) |

**추론:** 8·9·10은 **각 제약 하나씩**만 켜서 “이 부등식이 허용하는 영역”을 보여줌. **12**에서 세 제약+비음을 **동시에** 적용해 **교집합**을 취하면 최종 **가능해 영역(다각형)** 이 나옴.

## 2. RHS와 평행 경계선 (슬라이드 11)

- 제약 \(3D + 2W \leq b\) 에서 **b만** 바꾸면 경계선이 **평행이동**.
- **18 → 24** 이면 자원 증가 → 가능해 영역 확대. **18 → 12** 이면 축소. → 나중에 **섀도우가격·민감도**로 이어지는 직관.

## 3. 가능해 영역·용어 정리 (슬라이드 12)

- **Feasible region:** 모든 제약을 동시에 만족하는 \((D,W)\) 집합 — 그래프상 **오렌지 다각형**.
- **Feasible solution:** 그 영역 안의 한 점 (예: (2,3), (4,3)).
- **Infeasible solution:** 어떤 제약이라도 어기는 점 (예: (4,6)은 \(3D+2W\leq18\) 위반).
- **꼭짓점:** (0,0), (4,0), (4,3), (2,6), (0,6) — 최적해는 이 중 하나(또는 인접 두 꼭짓점 사이).

## 4. 목적함수선과 최적해 (슬라이드 13 → 14)

- **P = 1,500** 등이익선이 가능해 영역을 **관통** → P=1500인 실행가능해 존재. P를 **늘리면** 직선이 위로 이동.
- **그래프 해법 요약(14):** 기울기 고정 → 직선자를 “개선 방향”으로 밀어 **가능해 영역을 벗어나기 직전**에 멈춘 점 = 최적. 선형이므로 그 직선이 **꼭짓점**을 지남 → **꼭짓점에서 최적해**.
- **Wyndor 최적해 검산:** 꼭짓점별 \(P = 300D + 500W\) 계산 → (2,6)에서 \(P = 600 + 3{,}000 = 3{,}600\) (최대). ∴ **최적해 (D*, W*) = (2, 6), P* = 3,600**.

# Part B. Wyndor Glass Co. — LP 모형 수립

## 1. LP 모형 설계 세 가지 질문 (슬라이드 4)

- **결정변수:** 무엇을 정하는가? → 두 신제품의 **주당 생산률** (production rates).
- **제약:** 어떤 제한이 있는가? → 두 제품이 각 공장에서 쓰는 **주당 생산시간**이 공장 **가용시간을 초과할 수 없음**.
- **목적함수:** 성과 지표는? → 두 제품의 **주당 총 이익** (Total profit per week).

## 2. 제품믹스 예제 (슬라이드 2~3, 5)

- **상황:** 위 슬라이드 2~3. 문(Doors)·창문(Windows) 주당 생산량 조합으로 총 이익 최대화.
- **결정변수:** \(D\) = 문 주당 생산량, \(W\) = 창문 주당 생산량 (슬라이드 5 표기; \(x_1,x_2\) 와 동일)
- **목적함수:** \(\max\; P = 300D + 500W\) (단위: $)
- **제약식:**
  - Plant 1: \(D \leq 4\)
  - Plant 2: \(2W \leq 12\) → \(W \leq 6\)
  - Plant 3: \(3D + 2W \leq 18\)
  - 비음: \(D \geq 0,\; W \geq 0\)

## 3. LP 정리 (대수모형, 슬라이드 5)

\[
\begin{aligned}
\text{Max} \quad & P = 300D + 500W \\
\text{s.t.} \quad & D \leq 4 \\
& 2W \leq 12 \\
& 3D + 2W \leq 18 \\
& D, W \geq 0
\end{aligned}
\]

## 4. 그래프 해법 적용 (슬라이드 6~14)

- **축:** D(문 주당 생산량) 가로, W(창문 주당 생산량) 세로. **Origin (0,0)** 기준 (슬라이드 6).
- **제약 단계별:** 7(비음만) → 8(D≤4) → 9(2W≤12) → 10(3D+2W≤18) 각각 허용 영역을 그린 뒤, **12**에서 전부의 **교집합** = **가능해 영역(Feasible region)** — 꼭짓점 (0,0), (4,0), (4,3), (2,6), (0,6).
- **RHS 변화:** 11 — \(3D+2W\) 의 우변만 바꾸면 경계선이 **평행이동** (민감도 직관).
- **목적함수선:** 13 — 등이익선 \(P = 1{,}500\) 등이 가능해 영역과 교차; P를 키우며 직선을 위로 이동.
- **5단계 요약(14):** (1) 각 제약 경계선 그리기 (2) 가능해 영역 찾기 (3) 목적함수선 기울기 (4) 기울기 유지한 채 개선 방향으로 직선 이동, 가능해 영역을 벗어나기 직전 정지 → 최적 목적함수선 (5) 그 위의 실행가능한 점 = **최적해**.
- **최적해:** 꼭짓점별 P 계산 시 **(2, 6)** 에서 \(P^* = 300(2)+500(6) = 3{,}600\) 최대. ∴ **(D*, W*) = (2, 6), P* = 3,600**.

# 수리모델로 변환 — THE PROFIT & GAMBIT CO. (모델링 과정 집중)

**목표:** 데이터(슬라이드 29) → 결정변수·제약·목적함수 설계(30) → 대수모형(31) 순으로 **모델링 과정**을 따라가며, Wyndor(최대화)와의 **차이점**을 명시한다.

## 1. 결정변수 명시 (TV, PM)

- **의사결정 대상:** “TV에 몇 단위, 인쇄매체에 몇 단위 광고를 할 것인가?”
- **결정변수 (슬라이드 30·31):**
  - **\(TV\)** = the number of units of advertising on **television** (TV 광고 단위 수)
  - **\(PM\)** = the number of units of advertising in the **print media** (인쇄매체 광고 단위 수)
- **비음:** \(TV \geq 0\), \(PM \geq 0\) (광고 단위는 0 이상).

## 2. 제약조건 — 데이터에서 제약식으로 (슬라이드 29 → 31)

**원칙:** “Minimum required increase”를 **이상(≥)** 으로 만족해야 하므로, 제약은 모두 **≥** 형태.

| 제품 | TV 1단위 기여 | PM 1단위 기여 | 최소 요구 증가 | 제약식 (판매증가 ≥ 최소요구) |
|------|----------------|----------------|----------------|------------------------------|
| Stain remover    | 0  | 1 | 3  | \(0\cdot TV + 1\cdot PM \geq 3\) → **\(PM \geq 3\)** |
| Liquid detergent | 3  | 2 | 18 | \(3\cdot TV + 2\cdot PM \geq 18\) → **\(3TV + 2PM \geq 18\)** |
| Powder detergent | -1 | 4 | 4  | \((-1)\cdot TV + 4\cdot PM \geq 4\) → **\(-TV + 4PM \geq 4\)** |

- **해석:** 각 제품별 “(TV 기여)×TV + (PM 기여)×PM ≥ 최소 요구” 로 **세 개의 선형 제약식**이 나옴. Powder는 TV 1단위당 -1%이므로 계수가 음수.

## 3. 목적함수 — 최소화 (슬라이드 29 단위비용, 30·31)

- **성과 지표 (30):** Total cost from advertising → **최소화(Minimize)**.
- **단위 비용 (29):** TV $1M/단위, Print $2M/단위 → \(Cost = 1\cdot TV + 2\cdot PM\) (백만 달러 단위).
- **목적함수:** \(\min\; Cost = TV + 2PM\).

## 4. Wyndor와의 차이 · 정리

| 구분 | Wyndor (제품믹스) | Profit & Gambit (광고) |
|------|-------------------|-------------------------|
| **결정변수** | \(D\), \(W\) (생산량) | **\(TV\), \(PM\)** (광고 단위) |
| **목적** | **최대화** (이익) | **최소화** (비용) |
| **제약 방향** | 자원 **한도** → \(\leq\) | 목표 **최소 달성** → **\(\geq\)** |
| **제약 개수** | 3 (공장) + 비음 | 3 (제품별 판매목표) + 비음 |

- 그래프 해법에서도 **최소화**는 등비용선을 **아래/왼쪽**으로 밀어 “가능해 영역에 **처음** 닿는” 꼭짓점이 최적해.

## 5. Profit & Gambit LP — 최종 수리모형 (슬라이드 31)

\[
\begin{aligned}
\text{Min} \quad & Cost = TV + 2PM \quad \text{(millions of dollars)} \\
\text{s.t.} \quad & PM \geq 3 \\
& 3TV + 2PM \geq 18 \\
& -TV + 4PM \geq 4 \\
& TV, PM \geq 0
\end{aligned}
\]

- **모델링 순서 요약:** (1) 결정변수 **TV, PM** 정의 → (2) 표에서 제품별 기여·최소요구로 **제약식 3개** 도출 → (3) 단위비용으로 **목적함수(최소화)** 결정 → (4) 비음 조건 추가.

## 실습 예제 — 표 데이터 버전 (그래프로 그려 손으로 풀기)

**표: Increase in Sales per Unit of Advertising** (제시된 표 기준)

| Product          | TV  | Print Media | Minimum Required Increase |
|------------------|-----|-------------|---------------------------|
| Stain remover    | 0%  | **1.5%**    | 3%  |
| Liquid detergent | 3%  | **4%**      | 18% |
| Powder detergent | -1% | **2%**      | 4%  |
| **Unit cost**    | **$1 million** | **$2 million** | — |

이 표 기준으로 수리모형을 세우면 (비율을 그대로 % 단위로 쓰면):

- **결정변수:** \(TV\), \(PM\) (광고 단위 수)
- **목적함수:** \(\min\; Cost = TV + 2PM\) (백만 달러)
- **제약:**
  - Stain: \(0\cdot TV + 1.5\cdot PM \geq 3\) → **\(PM \geq 2\)**
  - Liquid: \(3\cdot TV + 4\cdot PM \geq 18\)
  - Powder: \((-1)\cdot TV + 2\cdot PM \geq 4\) → **\(-TV + 2PM \geq 4\)**
  - 비음: \(TV \geq 0\), \(PM \geq 0\)

**가능해 영역:** 위 세 부등식 + 비음의 교집합. 그래프로 그리면 \(PM \geq 2\) 반평면, \(3TV+4PM \geq 18\) 직선 위쪽, \(-TV+2PM \geq 4\) 직선 위쪽, 제1사분면의 교집합.

**꼭짓점 후보:**
- \(3TV+4PM=18\) 과 \(-TV+2PM=4\) 의 교점: \(-TV+2PM=4\) → \(TV = 2PM-4\). 대입하면 \(3(2PM-4)+4PM=18\) → \(10PM=30\) → \(PM=3\), \(TV=2\). → **(2, 3)**. 세 제약·비음 모두 만족.
- \(TV=0\) 과 \(3TV+4PM=18\) 의 교점: **(0, 4.5)**. \(-0+2\times 4.5=9 \geq 4\), \(PM \geq 2\) 만족.

**목적함수 값 비교:**
- (2, 3): \(Cost = 2 + 2\times 3 = \mathbf{8}\) (백만 달러)
- (0, 4.5): \(Cost = 0 + 2\times 4.5 = 9\) (백만 달러)

**최적해 (최소 비용):**
- **\(TV^* = 2\), \(PM^* = 3\)**
- **최소 총 비용 = $8 million**  
  (TV 2단위 × $1M + Print 3단위 × $2M = $2M + $6M = $8M)

*표에서 Print Media 열이 1%, 2%, 4%인 버전(슬라이드 31)이면 제약식이 \(PM \geq 3\), \(3TV+2PM \geq 18\), \(-TV+4PM \geq 4\) 가 되며, 최적해는 그에 맞춰 다시 계산하면 된다.*

## 단계별 왜 / 어떻게 — 수리모형과 엑셀의 대응

### Step #1: Data Cells — 왜, 어떻게

- **왜:** LP의 **파라미터**(단위이익, 단위당 사용량, 가용량)는 **고정값**이므로 한곳에 모아 두면 수식이 셀 참조만으로 유지되고, 나중에 숫자만 바꿔도 모형이 갱신된다.
- **어떻게:**  
  - **C4:D4** = 목적함수 계수 \((c_D, c_W) = (300, 500)\).  
  - **C7:D9** = 제약식 **LHS 계수** \(a_{i,D}, a_{i,W}\) (공장 \(i\)에서 문·창문 단위당 사용 시간).  
  - **G7:G9** = 제약식 **RHS** \(b_1=4, b_2=12, b_3=18\).  
- **행·열 일관 사용:** 제품(Doors/Windows)은 열(C/D), 공장(Plant 1~3)은 행(7~9)으로 통일하면 SUMPRODUCT로 “같은 열끼리 곱해 합”이 자연스럽게 한 번에 계산된다.

### Step #2: Changing Cells — 왜, 어떻게

- **왜:** Solver가 **바꿀 수 있는 것**은 “문·창문 각각 몇 단위 생산할지”뿐이다. 이 두 값을 **한 셀씩** 두면 Solver의 “By Changing Variable Cells”에 C12:D12만 지정하면 된다.
- **어떻게:**  
  - **C12** = \(D\) (문 생산량), **D12** = \(W\) (창문 생산량).  
  - 초기값 0은 “아무것도 안 만드는 해”로, 제약을 만족하며 목적함수 값이 0임을 바로 확인할 수 있다.  
  - 노란색+테두리로 표시하면 **결정변수**와 데이터/계산 셀을 구분하기 쉽다.

### Step #3: Objective Cell — 왜 그렇게 설정하고, 함수로 어떻게 진행하는지

- **목적함수 (수리모형):** \(\max\; P = 300D + 500W\).  
- **왜 이 식인가:** 이익 = (문 단위이익)×(문 생산량) + (창문 단위이익)×(창문 생산량). 단위이익은 **데이터 셀** C4, D4에 있으므로, **변수 셀** C12, D12와 곱해 합치면 된다.  
- **엑셀에서 어떻게:**  
  - **G12**에 총이익을 넣는다.  
  - **수식:** `=SUMPRODUCT(C4:D4, C12:D12)`.  
  - SUMPRODUCT(범위1, 범위2) = 같은 위치 곱의 합 → C4*C12 + D4*D12 = 300*D + 500*W.  
  - Solver는 이 **한 셀(G12)** 을 “Max”로 지정해 최대화한다.  
- **정리:** 목적함수는 “계수(데이터 셀) × 결정변수(Changing Cells)”를 **한 셀**에 SUMPRODUCT로 넣고, 그 셀을 목적 셀(Set Objective)로 두면 된다.

### Step #4: Constraints — 왜, 어떻게 (제약식과 함수)

- **제약 (수리모형):**  
  - Plant 1: \(1\cdot D + 0\cdot W \leq 4\)  
  - Plant 2: \(0\cdot D + 2\cdot W \leq 12\)  
  - Plant 3: \(3\cdot D + 2\cdot W \leq 18\)  
- **왜 “사용량” 셀을 두는가:** 제약은 “(사용량) ≤ (가용량)” 형태. **사용량**은 공장별로 (해당 행의 계수)×(C12,D12)의 합이므로, **행마다 한 셀(E7,E8,E9)** 에 계산해 두고, 그 셀을 가용량(G7,G8,G9)과 비교하면 된다.  
- **엑셀에서 어떻게:**  
  - **E7** (Plant 1 사용시간): `=SUMPRODUCT(C7:D7, C12:D12)` → \(1\cdot C12 + 0\cdot D12\).  
  - **E8:** `=SUMPRODUCT(C8:D8, C12:D12)` → \(0\cdot C12 + 2\cdot D12\).  
  - **E9:** `=SUMPRODUCT(C9:D9, C12:D12)` → \(3\cdot C12 + 2\cdot D12\).  
  - 제약 정의: **E7 ≤ G7**, **E8 ≤ G8**, **E9 ≤ G9** (세 칸 연속: 사용량, <=, 가용량).  
- **정리:** 제약식 LHS = “해당 행의 기술계수(C7:D7 등)와 결정변수(C12:D12)의 SUMPRODUCT”. RHS는 이미 데이터 셀(G7:G9)에 있으므로, Solver에 “E7:E9 <= G7:G9”로 넣으면 된다.

### 수식 한눈에 — 변수·목적함수·제약의 대응

| 구분 | 수리모형 | 엑셀 셀 | 엑셀 수식 |
|------|----------|---------|-----------|
| 결정변수 | \(D, W\) | C12, D12 | (직접 입력 또는 Solver가 변경) |
| 목적함수 | \(P = 300D + 500W\) | G12 | `=SUMPRODUCT(C4:D4, C12:D12)` |
| 제약 LHS (Plant 1) | \(1D + 0W\) | E7 | `=SUMPRODUCT(C7:D7, C12:D12)` |
| 제약 LHS (Plant 2) | \(0D + 2W\) | E8 | `=SUMPRODUCT(C8:D8, C12:D12)` |
| 제약 LHS (Plant 3) | \(3D + 2W\) | E9 | `=SUMPRODUCT(C9:D9, C12:D12)` |
| 제약 조건 | 사용량 ≤ 가용량 | E7≤G7, E8≤G8, E9≤G9 | — |

### 시행해(Trial Solution) — 함수가 어떻게 진행되는지

- **시행해:** C12=4 (Doors), D12=3 (Windows)를 넣었을 때.
- **E7** = SUMPRODUCT(C7:D7, C12:D12) = 1×4 + 0×3 = **4** → G7(4)와 비교 → 4 ≤ 4 (binding).  
- **E8** = 0×4 + 2×3 = **6** → G8(12)와 비교 → 6 ≤ 12 (slack 6).  
- **E9** = 3×4 + 2×3 = **18** → G9(18)와 비교 → 18 ≤ 18 (binding).  
- **G12** = SUMPRODUCT(C4:D4, C12:D12) = 300×4 + 500×3 = **2,700**.  
- **의미:** 결정변수만 바꿔 넣으면, **목적 셀**과 **제약 LHS 셀**이 수식에 의해 자동 계산되고, Solver는 이 구조를 이용해 “G12 최대화, E7:E9 ≤ G7:G9, C12:D12 ≥ 0”인 최적해를 찾는다.
