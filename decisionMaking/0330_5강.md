## 1. LP 정의와 일반형 — 도출·인과·선형/비선형

슬라이드: **Linear Programming (선형 계획)** · **일반적인 선형계획문제**  
핵심은 정의 암기가 아니라, **실제 의사결정 상황에서 목적함수·변수·제약이 “왜 그렇게 도출되는지”** 인과를 잡는 것이다.

---

### 1.1 모형화의 세 층 — 무엇이 먼저 도출되는가

현장 문제는 보통 **한 줄 질문**(“비용을 줄여라”, “이익을 늘려라”)으로 주어진다. LP로 옮길 때는 **역할이 다른 세 덩어리**로 나눈다. 순서는 고정은 아니지만, 사고의 흐름은 보통 아래와 같다.

| 층 | 수학 대응 | 인과(왜 여기에 붙는가) |
|----|-----------|------------------------|
| **① 의사결정변수** \(x_1,\ldots,x_n\) | 미지수 | **경영자(모형 사용자)가 수치를 정할 수 있는 레버**다. 광고비, 생산량, 운송량, 0-1 배정 등 “조절 가능한 양”이 변수로 옮겨진다. **정하지 못하는 것**(이미 정해진 수요, 공장 용량, 법규)은 변수가 아니라 **제약의 계수나 우변**으로 들어간다. |
| **② 목적함수** \(z = \sum_j c_j x_j\) | 최대 또는 최소 | **성과를 숫자 하나로 요약한 척도**다. “무엇을 최적화하는가”는 **조직의 목표**에서 온다. 이익·비용·노출·거리 등을 **단위당 기여 \(c_j\)** 와 **활동 수준 \(x_j\)** 의 **가중합**으로 쓸 수 있을 때, 그 가중합이 목적함수로 **도출**된다. |
| **③ 제약식** | \(\sum_j a_{ij}x_j \;\{\le,=,\ge\}\; b_i\) | **불가피한 관계**다. 자원 한도, 수요·공급 일치, 품질 하한, 계약상 납품량 등은 “변수를 마음대로 키우면 어긋나는 현실”이 **등식·부등식**으로 **도출**된다. \(a_{ij}\)는 **단위 활동이 자원·요구를 얼마나 소비하는지**, \(b_i\)는 **한도·요구량**이다. |

**한 줄 요약:** 변수는 **내가 움직이는 손잡이**, 목적은 **그 손잡이를 어디로 당길지에 대한 나침반**, 제약은 **손잡이가 돌아갈 수 있는 울타리**다. 세 가지가 같은 \(x\)에 대해 말해야 모형이 닫힌다.

---

### 1.2 “Linear”의 의미 — 목적함수와 제약이 왜 “선형식”이어야 하는가

슬라이드 정의:

- **Linear:** **목적함수**와 **제약식**이 모두 **선형식**(의사결정변수에 대해 1차식).
- **Programming** = **Planning** = **계획** — 컴퓨터 프로그램 문법이 아니라 **자원·활동을 어떻게 배분할지 계획**한다는 뜻이다.

**선형**이 요구되는 이유는 단순하다. LP 해법(심플렉스 등)과 **전역 최적성**(볼록 다면체 위에서 꼭짓점 최적)은 **목적·제약이 모두 \(x\)에 대해 선형**일 때 체계가 닫히기 때문이다.  
반대로 **변수의 곱**, **\(x^2\)**, **로그·지수**, **min/max 안에 변수** 등이 들어가면 **같은 “계획” 문제라도 LP가 아니라** 비선형·정수계획 등 다른 도구가 필요하다.

---

### 1.3 선형 vs 비선형(슬라이드 그래프) — 인과·한계효과

슬라이드는 **가로: 광고비 \(X\)**, **세로: 판매대수 \(Y\)** 로 **의사결정(투입)** 과 **성과(산출)** 의 관계를 그린다.

**(a) 선형 관계**  
직선: 한 점 \((X^*,Y^*)\) 근처에서 \(\Delta x\) 를 줄였을 때 \(\Delta y/\Delta x\) 가 **구간 어디서나 동일**(기울기 일정).  
**모형화 함의:** “광고 1단위를 늘릴 때마다 판매가 **항상 같은 비율**로 늘어난다”는 가정이면, \(Y\) 를 \(X\) 의 선형함수로 두는 것이 자연스럽고, **목적·제약에 \(X\)가 선형으로만 들어가면** LP 구조와 맞는다.

**(b) 비선형 관계(S자 곡선 등)**  
같은 \(\Delta x\) 라도 위치에 따라 \(\Delta y\) 가 달라진다(초반·중반·포화 구간 **한계효과 불일치**).  
**모형화 함의:** 성과가 이런 곡선이면 **한 번에 LP로 “판매 \(Y\)” 자체를 목적에 넣기** 어렵다. 현실에서는 **구간 선형화**, **근사**, 또는 **비선형 계획법**으로 넘어간다.

즉, **선형/비선형은 그림의 모양 문제가 아니라 “한계효과가 일정한가”** 라는 **인과 가정** 문제다. CH.3에서 다루는 **형식화·응용**은 전제적으로 **그 한계효과를 계수 \(c_j, a_{ij}\) 로 고정**할 수 있는 상황을 다룬다.

---

### 1.4 일반형 — 기호가 각각 무엇을 “도출”했는지

슬라이드의 **일반적인 선형계획문제**는 다음과 같이 쓴다.

**의사결정변수:** \(x_1,\ldots,x_n\)

\[
\min \;\text{또는}\; \max \; z = c_1 x_1 + c_2 x_2 + \cdots + c_n x_n
\]

\[
\text{subject to} \quad
\begin{cases}
a_{11}x_1 + \cdots + a_{1n}x_n \;\{\le,=,\ge\}\; b_1 \\
\quad\vdots \\
a_{m1}x_1 + \cdots + a_{mn}x_n \;\{\le,=,\ge\}\; b_m
\end{cases}
\qquad
x_1,\ldots,x_n \ge 0 \quad \text{(비음조건)}
\]

| 기호 | 이름 | 도출 맥락(인과) |
|------|------|-----------------|
| \(x_j\) | 의사결정변수 | \(j\) 번째 **활동 수준**(생산량, 운송량, 배정 여부를 연속으로 풀면 0~1 등). |
| \(c_j\) | 목적계수 | 활동 **1단위**가 목적 \(z\) 에 주는 기여(단위이익·단위비용·단위노출 등). **“왜 이게 \(z\) 에 곱해지나”** → 단위당 효과를 데이터로 잡았기 때문. |
| \(a_{ij}\) | 기술·자원계수 | 활동 \(j\) 를 1 늘릴 때 제약 \(i\) (자원·수요·품질)에 가하는 **소비·기여**. |
| \(b_i\) | 우변(RHS) | 그 제약에서 허용되거나 요구되는 **총량**(가용 자원, 최소 만족량 등). |
| \(\le,=,\geq\) | 제약 방향 | **“넘지 말아야 할 자원”** vs **“정확히 맞춰야 할 수요”** vs **“최소한 만족해야 할 기준”** 의 차이. |

**비음 조건** \(x_j \ge 0\) 은 “물리적으로 음의 생산·음의 운송은 없다” 같은 **현실 규칙**에서 도출되는 경우가 많다. (필요하면 자유변수로 두는 모형도 있으나 CH.3 기본 실습은 비음이 기본.)

---

### 1.5 정리 — 5강 이후 예제를 읽을 때 체크할 질문

각 사례(Decora, Big M, Sellmore, W사, …)에서 다음만 스스로에게 물으면 **도출**이 선명해진다.

1. **변수:** “여기서 내가 숫자로 정하는 것은 정확히 무엇인가?”  
2. **목적:** “그 숫자들이 바뀔 때, 회사가 좋아하는 방향을 **하나의 수**로 어떻게 잴 것인가? 계수는 어디서 왔는가?”  
3. **제약:** “그 숫자를 마음대로 키우면 **현실과 충돌하는 관계**는 무엇인가? 그게 왜 \(a_{ij}\) 와 \(b_i\) 로 쓰이는가?”

이 세 질문에 답이 선형식으로 쓰이면 **LP**이고, 한계효과가 구간마다 달라져 곡선이 필요하면 **이 장의 표준 LP만으로는 부족**할 수 있다.

## 2. 제조·절단 문제 — Decora Associates (60인치 봉)

### 2.1 스토리

- **Decora**는 욕실 액세서리(수건걸이·샤워커튼봉 등)를 생산한다. **스테인리스 봉** 길이는 **12, 18, 24, 40, 60** 인치 등이 필요하다.
- **원자재:** 외부에서 **60인치 봉**을 구매한 뒤 **절단**해 사용한다.
- **예:** 60인치 1개로 **40인치 + 18인치**를 만들면 **2인치 폐기(waste)**. **12인치 5개**면 **폐기 0**.
- **다음 기간 수요**
  - 12″: **25**개
  - 18″: **52**개
  - 24″: **45**개
  - 40″: **30**개
  - 60″: **12**개

**질문:** 수요를 만족시키기 위해 구매해야 할 **60인치 봉의 최소 개수**는?

---

### 2.2 사고의 출발 — "무엇을 변수로 놓을 것인가"

§1.5의 세 질문을 그대로 적용한다.

1. **변수(내가 숫자로 정하는 것):** 60인치 봉을 "어떤 방식으로 잘라 쓸지" 그리고 "그 방식을 **몇 번** 쓸지"를 정해야 한다. 이 "방식"이 바로 **절단 패턴(cutting pattern)** 이다.
2. **목적(나침반):** 구매하는 60인치 봉 **총 개수를 최소화** — 봉 1개가 비용 1이니, 패턴별 사용 횟수의 **단순 합**이 목적함수.
3. **제약(울타리):** 각 길이별로 절단되어 나오는 개수의 합이 **수요 이상**이어야 한다.

따라서 **핵심은 "패턴을 빠짐없이 열거하는 것"** 이다. 패턴이 곧 변수가 되고, 패턴 안의 각 길이별 개수가 제약의 계수 \(a_{ij}\) 가 된다.

### 2.4 결정변수 정의

\(p_k\) = **패턴 \(k\) 를 사용하는 60인치 봉의 개수** (\(k = 1,\ldots,26\), \(p_k \ge 0\) 정수 또는 연속)

**왜 패턴이 변수인가?**
개별 봉마다 "몇 인치를 몇 개 자를지"를 따로 정하면 변수가 폭발한다. 대신 "**자르는 방식(패턴)은 유한 개**이고, 같은 패턴으로 자르는 봉은 묶는다"는 발상이 **절단 재고(cutting stock)** 문제의 핵심이다. 패턴 한 줄이 §1.4의 기술계수 행 \(a_{ij}\) 에 그대로 대응한다.

---

### 2.5 목적함수 — 왜 "봉 총 개수"인가

60인치 봉을 외부에서 구매하는 비용을 줄이고 싶다. 봉 1개당 구매가가 동일하므로, **사용 봉 수 = 비용**에 비례한다.

\[
\min\; Z = \sum_{k=1}^{26} p_k
= p_1 + p_2 + \cdots + p_{26}
\]

목적계수 \(c_k = 1\) (모든 \(k\)). 이것은 §1.4의 \(c_j\) 가 "단위당 기여"인 것과 같다 — 여기선 "패턴 1회 사용 = 봉 1개 소비 = 비용 1단위".

---

### 2.6 제약식 — 왜 이렇게 도출되는가

각 길이의 **수요를 충족**해야 한다. 패턴 \(k\) 를 \(p_k\) 번 쓰면, 그로부터 나오는 12″ 개수는 \((\text{P}k\text{의 } n_{12}) \times p_k\) 이다. 모든 패턴에서 나온 12″ 합이 **수요 이상**이어야 한다.

\(a_{ik}\) = 패턴 \(k\) 에서 길이 \(i\) 가 몇 개 나오는지 (위 표의 각 셀 값).

**12″ 수요:**

\[
0 p_1 + 0 p_2 + 1 p_3 + 0 p_4 + 1 p_5 + 0 p_6 + 0 p_7 + 1 p_8 + 0 p_9 + 3 p_{10} + 2 p_{11} + 1 p_{12} + 0 p_{13} + 0 p_{14} + 2 p_{15} + 1 p_{16} + 0 p_{17} + 3 p_{18} + 2 p_{19} + 1 p_{20} + 0 p_{21} + 5 p_{22} + 4 p_{23} + 3 p_{24} + 2 p_{25} + 1 p_{26} \;\ge\; 25
\]

**18″ 수요:**

\[
0 p_1 + 1 p_2 + 0 p_3 + 0 p_4 + 0 p_5 + 0 p_6 + 2 p_7 + 1 p_8 + 1 p_9 + 0 p_{10} + 0 p_{11} + 0 p_{12} + 0 p_{13} + 3 p_{14} + 2 p_{15} + 2 p_{16} + 2 p_{17} + 1 p_{18} + 1 p_{19} + 1 p_{20} + 1 p_{21} + 0 p_{22} + 0 p_{23} + 0 p_{24} + 0 p_{25} + 0 p_{26} \;\ge\; 52
\]

**24″ 수요:**

\[
0 p_1 + 0 p_2 + 0 p_3 + 0 p_4 + 2 p_5 + 2 p_6 + 1 p_7 + 1 p_8 + 1 p_9 + 1 p_{10} + 1 p_{11} + 1 p_{12} + 1 p_{13} + 0 p_{14} + 0 p_{15} + 0 p_{16} + 0 p_{17} + 0 p_{18} + 0 p_{19} + 0 p_{20} + 0 p_{21} + 0 p_{22} + 0 p_{23} + 0 p_{24} + 0 p_{25} + 0 p_{26} \;\ge\; 45
\]

**40″ 수요:**

\[
0 p_1 + 1 p_2 + 1 p_3 + 1 p_4 + 0 p_5 + \cdots + 0 p_{26} \;\ge\; 30
\]

(P2, P3, P4만 \(n_{40}=1\), 나머지는 0)

**60″ 수요:**

\[
1 p_1 + 0 p_2 + \cdots + 0 p_{26} \;\ge\; 12
\]

(P1만 \(n_{60}=1\))

**비음 조건:**

\[
p_k \ge 0 \quad (k=1,\ldots,26)
\]

---

### 2.7 완전한 수리모형 (요약)

\[
\boxed{
\begin{aligned}
\min\quad & Z = \sum_{k=1}^{26} p_k \\[6pt]
\text{s.t.}\quad
& \sum_{k=1}^{26} a_{12,k}\, p_k \;\ge\; 25 \quad\text{(12″ 수요)} \\
& \sum_{k=1}^{26} a_{18,k}\, p_k \;\ge\; 52 \quad\text{(18″ 수요)} \\
& \sum_{k=1}^{26} a_{24,k}\, p_k \;\ge\; 45 \quad\text{(24″ 수요)} \\
& \sum_{k=1}^{26} a_{40,k}\, p_k \;\ge\; 30 \quad\text{(40″ 수요)} \\
& \sum_{k=1}^{26} a_{60,k}\, p_k \;\ge\; 12 \quad\text{(60″ 수요)} \\
& p_k \ge 0,\; p_k \in \mathbb{Z} \quad (k=1,\ldots,26)
\end{aligned}
}
\]

여기서 \(a_{i,k}\) 는 §2.3 패턴 표의 해당 길이 열 값이다.

---

### 2.8 인과 되짚기 — §1.5 체크리스트 대응

| §1.5 질문 | Decora에서의 답 |
|-----------|----------------|
| **변수:** 내가 숫자로 정하는 것은? | "어떤 패턴을 몇 번 쓸지" → \(p_k\) |
| **목적:** 바뀔 때 좋은 방향을 하나의 수로? | 구매 봉 수 = \(\sum p_k\), 적을수록 좋음 → \(\min\) |
| **제약:** 마음대로 키우면 충돌하는 현실? | 길이별 수요 충족. 패턴은 물리적으로 60″ 안에 들어야 하지만 이는 이미 패턴 열거 시 반영됨 |
| **왜 \(a_{ij}\)?** | 패턴에서 나오는 각 길이 개수가 그대로 기술계수 |
| **왜 ≥?** | "최소한 이만큼은 잘라야" → 초과 절단은 폐기물이지만 허용(여분 재고) |

---

### 2.9 스프레드시트 포인트 (슬라이드 엑셀)

- 슬라이드 수식 **`C12 = $F$3 − SUMPRODUCT(B7:B11, C7:C11)`** 은 각 패턴 열에서 **60 − (절단 길이 합) = 잔량(waste)** 을 계산한다.
- 엑셀에서는 **패턴을 열(column)** 로, **길이를 행(row)** 으로 두고, 아래에 **사용 횟수(\(p_k\))** 행을 결정변수로 놓는다.
- **수요 충족:** 각 길이 행에서 `SUMPRODUCT(패턴계수행, 사용횟수행) ≥ 수요` 제약.
- **목적 셀:** `SUM(사용횟수행)` → **Solver → Simplex LP(또는 정수 필요 시 Integer) → Min**.

> **실무 팁:** 26개 패턴 전부를 열로 넣어도 되지만, 효율 패턴(★) 11개만으로도 최적해를 얻을 수 있다. 슬라이드의 컴팩트 시트는 이 효율 패턴만 쓴 것으로 보인다.

## 3. 운송 문제 — The Big M Company

### 3.1 스토리

- **Big M Company** — 중장비(터렛 선반, turret lathe) 생산. 공장 **2곳**(F1, F2), 고객 **3곳**(C1, C2, C3).
- 선반은 **대당 단위로 개별 선적**한다.
- **Fixed-requirements:** 각 고객 주문량을 **정확히** 맞춰야 하고(부족도 초과도 불가), 각 공장의 생산량도 **전량 출하**해야 한다.

| | 생산량 |
|---|:---:|
| Factory 1 | **12** lathes |
| Factory 2 | **15** lathes |
| **합계** | **27** |

| | 주문량 |
|---|:---:|
| Customer 1 | **10** lathes |
| Customer 2 | **8** lathes |
| Customer 3 | **9** lathes |
| **합계** | **27** |

> **공급 합(27) = 수요 합(27)** — **균형(balanced) 운송 문제**. 이 균형이 성립하기에 모든 제약이 **등호(=)** 로 쓰인다.

**질문:** 총 운송비용을 최소화하려면 공장별·고객별로 **몇 대씩** 보내야 하는가?

---

### 3.2 사고의 출발 — §1.5 세 질문 적용

| §1.5 질문 | Big M에서의 답 |
|-----------|---------------|
| **변수:** 내가 숫자로 정하는 것은? | "공장 \(i\) → 고객 \(j\)" 경로별 **선적 대수** \(S_{ij}\). 총 \(2 \times 3 = 6\)개 |
| **목적:** 하나의 수로 어떻게? | 경로마다 **대당 운송비** × **대수**를 합산 → \(\min\) |
| **제약:** 마음대로 정하면 충돌하는 현실? | ① 각 공장에서 나가는 합 = 생산량(남기면 안 됨) ② 각 고객이 받는 합 = 주문량(부족해도 안 됨) |

**Decora 절단 문제와의 비교:**
- Decora: **패턴**이라는 추상적 단위를 변수로 둠 → 변수의 개수 = 패턴 수(26개).
- Big M: **경로**(공장→고객)가 변수 → 물리적으로 명확한 6개. **패턴 열거 없이** 구조가 바로 보인다.

---

### 3.3 네트워크 구조 (Distribution Network)

```
         $700/대            C1 (10대 필요)
F1 ──────────────────────►
(12대) ──$900──────────────► C2 (8대 필요)
       ──$800──────────────► C3 (9대 필요)

         $800/대            C1
F2 ──────────────────────►
(15대) ──$900──────────────► C2
       ──$700──────────────► C3
```

이 그림에서 **간선(edge)** 하나가 결정변수 하나에 대응한다. "네트워크 위의 유량(flow)"을 정하는 문제라서 **운송 문제(transportation problem)** 라고 부른다.

---

### 3.4 단위당 운송비 (\$/대) — 목적계수 \(c_{ij}\)의 출처

| From \\ To | C1 | C2 | C3 |
|------------|:---:|:---:|:---:|
| **Factory 1** | 700 | 900 | 800 |
| **Factory 2** | 800 | 900 | 700 |

이 표의 각 셀이 §1.4의 **\(c_j\)** 에 해당한다 — "선반 1대를 이 경로로 보낼 때 드는 비용"이 **단위당 기여(여기선 비용)** 다. 거리·물류비·관세 등에서 도출된 숫자이며, **변수와 무관한 상수**이므로 LP 계수로 쓸 수 있다.

---

### 3.5 결정변수 정의

\[
S_{ij} = \text{공장 } i \text{에서 고객 } j \text{로 보내는 선반 대수} \quad (i \in \{1,2\},\; j \in \{1,2,3\})
\]

구체적으로 6개: \(S_{11}, S_{12}, S_{13}, S_{21}, S_{22}, S_{23}\).

**왜 이것이 변수인가?** — 관리자가 **직접 결정할 수 있는 양**이 "어디에서 어디로 몇 대 보낼지"이기 때문. 생산량(12, 15)과 주문량(10, 8, 9)은 **이미 정해진 상수**(파라미터)이므로 변수가 아니라 **제약의 우변(RHS) \(b_i\)** 로 들어간다.

---

### 3.6 목적함수 — 도출 과정

**성과 척도:** 총 운송비용을 최소화.

선반 1대를 경로 \((i,j)\) 로 보내면 비용 \(c_{ij}\) 가 발생한다. \(S_{ij}\) 대를 보내면 \(c_{ij} \times S_{ij}\). **모든 경로의 합**이 총비용이다.

\[
\min\; Z = 700 S_{11} + 900 S_{12} + 800 S_{13} + 800 S_{21} + 900 S_{22} + 700 S_{23}
\]

**왜 선형인가?** — 대당 운송비가 **수량과 무관하게 일정**(한계비용 불변). 10대를 보내든 1대를 보내든 대당 \$700. §1.3의 "한계효과 일정 → 선형"이 그대로 적용된다.

---

### 3.7 제약식 — 왜 "등호(=)"인가

#### (1) 공장 제약 — "생산량을 **전량 출하**해야 한다"

공장에서 만든 선반은 창고에 남기는 게 아니라 **모두 고객에게 보내야** 한다(재고 보관 비용이 크거나 계약상 전량 납품).

\[
S_{11} + S_{12} + S_{13} = 12 \quad \text{(F1: 만든 12대를 빠짐없이 출하)}
\]
\[
S_{21} + S_{22} + S_{23} = 15 \quad \text{(F2: 만든 15대를 빠짐없이 출하)}
\]

**왜 ≤ 가 아니라 = 인가?** — 남기면 재고 비용이 들거나, 문제 설정상 "생산한 것은 반드시 보낸다(fixed requirements)"이기 때문. Decora에서는 "수요 **이상** 잘라도 됨(≥)"이었지만, 여기서는 **남는 것도, 모자라는 것도 불허** → **등호**.

#### (2) 고객 제약 — "주문량을 **정확히** 받아야 한다"

\[
S_{11} + S_{21} = 10 \quad \text{(C1: 두 공장에서 받는 합 = 주문 10대)}
\]
\[
S_{12} + S_{22} = 8 \quad \text{(C2: 주문 8대)}
\]
\[
S_{13} + S_{23} = 9 \quad \text{(C3: 주문 9대)}
\]

**왜 등호?** — 고객 주문이 **고정(fixed)** 이다. 덜 보내면 계약 위반, 더 보내면 고객이 받지 않는다.

#### (3) 비음 조건

\[
S_{ij} \ge 0 \quad (i=1,2;\; j=1,2,3)
\]

음수 운송("고객이 공장에 되돌려 보낸다")은 물리적으로 불가능.

---

### 3.8 완전한 수리모형

\[
\boxed{
\begin{aligned}
\min\quad & Z = 700 S_{11} + 900 S_{12} + 800 S_{13} + 800 S_{21} + 900 S_{22} + 700 S_{23} \\[6pt]
\text{s.t.}\quad
& S_{11} + S_{12} + S_{13} = 12 \quad\text{(F1 출고)} \\
& S_{21} + S_{22} + S_{23} = 15 \quad\text{(F2 출고)} \\
& S_{11} + S_{21} = 10 \quad\text{(C1 수요)} \\
& S_{12} + S_{22} = 8 \quad\text{(C2 수요)} \\
& S_{13} + S_{23} = 9 \quad\text{(C3 수요)} \\
& S_{ij} \ge 0
\end{aligned}
}
\]

> **제약 5개, 변수 6개.** 그런데 공급 합(12+15=27) = 수요 합(10+8+9=27)이므로 제약 중 하나는 **다른 4개에서 자동 도출(종속)** 된다. 따라서 **독립 제약은 4개**, 자유도는 6−4=2. 이것이 균형 운송 문제의 구조적 특징이다.

---

### 3.9 인과 되짚기 — Decora와의 대조

| 비교 항목 | Decora (절단) | Big M (운송) |
|-----------|--------------|-------------|
| 변수의 정체 | 패턴 사용 횟수 \(p_k\) | 경로별 운송량 \(S_{ij}\) |
| 변수 개수 | 패턴 수(26개) — **열거**로 결정 | 공장수 × 고객수(6개) — **구조**로 결정 |
| 목적계수 \(c\) | 1 (봉 1개 = 비용 1단위) | 대당 운송비 (경로마다 다름) |
| 제약 부호 | **≥** (수요 이상 OK) | **=** (정확히 일치, fixed) |
| 제약 계수 \(a_{ij}\) | 패턴에서 나오는 각 길이 개수 | 0 또는 1 (경로가 해당 노드에 연결되는지) |
| 핵심 구조 | **패턴 열거** | **네트워크 유량 보존** |

---

### 3.10 스프레드시트 — 슬라이드 레이아웃과 수식

슬라이드의 엑셀 구조(행 1–15 기준):

| 영역 | 셀 범위 | 내용 |
|------|---------|------|
| 단가 블록 | `C5:E6` | 경로별 \$/대 (상수) |
| **결정변수** | `C11:E12` | \(S_{ij}\) — **Solver가 바꿀 셀** |
| 공장 출고합 | `F11` = `SUM(C11:E11)`, `F12` = `SUM(C12:E12)` | **= Output(G열)** 제약 |
| 고객 입고합 | `C13` = `SUM(C11:C12)`, … | **= Order Size(행 15)** 제약 |
| **목적 셀** | `H15` = `SUMPRODUCT(C5:E6, C11:E12)` | **총비용 → Min** |

**슬라이드 최적해:**

| | C1 | C2 | C3 | 출고합 | = | Output |
|---|:---:|:---:|:---:|:---:|---|:---:|
| F1 | **10** | **2** | **0** | 12 | = | 12 |
| F2 | **0** | **6** | **9** | 15 | = | 15 |
| 입고합 | 10 | 8 | 9 | | | |
| = | = | = | = | | | |
| Order | 10 | 8 | 9 | | **총비용** | **\$20,500** |

> **해석:** F1은 가까운 C1에 전량(10대)을 보내고 남은 2대를 C2로. F2는 싼 경로(C3 \$700)로 9대를 보내고 나머지 6대를 C2로. C2는 두 공장에서 나눠 받는다. F1→C3, F2→C1 경로는 비싸서 0.

## 4. 할당 문제 — Sellmore Company

### 4.1 스토리

- **Sellmore Company** — 연례 영업 회의를 위해 **임시직 4명**을 고용: **Ann, Ian, Joan, Sean**.
- **업무 4가지:** 워드프로세싱(Word), 컴퓨터 그래픽(Graphics), 회의 자료 패킷(Packets), 사전·현장 등록(Registrations).
- 각 사람마다 **업무별 소요 시간**이 다르고, **시급**도 다르다.

**질문:** 사람–업무를 **1:1 배정**해서 **총 비용을 최소화**하라.

---

### 4.2 사고의 출발 — §1.5 세 질문 적용

| §1.5 질문 | Sellmore에서의 답 |
|-----------|-------------------|
| **변수:** 내가 숫자로 정하는 것은? | "사람 \(i\)가 업무 \(j\)를 맡는가/안 맡는가" → **0-1 변수** \(A_{ij}\) |
| **목적:** 하나의 수로 어떻게? | 배정된 조합의 **비용(시간 × 시급) 합** → \(\min\) |
| **제약:** 마음대로 정하면 충돌하는 현실? | ① 한 사람이 두 업무를 겸임 못 함 ② 한 업무에 두 사람이 붙으면 안 됨 |

**Big M 운송 문제와의 비교:**
- 운송: 경로별 **연속적 수량** → 변수 값이 0~15 사이 실수 가능.
- 할당: 배정 여부만 → 변수 값이 **0 또는 1** (이진). 하지만 LP 완화(0-1 제약 없이 풀기)로도 자연스럽게 정수해가 나오는 것이 할당 문제의 구조적 특징이다.

---

### 4.3 할당 문제의 5가지 가정 (슬라이드)

할당 문제(assignment problem)로 정식화하려면 아래를 만족해야 한다:

1. **담당자 수 = 업무 수** (4 = 4) — 정방행렬.
2. 각 사람은 **정확히 하나**의 업무만 수행.
3. 각 업무는 **정확히 한 사람**에게만 배정.
4. 모든 **(사람, 업무) 조합**에 대해 **비용이 정해져** 있음.
5. 목적: 모든 배정의 **총 비용 최소화**.

> **가정 1~3이 제약을 결정하고, 가정 4가 목적계수를 결정한다.** 가정 2와 3에서 "정확히 하나" → **등호(=)** 제약이 도출된다(Big M과 같은 fixed-requirement 구조).

---

### 4.4 데이터 — 시간에서 비용으로의 도출

#### (a) 소요 시간(Hours)

| | Word | Graphics | Packets | Registrations | 시급 (\$/hr) |
|---|:---:|:---:|:---:|:---:|:---:|
| **Ann** | 35 | 41 | 27 | 40 | **14** |
| **Ian** | 47 | 45 | 32 | 51 | **12** |
| **Joan** | 39 | 56 | 36 | 43 | **13** |
| **Sean** | 32 | 51 | 25 | 46 | **15** |

#### (b) 비용(\$) = 시간 × 시급 — **목적계수 \(c_{ij}\)의 도출**

| | T1(Word) | T2(Graphics) | T3(Packets) | T4(Registrations) |
|---|:---:|:---:|:---:|:---:|
| **P1(Ann)** | 35×14 = **490** | 41×14 = **574** | 27×14 = **378** | 40×14 = **560** |
| **P2(Ian)** | 47×12 = **564** | 45×12 = **540** | 32×12 = **384** | 51×12 = **612** |
| **P3(Joan)** | 39×13 = **507** | 56×13 = **728** | 36×13 = **468** | 43×13 = **559** |
| **P4(Sean)** | 32×15 = **480** | 51×15 = **765** | 25×15 = **375** | 46×15 = **690** |

**인과:** 원래 데이터는 **시간**과 **시급** 두 장이다. 그런데 LP 목적함수에 넣으려면 **하나의 수**(비용)로 합쳐야 한다. "시간 × 시급 = 비용"으로 변환한 결과가 위 행렬이고, 이것이 목적계수 \(c_{ij}\)가 된다.

---

### 4.5 결정변수 정의

\[
A_{ij} = \begin{cases} 1 & \text{사람 } i \text{가 업무 } j \text{를 맡으면} \\ 0 & \text{아니면} \end{cases}
\quad (i \in \{P1,P2,P3,P4\},\; j \in \{T1,T2,T3,T4\})
\]

총 \(4 \times 4 = 16\)개 변수.

**왜 0-1인가?** — "Ann이 Word를 **0.5만큼** 맡는다"는 현실적으로 불가능하다. 한 사람이 한 업무를 **통째로** 맡거나 안 맡거나 — 이것이 **이진 의사결정**이다. 하지만 할당 문제의 수학적 특성상, **LP 완화(0 ≤ A ≤ 1)로 풀어도 꼭짓점 해가 0-1로 나온다** (제약 행렬이 완전 단일모듈러).

---

### 4.6 목적함수 — 도출

비용 행렬 \(c_{ij}\) 와 배정 변수 \(A_{ij}\) 의 **원소별 곱의 합**:

\[
\min\; Z = 490 A_{11} + 574 A_{12} + 378 A_{13} + 560 A_{14}
\]
\[
\quad + 564 A_{21} + 540 A_{22} + 384 A_{23} + 612 A_{24}
\]
\[
\quad + 507 A_{31} + 728 A_{32} + 468 A_{33} + 559 A_{34}
\]
\[
\quad + 480 A_{41} + 765 A_{42} + 375 A_{43} + 690 A_{44}
\]

**왜 선형인가?** — \(A_{ij}\) 가 0 또는 1이므로, \(c_{ij} \times A_{ij}\) 는 "맡으면 \(c_{ij}\), 안 맡으면 0". 합산하면 **배정된 조합의 비용만 더해진다**. 변수끼리의 곱은 없다.

---

### 4.7 제약식 — 왜 "행 합 = 1, 열 합 = 1"인가

#### (1) 사람 제약 (행 합 = 1) — "각 사람은 정확히 하나의 업무"

\[
A_{11} + A_{12} + A_{13} + A_{14} = 1 \quad \text{(Ann)}
\]
\[
A_{21} + A_{22} + A_{23} + A_{24} = 1 \quad \text{(Ian)}
\]
\[
A_{31} + A_{32} + A_{33} + A_{34} = 1 \quad \text{(Joan)}
\]
\[
A_{41} + A_{42} + A_{43} + A_{44} = 1 \quad \text{(Sean)}
\]

**인과:** 임시직이 두 업무를 겸하면 시간이 부족하거나 품질이 떨어진다. 문제 조건에서 "**정확히 하나**"로 고정했으므로 **등호**.

#### (2) 업무 제약 (열 합 = 1) — "각 업무는 정확히 한 사람이 담당"

\[
A_{11} + A_{21} + A_{31} + A_{41} = 1 \quad \text{(Word)}
\]
\[
A_{12} + A_{22} + A_{32} + A_{42} = 1 \quad \text{(Graphics)}
\]
\[
A_{13} + A_{23} + A_{33} + A_{43} = 1 \quad \text{(Packets)}
\]
\[
A_{14} + A_{24} + A_{34} + A_{44} = 1 \quad \text{(Registrations)}
\]

**인과:** 한 업무에 두 사람이 붙으면 중복·혼선이 생긴다. 한 사람만 전담.

#### (3) 비음 조건

\[
A_{ij} \ge 0 \quad (i=1,\ldots,4;\; j=1,\ldots,4)
\]

(0-1 조건은 LP 완화 시 생략 가능. 자연스럽게 0 또는 1이 나온다.)

---

### 4.8 완전한 수리모형

\[
\boxed{
\begin{aligned}
\min\quad & Z = \sum_{i=1}^{4}\sum_{j=1}^{4} c_{ij}\, A_{ij} \\[6pt]
\text{s.t.}\quad
& \sum_{j=1}^{4} A_{ij} = 1 \quad (i=1,\ldots,4) \quad\text{— 사람당 업무 1개} \\[3pt]
& \sum_{i=1}^{4} A_{ij} = 1 \quad (j=1,\ldots,4) \quad\text{— 업무당 사람 1명} \\[3pt]
& A_{ij} \ge 0
\end{aligned}
}
\]

> **제약 8개, 변수 16개.** Big M과 마찬가지로 행 합들의 총합 = 열 합들의 총합 = 4이므로 **독립 제약은 7개**.

---

### 4.9 인과 되짚기 — 세 문제 대조

| 비교 항목 | Decora (절단) | Big M (운송) | Sellmore (할당) |
|-----------|:---:|:---:|:---:|
| 변수의 정체 | 패턴 사용 횟수 | 경로별 운송량 | 사람-업무 배정 0/1 |
| 변수 성격 | 정수(연속 완화 가능) | 연속(≥0) | 0-1(LP 완화로 정수 보장) |
| 목적 | 봉 수 min | 운송비 min | 인건비 min |
| 제약 부호 | **≥** (초과 OK) | **=** (정확히) | **=** (정확히) |
| 기술계수 \(a_{ij}\) | 패턴별 길이 개수(0~5) | 0 또는 1 | 0 또는 1 |
| "정확히" 이유 | 남는 건 폐기 → 허용 | 재고 불가·계약 | 겸임 불가·전담 |
| 핵심 사전 작업 | 패턴 열거 | 네트워크 그리기 | 비용 행렬 계산 |

---

### 4.10 스프레드시트 — 슬라이드 레이아웃과 수식

슬라이드 엑셀 구조(행 1–30 기준):

| 영역 | 셀 범위 | 내용 |
|------|---------|------|
| 소요 시간 | `D5:G8` | 사람 × 업무 시간 (Hours) |
| 시급 | `H5:H8` | \$/hr |
| **비용 행렬** | `D15:G18` | = 시간 × 시급 (상수) |
| **결정변수** | `D24:G27` | \(A_{ij}\) — 0 또는 1, **Solver 변경 셀** |
| 사람별 합(행) | `H24` = `SUM(D24:G24)` | **= 1** (Supply 열) |
| 업무별 합(열) | `D28` = `SUM(D24:D27)` | **= 1** (Demand 행) |
| **목적 셀** | `J30` = `SUMPRODUCT(D15:G18, D24:G27)` | **총비용 → Min** |

**슬라이드 최적해:**

| | Word | Graphics | Packets | Registrations | 합 | = |
|---|:---:|:---:|:---:|:---:|:---:|---|
| **Ann** | 0 | 0 | **1** | 0 | 1 | = 1 |
| **Ian** | 0 | **1** | 0 | 0 | 1 | = 1 |
| **Joan** | 0 | 0 | 0 | **1** | 1 | = 1 |
| **Sean** | **1** | 0 | 0 | 0 | 1 | = 1 |
| 합 | 1 | 1 | 1 | 1 | | **총비용** |
| = | = | = | = | = | | **\$1,957** |

**해석:** Ann→Packets(\$378), Ian→Graphics(\$540), Joan→Registrations(\$559), Sean→Word(\$480). 합 = 378+540+559+480 = **\$1,957**.

> **왜 이 배정이 최적인가?** — 각 사람의 "가장 싼 업무"만 고르면 충돌(Ann과 Sean 모두 Packets가 최저)이 생긴다. LP(또는 헝가리안 알고리즘)는 **전체 조합**을 고려해 충돌 없이 총비용을 최소화하는 배정을 찾는다.

## 5. 혼합 생산 계획 — W사 포도젤리·포도주스

### 5.1 스토리

- **W사** — 포도젤리와 포도주스를 생산·판매하는 회사.
- 포도 경작자로부터 포도를 수확해 **1등급(최하품)~10등급(최상품)** 으로 분류·구매한다.
- **현재 W사가 보유한 포도:**

| 등급 | 보유량 |
|:---:|:---:|
| **9등급** (상급) | 4만 kg |
| **6등급** (중급) | 6만 kg |
| **4등급** (하급) | 6만 kg |

- **포도젤리:** 평균 등급 **5 이상** 요구, 1 kg 판매 시 이익 **2,700원**.
- **포도주스:** 평균 등급 **7 이상** 요구, 1 kg 판매 시 이익 **3,500원**.

**질문 두 가지:**
1. 최대 이익을 창출하기 위한 **포도젤리·포도주스의 생산량**은?
2. 생산할 때 **등급별 포도를 어떻게 혼합**해야 하는가?

---

### 5.2 사고의 출발 — 이 문제의 구조를 잡기

#### 왜 "제품별 생산량"만으로는 변수가 부족한가

얼핏 보면 "젤리 생산량, 주스 생산량" 2개면 될 것 같다. 하지만 **품질(등급) 제약** 때문에 그게 안 된다.

- 같은 1만 kg 젤리라도 **9등급만 써서 만든 젤리**와 **4등급만 써서 만든 젤리**는 **평균 등급이 다르다**.
- "젤리를 얼마나 만들지" 뿐 아니라 "그 젤리에 **어떤 등급 포도를 얼마씩 넣을지**"까지 정해야 품질 제약을 검증할 수 있다.

따라서 변수는 **제품 × 등급** 조합으로 쪼개야 한다.

---

### 5.3 결정변수 — 제품 × 등급 매트릭스

슬라이드의 변수명 관례: 첫 번째 첨자 = **제품**(1=젤리, 2=주스), 두 번째 첨자 = **등급 순번**(1=9등급, 2=6등급, 3=4등급).

|  | 9등급(첨자 1) | 6등급(첨자 2) | 4등급(첨자 3) | **행합 = 생산량** |
|---|:---:|:---:|:---:|:---:|
| **젤리(제품 1)** | \(x_{11}\) | \(x_{12}\) | \(x_{13}\) | \(x_{11}+x_{12}+x_{13}\) |
| **주스(제품 2)** | \(x_{21}\) | \(x_{22}\) | \(x_{23}\) | \(x_{21}+x_{22}+x_{23}\) |
| **열합 = 등급별 사용량** | \(x_{11}+x_{21}\) | \(x_{12}+x_{22}\) | \(x_{13}+x_{23}\) | |

총 **6개** 변수. 단위: **만 kg** (또는 천 kg — 엑셀에서 통일만 하면 됨).

**§1.5 대응:** "내가 숫자로 정하는 것" = 각 제품에 각 등급 포도를 **얼마나 투입할지**. 이것을 정하면 생산량(행합)도, 등급별 소비량(열합)도 자동으로 결정된다.

> **이전 문제들과의 비교:**
> - Decora: "패턴을 몇 번 쓸지" → 패턴이 변수 단위
> - Big M: "경로별 몇 대 보낼지" → 경로가 변수 단위
> - Sellmore: "사람-업무 배정 여부" → 0-1 변수
> - **W사: "제품에 원료를 얼마 넣을지"** → **제품×원료(등급)** 조합이 변수 단위
>
> 공통점: **"무엇을 조합하는가"의 가장 세밀한 단위**를 변수로 놓는다.

### 5.4 목적함수 — 도출 과정

#### 이익의 인과

- 포도젤리 1 kg 판매 시 이익 **2,700원** → 젤리 생산량이 \((x_{11}+x_{12}+x_{13})\) 만 kg이면 이익 = \(2{,}700 \times (x_{11}+x_{12}+x_{13})\).
- 포도주스 1 kg 판매 시 이익 **3,500원** → 이익 = \(3{,}500 \times (x_{21}+x_{22}+x_{23})\).

**핵심 가정:** 이익은 **생산량(= 판매량)에 비례**한다. 즉 **한계이익 불변** — §1.3의 선형 조건이 성립.

\[
\max\; Z = 2{,}700\,(x_{11}+x_{12}+x_{13}) + 3{,}500\,(x_{21}+x_{22}+x_{23})
\]

> **단위 주의 (슬라이드):** 변수를 **만 kg** 단위로 두면 이익도 만 kg 단위로 스케일링. 슬라이드에서는 \(Z = 2.7(\cdots) + 3.5(\cdots)\) 로 쓰는데, 이는 **천원 × 만 kg = 백만원** 스케일이다.
>
> | 변수 단위 | 이익 계수 | Z 단위 |
> |:---:|:---:|:---:|
> | kg | 2,700 원/kg | 원 |
> | 천 kg | 2,700 천원/천kg = 2.7 백만원 | 백만원 |
> | **만 kg** | 2,700 만원/만kg = **2.7 천만원** | 천만원 |
>
> 엑셀에서는 **변수와 계수의 단위를 맞추는 것**이 핵심. 슬라이드의 2.7, 3.5는 이미 스케일링된 값이다.

**왜 "등급과 무관하게" 같은 계수인가?** — 9등급 포도로 만든 젤리든 4등급 포도로 만든 젤리든, **제품이 "포도젤리"인 이상 판매가(이익)는 동일**하다. 등급 차이는 **제약(품질 요건)**으로만 반영되고, 이익에는 영향을 주지 않는다.

### 5.5 제약식 ① — 자원(원료) 상한: "보유 포도를 넘을 수 없다"

각 등급의 **열합**(젤리+주스에 투입된 총량)이 **보유량 이하**여야 한다.

\[
x_{11} + x_{21} \le 40 \quad \text{(9등급: 보유 4만 kg)}
\]
\[
x_{12} + x_{22} \le 60 \quad \text{(6등급: 보유 6만 kg)}
\]
\[
x_{13} + x_{23} \le 60 \quad \text{(4등급: 보유 6만 kg)}
\]

**왜 ≤ 인가?** — 보유 포도를 **전부 쓸 의무는 없다**. 남는 포도는 그냥 재고로 두면 된다(폐기나 비용이 없다는 가정). 이것이 Big M(=, 전량 출하)이나 Sellmore(=, 전원 배정)과 다른 점이다.

**왜 = 가 아닌가?** — 예컨대 4등급 포도가 남더라도, 그걸 억지로 쓰면 품질(평균 등급)이 떨어질 수 있다. 이익을 최대화하려면 **쓸 만큼만 쓰는 게** 나을 수 있다.

---

### 5.6 제약식 ② — 품질(등급) 제약: 가중평균 → 선형 부등식 변환

이 문제의 **핵심이자 가장 흥미로운 부분**이다. "평균 등급 5 이상"이라는 **비율(분수) 조건**을 어떻게 **LP에 넣을 수 있는 선형 부등식**으로 바꾸는가?

#### 젤리: 평균 등급 ≥ 5

**Step 1 — 평균 등급을 수식으로 쓴다**

\[
\text{젤리 평균 등급} = \frac{9 \cdot x_{11} + 6 \cdot x_{12} + 4 \cdot x_{13}}{x_{11} + x_{12} + x_{13}} \ge 5
\]

- 분자: 각 등급 × 투입량의 합 (= 가중 합)
- 분모: 총 젤리 생산량 (= 가중치의 합)

**Step 2 — 분모를 양변에 곱한다**

분모 \((x_{11}+x_{12}+x_{13})\) 는 생산량이므로 **≥ 0** 이다. 양수(생산량 > 0)일 때 부등호 방향이 유지된다.

\[
9x_{11} + 6x_{12} + 4x_{13} \ge 5\,(x_{11} + x_{12} + x_{13})
\]

**Step 3 — 우변을 전개하고 좌변으로 이항**

\[
9x_{11} + 6x_{12} + 4x_{13} \ge 5x_{11} + 5x_{12} + 5x_{13}
\]

\[
(9-5)x_{11} + (6-5)x_{12} + (4-5)x_{13} \ge 0
\]

\[
\boxed{4x_{11} + 1x_{12} - 1x_{13} \ge 0}
\]

**인과 해석:** 이 부등식은 "**9등급(기준 이상)과 6등급(기준 이상)이 4등급(기준 이하)의 끌어내림을 충분히 상쇄해야 한다**"는 뜻이다.
- \(x_{11}\)(9등급)의 계수 **+4** = 기준(5)보다 **4만큼 높아서** 평균을 올리는 힘.
- \(x_{12}\)(6등급)의 계수 **+1** = 기준보다 **1만큼 높아서** 약간 올림.
- \(x_{13}\)(4등급)의 계수 **−1** = 기준보다 **1만큼 낮아서** 평균을 끌어내림.

---

#### 주스: 평균 등급 ≥ 7

같은 과정을 반복한다.

\[
\frac{9x_{21} + 6x_{22} + 4x_{23}}{x_{21}+x_{22}+x_{23}} \ge 7
\]

\[
9x_{21} + 6x_{22} + 4x_{23} \ge 7(x_{21}+x_{22}+x_{23})
\]

\[
(9-7)x_{21} + (6-7)x_{22} + (4-7)x_{23} \ge 0
\]

\[
\boxed{2x_{21} - 1x_{22} - 3x_{23} \ge 0}
\]

**인과 해석:** 주스는 기준이 7로 높다.
- 9등급(계수 +2)만이 기준보다 높다 — 유일한 "올림 역할".
- 6등급(계수 −1)은 이제 기준보다 **낮아서** 끌어내린다.
- 4등급(계수 −3)은 기준과 격차가 크다 — **강한 끌어내림**.

→ 주스를 많이 만들려면 **9등급 포도를 충분히 확보**해야 한다. 그런데 9등급은 **4만 kg밖에 없다** — 여기서 자원 제약과 품질 제약이 **동시에 바인딩**되는 긴장 관계가 생긴다.

---

#### 정리: 비율 → 선형 변환 패턴

| 단계 | 조작 | 결과 |
|------|------|------|
| 원래 | \(\frac{\sum g_k x_k}{\sum x_k} \ge G\) | 비선형(분수) |
| 분모 곱 | \(\sum g_k x_k \ge G \sum x_k\) | 선형(양변 곱) |
| 이항 | \(\sum (g_k - G) x_k \ge 0\) | **순수 선형 부등식** |

> **이 변환이 CH.3에서 가장 중요한 기법 중 하나다.** 가중평균 조건은 겉보기에 비선형이지만, 분모가 **변수의 합(≥0)** 이므로 양변 곱으로 선형화할 수 있다. 이 패턴은 혼합·배합(blending) 문제 전반에서 반복된다.

---

### 5.7 완전한 수리모형

\[
\boxed{
\begin{aligned}
\max\quad & Z = 2.7\,(x_{11}+x_{12}+x_{13}) + 3.5\,(x_{21}+x_{22}+x_{23}) \quad\text{(총이익, 백만원 스케일)} \\[6pt]
\text{s.t.}\quad
& x_{11} + x_{21} \le 40 \quad\text{(9등급 상한)} \\
& x_{12} + x_{22} \le 60 \quad\text{(6등급 상한)} \\
& x_{13} + x_{23} \le 60 \quad\text{(4등급 상한)} \\[3pt]
& 4x_{11} + x_{12} - x_{13} \ge 0 \quad\text{(젤리 평균 등급 ≥ 5)} \\
& 2x_{21} - x_{22} - 3x_{23} \ge 0 \quad\text{(주스 평균 등급 ≥ 7)} \\[3pt]
& x_{11},\, x_{12},\, x_{13},\, x_{21},\, x_{22},\, x_{23} \ge 0
\end{aligned}
}
\]

> **제약 5개(자원 3 + 품질 2), 변수 6개.** 자유도 = 6 − 5 = 1(활성 제약이 5개일 때). Decora(26변수 5제약)에 비해 **소규모지만 품질 제약의 도출 과정이 핵심**.

### 5.8 인과 되짚기 — §1.5 체크리스트 대응

| §1.5 질문 | W사에서의 답 |
|-----------|-------------|
| **변수:** 내가 숫자로 정하는 것은? | "각 제품에 각 등급 포도를 얼마나 넣을지" → \(x_{ij}\) (6개) |
| **목적:** 하나의 수로 어떻게? | 제품별 이익 × 생산량의 합 → \(\max Z\) |
| **제약 ①:** 마음대로 키우면 충돌? | 보유 포도량 초과 → **자원 상한 (≤)** |
| **제약 ②:** 또 무엇이 충돌? | 싸구려 포도만 쓰면 품질(평균 등급) 미달 → **품질 하한 (≥)** |
| **왜 ≤ 와 ≥ 가 섞여 있나?** | 자원은 "넘지 마라", 품질은 "이 이상이어야 해" — **방향이 반대** |

### 5.9 네 문제 대조 — 제약 부호와 인과

| 문제 | 제약 부호 | 인과 |
|------|:---:|------|
| **Decora** | ≥ | 수요 이상 잘라야 (초과 = 폐기, 허용) |
| **Big M** | = | 공급·수요 정확히 일치 (고정 요건) |
| **Sellmore** | = | 1:1 배정 (겸임·공석 불가) |
| **W사** | **≤ + ≥ 혼합** | 자원 ≤ (남겨도 됨) + 품질 ≥ (기준 이상) |

> 같은 LP라도 **현실의 "어기면 안 되는 관계"가 무엇이냐**에 따라 부호가 달라진다. §1.1의 "울타리"가 **위에서 누르는 천장(≤)**인지, **아래에서 받치는 바닥(≥)**인지, **양쪽 다 고정(=)**인지를 구별하는 것이 모형화의 핵심이다.

### 5.10 스프레드시트 모형 개발 — 초기해에서 최적해까지

슬라이드는 **두 단계**로 보여준다: ① **초기해**(아무 값이나 넣어 구조를 확인) → ② **Solver 돌려서 최적해**.

#### 5.10.1 시트 레이아웃 — 셀 배치와 수식의 인과

슬라이드 기준 셀 주소를 따라 재구성한다.

```
     A          B(9등급)   C(6등급)   D(4등급)   E(생산량)   F(품질LHS)  G(품질RHS)
 3   등급:       9          6          4
 4   보유량:     40         60         60                                          (만 kg)
 5   이익단가:                                              젤리 2.7  주스 3.5    (천원/kg)
 6   기준등급:                                              젤리 5    주스 7
 7
 8   --- 파라미터 영역 끝 ---
 9
10               9등급      6등급      4등급      생산량      품질LHS    품질RHS
11   ──────────────────────────────────────────────────────────────────────────
12   젤리(x1j)   x₁₁        x₁₂        x₁₃        E12        F12        G12      ← 결정변수 행
13   주스(x2j)   x₂₁        x₂₂        x₂₃        E13        F13        G13      ← 결정변수 행
14   ──────────────────────────────────────────────────────────────────────────
15   등급별합    B15        C15        D15                                         ← 열합(사용량)
16   보유량      40         60         60                                          ← 제약 RHS
17
18   목적 셀(총이익):  ??
```

---

#### 5.10.2 각 수식이 "무엇을 계산하고, 왜 필요한가"

| 셀 | 수식 | 무엇을 계산하는가 | 왜 필요한가(인과) |
|----|------|-------------------|-------------------|
| **E12** | `=SUM(B12:D12)` | 젤리 총생산량 = \(x_{11}+x_{12}+x_{13}\) | 품질 RHS 계산과 이익 계산에 쓰임. **행합 = 이 제품에 들어간 포도 총량 = 생산량** |
| **E13** | `=SUM(B13:D13)` | 주스 총생산량 = \(x_{21}+x_{22}+x_{23}\) | 위와 동일 |
| **B15** | `=SUM(B12:B13)` | 9등급 사용 총량 = \(x_{11}+x_{21}\) | 자원 제약 LHS. **열합 = 이 등급 포도가 양쪽 제품에 얼마나 쓰였는지** |
| **C15** | `=SUM(C12:C13)` | 6등급 사용 총량 | 위와 동일 |
| **D15** | `=SUM(D12:D13)` | 4등급 사용 총량 | 위와 동일 |
| **F12** | `=SUMPRODUCT(B3:D3, B12:D12)` | 젤리의 **가중 등급합** = \(9x_{11}+6x_{12}+4x_{13}\) | §5.6 품질 제약의 **LHS** (분자에 해당) |
| **F13** | `=SUMPRODUCT(B3:D3, B13:D13)` | 주스의 가중 등급합 = \(9x_{21}+6x_{22}+4x_{23}\) | 위와 동일 |
| **G12** | `=5*SUM(B12:D12)` 또는 `=5*E12` | 젤리 기준등급 × 생산량 = \(5(x_{11}+x_{12}+x_{13})\) | §5.6 품질 제약의 **RHS** (분모 곱한 값) |
| **G13** | `=7*SUM(B13:D13)` 또는 `=7*E13` | 주스 기준등급 × 생산량 | 위와 동일 |
| **목적** | `=B7*E12+C7*E13` 즉 `=2.7*E12+3.5*E13` | 총이익 = 2.7×젤리생산 + 3.5×주스생산 | **목적함수 값 → Solver가 Max할 대상** |

> **수식 연쇄의 흐름:**
> ```
> 결정변수(B12:D13) → 행합(E12:E13, 생산량) → 목적 셀(이익)
>                   → 열합(B15:D15, 사용량) → 자원 제약(≤ 보유량)
>                   → SUMPRODUCT(F12:F13, 품질LHS) vs 기준×생산량(G12:G13) → 품질 제약(≥)
> ```
> 모든 수식이 **결정변수 6개에서 출발**해 파생된다. Solver가 변수를 바꾸면 모든 셀이 자동 갱신.

---

#### 5.10.3 단위에 주의 — 왜 2,700이 아니라 2.7인가

슬라이드가 반복 강조하는 포인트: **백만원 = 천원 × 1,000 kg**.

| 항목 | 원래 단위 | 엑셀에서 쓰는 단위 | 변환 |
|------|-----------|---------------------|------|
| 변수 \(x_{ij}\) | **만 kg** | 만 kg (그대로) | — |
| 이익 단가 | 2,700 **원/kg** | 2.7 **천원/kg** | ÷1,000 |
| 보유량 | 4**만** kg | 40 (**천 kg**) 또는 4 (**만 kg**) | 변수 단위와 맞춤 |
| 목적함수 Z | ? | **만 kg × 천원/kg = 천만원** | |

**실수하기 쉬운 곳:** 변수를 "만 kg"으로 두면서 이익을 "원/kg"으로 쓰면 Z의 단위가 "만원"이 되어 숫자가 너무 커진다. 슬라이드가 2.7, 3.5로 쓴 이유는 **계수의 단위를 맞춰** Z가 깔끔한 스케일로 나오도록 한 것이다.

---

#### 5.10.4 초기해 (Solver 돌리기 전) — "구조 확인용"

Solver를 돌리기 전에 **아무 값이나 넣어** 수식이 제대로 연결되었는지 확인한다. 슬라이드 초기해 예시:

| | 9등급(B) | 6등급(C) | 4등급(D) | 생산량(E) | 품질LHS(F) | 품질RHS(G) |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| 젤리 | 0 | 0 | 0 | 0 | 0 | 0 |
| 주스 | 0 | 0 | 0 | 0 | 0 | 0 |
| 등급별합 | 0 | 0 | 0 | | | |
| 보유량 | 40 | 60 | 60 | | | |

초기값이 전부 0이면:
- 모든 제약이 자동 충족(0 ≤ 40, 0 ≥ 0 등) — 실행 가능.
- 목적함수 = 0 — 당연히 최적은 아님.
- **이 상태에서 수식에 에러가 없는지, 제약 셀이 올바른 비교를 하는지 눈으로 점검.**

---

#### 5.10.5 최적해 (Solver 실행 후)

Solver(Simplex LP, Max)를 돌리면 다음과 같은 최적해를 얻는다:

| | 9등급 | 6등급 | 4등급 | 생산량 | 품질LHS | 품질RHS | LHS ≥ RHS? |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **젤리** | \(x_{11}^*\) | \(x_{12}^*\) | \(x_{13}^*\) | \(\sum\) | \(9x_{11}^*+\cdots\) | \(5 \times \sum\) | ✓ |
| **주스** | \(x_{21}^*\) | \(x_{22}^*\) | \(x_{23}^*\) | \(\sum\) | \(9x_{21}^*+\cdots\) | \(7 \times \sum\) | ✓ |
| 등급별합 | ≤ 40 | ≤ 60 | ≤ 60 | | | | |

> **최적해에서 확인할 것:**
> 1. **어느 자원 제약이 바인딩(등호로 꽉 차는)되는가?** — 9등급(4만 kg)은 가장 적고 주스의 올림 역할을 하므로 **바인딩될 가능성이 높다**.
> 2. **어느 품질 제약이 바인딩되는가?** — 주스(기준 7)는 까다로우므로 품질 LHS = RHS로 딱 맞을 가능성이 높다(여유 없이 기준을 겨우 맞춤).
> 3. **4등급 포도가 남는가?** — 4등급은 가장 많고(6만) 품질을 끌어내리므로, 전량 사용하지 않을 수 있다.

#### 5.10.6 Solver 설정 정리

| Solver 항목 | 설정 |
|-------------|------|
| **목적 셀** | `=2.7*E12+3.5*E13` (또는 `B7*E12+C7*E13`) → **Max** |
| **변경 셀** | `B12:D13` (6개: \(x_{11}\)~\(x_{23}\)) |
| **제약 조건** | |
| 자원 ① | `B15 ≤ 40` (9등급 사용합 ≤ 보유) |
| 자원 ② | `C15 ≤ 60` (6등급) |
| 자원 ③ | `D15 ≤ 60` (4등급) |
| 품질 ① | `F12 ≥ G12` (젤리 가중등급합 ≥ 기준×생산량) |
| 품질 ② | `F13 ≥ G13` (주스 가중등급합 ≥ 기준×생산량) |
| 비음 | `B12:D13 ≥ 0` (Solver 옵션에서 "비음 조건 가정" 체크로도 가능) |
| **해법** | **Simplex LP** |

> **주의:** 품질 제약을 Solver에 넣을 때 **LHS ≥ RHS** 방향을 거꾸로 쓰면 전혀 다른 답이 나온다. `F12 ≥ G12` 인지 `G12 ≤ F12` 인지 — 같은 뜻이지만 입력 시 헷갈리지 않게 주의.

## 6. 동적 생산–재고 계획 — 축구공 회사

### 6.1 동적 생산 계획이란 — 이전 문제들과 무엇이 다른가

| 비교 | Decora·Big M·Sellmore·W사 | 축구공 회사 |
|------|:---:|:---:|
| 시간 | **단일 기간** (한 번에 결정) | **여러 기간**(6개월) — 기간마다 결정 |
| 핵심 연결 | 각 제약이 독립적 | **기간 간 재고 수지**로 연결됨 |
| 변수 | 공간적 배분(경로·배정·혼합) | **시간적 배분**(언제 얼마나 만들어 둘지) |

**두 유형:**

1. **생산–재고 일정 (production-inventory scheduling)**
   - 여러 기간에 걸친 수요량 예측
   - 기간별 재고 수준 고려
   - **최소 비용**으로 생산–재고 일정을 수립

2. **총괄 생산 계획 (aggregate production planning)**
   - 위에 **기간별 고용 계획** 추가
   - 생산–재고–**고용 및 근무(초과작업)** 일정까지 최적화
   - → §7(행복가구)에서 다룸

축구공 문제는 **유형 1**에 해당한다.

---

### 6.2 스토리

- **축구공 생산·판매 회사** — 향후 **6개월간** 수요를 **적시에** 만족하기 원함.

**수요(단위: 천 개):**

| 월 | 1월 | 2월 | 3월 | 4월 | 5월 | 6월 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 수요 \(d_t\) | 10 | 15 | 30 | **35** | 25 | 10 |

> **수요의 특징:** 4월에 피크(35), 1·6월에 저수요(10). 수요가 불균일하므로 **미리 만들어 재고로 보관** vs **그때그때 생산** 사이의 트레이드오프가 생긴다.

**제약 파라미터:**

| 항목 | 값 | 단위 |
|------|:---:|------|
| 월 최대 생산 용량 | **30** | 천 개 |
| 월 최대 재고 용량 | **10** | 천 개 |
| 1월초 초기 재고 \(y_0\) | **5** | 천 개 |

**비용 파라미터:**

| 월 | 1월 | 2월 | 3월 | 4월 | 5월 | 6월 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 생산 단가 \(c_t\) (천원/천개) | 12.50 | 12.55 | 12.70 | 12.80 | 12.85 | 12.95 |
| 재고 유지비 \(h_t = 0.05 \times c_t\) | 0.625 | 0.6275 | 0.635 | 0.64 | 0.6425 | 0.6475 |

> **재고 유지비 = 생산 단가의 5%.** 예: 1월에 1단위(천 개)를 1달간 재고 보관 → 비용 = 12.5 × 0.05 = **0.625** (천원). 생산 단가가 **월별로 다른** 이유는 재료 가격의 계절적 변동.

---

### 6.3 사고의 출발 — §1.5 세 질문 적용

| §1.5 질문 | 축구공에서의 답 |
|-----------|----------------|
| **변수:** 내가 숫자로 정하는 것은? | **월별 생산량** \(x_t\) — "이번 달에 몇 개 만들지" (6개) |
| **목적:** 하나의 수로 어떻게? | 6개월 **총비용(생산비 + 재고비)** → \(\min\) |
| **제약:** 마음대로 정하면 충돌하는 현실? | ① 생산 용량 상한 ② 재고 용량 상한 ③ 수요 충족(재고 ≥ 0, 백오더 불가) |

**이전 문제들과의 차이:**
- W사: 변수 = "무엇을 얼마나 혼합할지" (공간적 배분)
- 축구공: 변수 = "**언제** 얼마나 만들지" (시간적 배분)
- **새로운 요소: 기간 간 재고 연결(Balance Equation)** — 이전 문제에는 없던 **동적** 구조

---

### 6.4 결정변수와 보조변수

#### 결정변수 (Solver가 바꿀 셀)

\[
x_t = \text{t월 생산량} \quad (t = 1,\ldots,6), \quad x_t \ge 0
\]

#### 보조변수 (수식으로 자동 계산)

\[
y_t = \text{t월 **말** 재고량} \quad (t = 1,\ldots,6)
\]

**왜 \(y_t\)도 변수인가, 그런데 왜 "보조"인가?**

- \(y_t\)는 \(x_t\)가 정해지면 **자동으로 결정**된다(Balance Equation으로). 따라서 "독립적으로 자유롭게 정하는" 변수가 아니라 **종속 변수(보조변수)**.
- 하지만 제약(\(y_t \ge 0\), \(y_t \le 10\))과 목적(재고비)에 \(y_t\)가 등장하므로 **모형에는 필요**하다.
- 엑셀에서는 \(y_t\)를 수식 셀로 두면 Solver 변경 셀에 넣지 않아도 된다.

---

### 6.5 Balance Equation — 이 문제의 심장

**재고 수지(Balance Equation):**

\[
\boxed{y_t = y_{t-1} + x_t - d_t}
\]

| 기호 | 의미 | 인과 |
|------|------|------|
| \(y_{t-1}\) | 전월 말 재고 | "지난달에 남긴 것" |
| \(x_t\) | 당월 생산 | "이번 달에 만든 것" |
| \(d_t\) | 당월 수요 | "이번 달에 팔려 나간 것" |
| \(y_t\) | 당월 말 재고 | **남은 것 + 만든 것 − 나간 것** |

**전개:**

| 월 | Balance Equation | 구체적 |
|:---:|---|---|
| 1월 | \(y_1 = y_0 + x_1 - d_1\) | \(y_1 = 5 + x_1 - 10\) |
| 2월 | \(y_2 = y_1 + x_2 - d_2\) | \(y_2 = y_1 + x_2 - 15\) |
| 3월 | \(y_3 = y_2 + x_3 - d_3\) | \(y_3 = y_2 + x_3 - 30\) |
| 4월 | \(y_4 = y_3 + x_4 - d_4\) | \(y_4 = y_3 + x_4 - 35\) |
| 5월 | \(y_5 = y_4 + x_5 - d_5\) | \(y_5 = y_4 + x_5 - 25\) |
| 6월 | \(y_6 = y_5 + x_6 - d_6\) | \(y_6 = y_5 + x_6 - 10\) |

> **이것이 "동적"인 이유:** \(y_1\)이 \(y_2\)에 영향을 주고, \(y_2\)가 \(y_3\)에 영향을 주고… — **체인**으로 연결된다. 1월에 많이 만들면 재고가 쌓여 2월 이후에 덜 만들어도 되지만, 재고비가 든다. 이 **시간적 트레이드오프**가 W사(공간적 혼합)에는 없던 구조다.

---

### 6.6 제약식 — 왜 이런 형태인가

#### (1) 생산 용량 상한 — "공장이 한 달에 만들 수 있는 한계"

\[
x_t \le 30 \quad (t = 1,\ldots,6)
\]

**인과:** 설비·인력·작업 시간의 물리적 한계. 아무리 수요가 35(4월)라도 한 달에 30 이상은 못 만든다 → **미리 만들어 재고로 쌓아야** 한다.

#### (2) 재고 용량 상한 — "창고 크기의 한계"

\[
y_t \le 10 \quad (t = 1,\ldots,6)
\]

**인과:** 창고 공간, 보관 조건 등의 물리적 한계. 미리 많이 만들고 싶어도 10천 개까지만 쌓을 수 있다.

#### (3) 백오더 불허 — "주문 잔고를 허용하지 않는다"

\[
y_t \ge 0 \quad (t = 1,\ldots,6)
\]

**인과:** 월말 재고가 **음수**라는 것은 "수요를 못 채우고 다음 달로 밀렸다"는 뜻(백오더/주문잔고). 이 문제에서는 **허용하지 않는다** → 모든 달에 재고 ≥ 0.

> **주의:** 재고가 음수가 될 수 없으므로, 4월 수요 35(최대 생산 30 초과)를 **반드시 이전 달 재고로 보충**해야 한다. 이것이 "미리 생산"의 필요성을 만든다.

#### (4) 비음 조건

\[
x_t \ge 0 \quad (t = 1,\ldots,6)
\]

---

### 6.7 목적함수 — 생산비 + 재고비

#### 월별 비용 구조

\[
\text{t월 비용} = \underbrace{c_t \cdot x_t}_{\text{생산비}} + \underbrace{h_t \cdot y_t}_{\text{재고비}}
\]

| 항목 | 수식 | 인과 |
|------|------|------|
| **생산비** | \(c_t \times x_t\) | t월에 \(x_t\)개 만들 때의 재료·가공 비용. 단가 \(c_t\)는 월별로 다름(계절 변동) |
| **재고비** | \(h_t \times y_t\) = \(0.05 c_t \times y_t\) | t월 말 재고 \(y_t\)를 한 달간 보관하는 비용. 단가의 5% |

#### 6개월 총비용 (목적함수)

\[
\min\; Z = \sum_{t=1}^{6} (c_t \cdot x_t + h_t \cdot y_t)
\]

전개하면:

\[
\min\; Z = 12.50\, x_1 + 12.55\, x_2 + 12.70\, x_3 + 12.80\, x_4 + 12.85\, x_5 + 12.95\, x_6
\]
\[
\quad + 0.625\, y_1 + 0.6275\, y_2 + 0.635\, y_3 + 0.64\, y_4 + 0.6425\, y_5 + 0.6475\, y_6
\]

**왜 \(\min\) 인가?** — W사는 이익 최대화(\(\max\))였지만, 여기서는 수요가 **이미 정해져** 있고 그걸 충족하는 **비용을 줄이는** 문제이므로 \(\min\).

**왜 생산 단가가 월별로 다른 게 중요한가?** — 단가가 일정하면 "아무 때나 만들어도 생산비는 같다 → 재고비만 최소화하면 됨". 하지만 단가가 월별로 다르므로 "**싼 달에 미리 만들어 재고로 쌓을지** vs **비싼 달에 만들지만 재고비를 아낄지**"의 트레이드오프가 생긴다.

---

### 6.8 완전한 수리모형

\[
\boxed{
\begin{aligned}
\min\quad & Z = \sum_{t=1}^{6}\bigl(c_t\, x_t + h_t\, y_t\bigr) \\[6pt]
\text{s.t.}\quad
& y_t = y_{t-1} + x_t - d_t \quad (t=1,\ldots,6;\; y_0 = 5) \quad\text{(Balance)} \\
& x_t \le 30 \quad (t=1,\ldots,6) \quad\text{(생산 상한)} \\
& y_t \le 10 \quad (t=1,\ldots,6) \quad\text{(재고 상한)} \\
& y_t \ge 0 \quad (t=1,\ldots,6) \quad\text{(백오더 불허)} \\
& x_t \ge 0 \quad (t=1,\ldots,6)
\end{aligned}
}
\]

> **변수:** \(x_t\) 6개 (Solver 변경 셀) + \(y_t\) 6개 (수식으로 계산, 종속).
> **제약:** Balance 6개 + 생산상한 6개 + 재고상한 6개 + 비음 12개 = 30개.
> 하지만 Balance는 **등식으로 \(y_t\)를 결정**하므로 실질 자유도는 \(x_t\) 6개에 대한 부등식 제약 18개.

---

### 6.9 인과 되짚기 — 왜 "동적"인가, 핵심 트레이드오프

#### 4월 문제를 예로 들어보자

- 4월 수요 = **35** > 생산 상한 **30**. → 4월만으로는 **5천 개 부족**.
- 따라서 **3월 이전에 미리 만들어 재고로 보관**해야 한다.
- 하지만 재고 상한 = **10** → 한 달에 최대 10천 개까지만 쌓을 수 있다.
- 1월 초기 재고 5가 있으므로, 이것도 활용 가능.

이런 **기간 간 파급 효과**가 "동적"의 핵심이다. 1월 결정이 4월에 영향을 미친다.

#### 다섯 문제 대조

| 문제 | 시간 구조 | 핵심 연결 | 제약 특징 |
|------|:---:|:---:|------|
| Decora | 단일 기간 | 없음 | 패턴 열거 |
| Big M | 단일 기간 | 없음 | 공급=수요 등호 |
| Sellmore | 단일 기간 | 없음 | 1:1 배정 등호 |
| W사 | 단일 기간 | 없음 | 자원 ≤ + 품질 ≥ |
| **축구공** | **6개월** | **Balance Eq.** | 상한 ≤ + 비음 ≥ + **기간 연쇄** |

---

15
16   ──────── 보조변수 (수식) ────────
17   생산비:    B5*B14   C5*C14   ...                                   ← cₜ × xₜ
18   수요:      10       15       30       35       25       10         ← 상수
19
20   ──────── 재고 ────────
21   초기재고   B3=5
22   월말재고:  B22      C22      D22      E22      F22      G22       ← yₜ (수식)
23   재고비:    B7*B22   C7*C22   ...                                   ← hₜ × yₜ
24
25   ──────── 비용 합산 ────────
26   월별비용:  B17+B23  C17+C23  ...                                   ← 생산비+재고비
27   총비용:    SUM(B26:G26)                                            ← 목적 셀
```

---

#### 6.10.1 핵심 수식과 인과

| 셀 | 수식 | 인과 |
|----|------|------|
| **B22** (1월말 재고) | `=B3+B14-B18` 즉 `=$B$3+B14-B11` | \(y_1 = y_0 + x_1 - d_1 = 5 + x_1 - 10\). **초기재고(상수) + 생산(변수) − 수요(상수)** |
| **C22** (2월말 재고) | `=B22+C14-C18` | \(y_2 = y_1 + x_2 - d_2\). **전월 말 재고(B22) 참조** — 여기서 **기간 간 연쇄**가 생김 |
| **D22~G22** | 같은 패턴 | \(y_t = y_{t-1} + x_t - d_t\) |
| **B17** (1월 생산비) | `=B5*B14` | \(c_1 \times x_1 = 12.50 \times x_1\) |
| **B23** (1월 재고비) | `=B7*B22` | \(h_1 \times y_1 = 0.625 \times y_1\) |
| **B26** (1월 총비용) | `=B17+B23` | 생산비 + 재고비 |
| **목적 셀** | `=SUM(B26:G26)` | 6개월 총비용 → **Min** |

> **수식 연쇄 흐름:**
> ```
> 결정변수(x₁~x₆) ──┬── × 생산단가 → 생산비(행17)──┐
>                    │                              ├→ 월별비용(행26) → 총비용(목적)
>                    └── Balance Eq. → 월말재고(행22)─┤
>                         ↑                          └── × 재고단가 → 재고비(행23)
>                    전월재고(체인)
> ```

---

#### 6.10.2 Solver 설정

| Solver 항목 | 설정 |
|-------------|------|
| **목적 셀** | `=SUM(B26:G26)` → **Min** |
| **변경 셀** | `B14:G14` (생산량 \(x_1\)~\(x_6\), 6개) |
| **제약 조건** | |
| 생산 상한 | `B14:G14 ≤ 30` |
| 재고 상한 | `B22:G22 ≤ 10` |
| 백오더 불허 | `B22:G22 ≥ 0` |
| 비음 | `B14:G14 ≥ 0` |
| **해법** | **Simplex LP** |

> **주의:** Balance Equation(\(y_t\))은 **수식 셀**이지 제약이 아니다. 엑셀에서 `B22=B3+B14-B18`로 수식을 넣으면, Solver가 \(x_t\)를 바꿀 때 \(y_t\)가 자동 갱신된다. **Solver 제약에는 \(y_t \le 10\), \(y_t \ge 0\)만** 넣으면 된다.

---

#### 6.10.3 최적해에서 예상되는 패턴

Solver를 돌리기 전에도 구조적으로 예상할 수 있는 것:

1. **4월(수요 35 > 생산 30):** 부족분 5를 **3월 이전 재고**로 충당해야 함.
2. **1·2월(저수요):** 수요보다 많이 만들어 재고를 쌓는 게 유리할 수 있음 — 단, 재고비와 생산 단가의 트레이드오프.
3. **생산 단가가 뒤로 갈수록 비싸짐**(12.50→12.95): 앞 달에 미리 만드는 인센티브가 생김. 하지만 재고비(5%)도 들어 **무한정 미리 만들 수는 없다**.
4. **재고 상한 10:** 2·3월에 재고를 10까지만 쌓을 수 있으므로, 4월 부족분을 **여러 달에 걸쳐** 분산 비축해야 할 수도 있다.

## 7. 총괄 생산 계획 — 행복가구 (예제 3.8)

### 7.1 축구공 → 행복가구: 무엇이 추가되는가

축구공(§6)은 **생산량**만 결정하면 됐다. 행복가구는 여기에 **인력 관리**가 겹친다.

| 비교 | 축구공 (§6) | 행복가구 (§7) |
|------|:---:|:---:|
| 결정 대상 | 생산량만 | 생산량 + **고용·해고·초과작업** |
| 비용 항목 | 생산비 + 재고비 | 생산비(재료) + **정규임금** + **초과임금** + **고용비** + **해고비** + 재고비 |
| Balance Eq. | 재고 수지 1개 | 재고 수지 + **인원 수지** — **2중 체인** |
| 용량 제한 | 고정(30/월) | **인원에 따라 변동** (인원 × 작업시간 / 4) |

→ §6.1에서 말한 **"총괄 생산 계획(aggregate production planning)"** 의 전형적 사례.

---

### 7.2 스토리 — 파라미터 전체 정리

**행복가구** — 소형 옷장 생산·판매. 향후 **5개월** 계획 (축소 모형; 보통 12개월).

#### (a) 수요

| 월 | 1월 | 2월 | 3월 | 4월 | 5월 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 수요 \(d_t\) (개) | 350 | 400 | **550** | 200 | 210 |

> 3월 피크(550). 축구공(4월 피크)과 같은 불균일 수요 → 미리 재고 비축 or 인원 조정 필요.

#### (b) 인력 파라미터

| 항목 | 값 | 단위 |
|------|:---:|------|
| 1월초 작업자 수 \(w_0\) | **3** | 명 |
| 1인당 정규 작업시간 | **160** | 시간/월 |
| 1인당 초과 작업시간 상한 | **20** | 시간/월 (즉 총 180시간/월 상한) |
| 정규 월급 | **150** | 만원/명·월 |
| 초과 작업 임금 | **2** | 만원/시간 |
| 고용 비용 | **170** | 만원/명 |
| 해고 비용 | **210** | 만원/명 |

> **고용·해고는 월초에 발생.** 즉, t월 초에 고용/해고 → t월 내내 그 인원으로 근무.

#### (c) 생산 파라미터

| 항목 | 값 | 단위 |
|------|:---:|------|
| 옷장 1개당 작업시간 | **4** | 시간/개 |
| 옷장 1개당 재료비 | **3** | 만원/개 |
| 초기 재고 \(I_0\) | **55** | 개 |
| 재고비 | **2** | 만원/개·월 |

#### (d) 기타 조건

- **백오더(주문미처리) 불허** — 당월 수요를 못 채우고 다음 달로 미루는 것 불가.
- **외주(하청) 없음** — 자체 생산만 가능.

---

### 7.3 사고의 출발 — 구해야 하는 것

**질문:** 5개월간 **고용·해고·생산·재고·초과작업** 계획을 세워 **총비용을 최소화**하라.

즉, **매월** 다음을 결정해야 한다:

1. **몇 명을 새로 고용할 것인가?**
2. **몇 명을 해고할 것인가?**
3. **초과 작업을 몇 시간 시킬 것인가?**
4. **옷장을 몇 개 만들 것인가?**

→ 이 4가지 결정이 **5개월 × 4종류 = 20개 결정변수**로 이어진다.

---

### 7.4 결정변수 — 4종류 × 5개월

| 변수 | 의미 | 단위 | 개수 |
|------|------|------|:---:|
| \(H_t\) | t월 **신규 고용** 작업자 수 | 명 | 5 |
| \(F_t\) | t월 **해고** 작업자 수 | 명 | 5 |
| \(O_t\) | t월 **초과 작업 시간** (전체 합) | 시간 | 5 |
| \(P_t\) | t월 **생산량** | 개 | 5 |

총 **20개** 결정변수 (Solver 변경 셀).

#### 왜 이 4가지인가?

- **\(H_t, F_t\):** 인원을 조절하는 레버. 고용하면 생산능력↑ 이지만 고용비 170만원 발생. 해고하면 인건비↓ 이지만 해고비 210만원.
- **\(O_t\):** 정규시간(160h×인원)으로 부족할 때 추가 생산력을 확보하는 레버. 시간당 2만원 추가.
- **\(P_t\):** 최종 산출물. 위 세 변수에 의해 **능력의 상한**이 정해지지만, 상한까지 반드시 만들 필요는 없음.

---

### 7.5 보조변수 — Balance Equation으로 결정되는 종속변수

축구공에서 \(y_t\)(월말재고)가 보조변수였듯이, 여기서는 **두 종류**의 보조변수가 있다.

| 보조변수 | 의미 | Balance Equation |
|----------|------|------------------|
| \(W_t\) | t월 **근무 가능 작업자 수** | \(W_t = W_{t-1} + H_t - F_t\), \(W_0 = 3\) |
| \(I_t\) | t월 **월말 재고** | \(I_t = I_{t-1} + P_t - d_t\), \(I_0 = 55\) |

**축구공과의 비교:**
- 축구공: Balance Eq. **1개** (재고 체인)
- 행복가구: Balance Eq. **2개** (인원 체인 + 재고 체인) — **2중 동적 구조**

---

### 7.6 Balance Equation ① — 인원 수지

\[
\boxed{W_t = W_{t-1} + H_t - F_t} \quad (t=1,\ldots,5;\; W_0 = 3)
\]

| 월 | 전개 |
|:---:|------|
| 1월 | \(W_1 = 3 + H_1 - F_1\) |
| 2월 | \(W_2 = W_1 + H_2 - F_2\) |
| 3월 | \(W_3 = W_2 + H_3 - F_3\) |
| 4월 | \(W_4 = W_3 + H_4 - F_4\) |
| 5월 | \(W_5 = W_4 + H_5 - F_5\) |

**인과:** "이번 달 근무 가능 인원 = 지난달 인원 + 새로 뽑은 사람 − 해고한 사람." 고용·해고가 **월초**에 발생하므로, \(W_t\)는 t월 **한 달 내내** 유효한 인원이다.

> **염두에 둘 것:** 같은 달에 고용과 해고를 동시에 하는 것은 **논리적으로 무의미**(뽑으면서 자르면 양쪽 비용만 낭비). 최적해에서는 **같은 달에 \(H_t > 0\) 이면서 \(F_t > 0\)인 경우는 나타나지 않는다** — LP가 자동으로 피해준다.

---

### 7.7 Balance Equation ② — 재고 수지

\[
\boxed{I_t = I_{t-1} + P_t - d_t} \quad (t=1,\ldots,5;\; I_0 = 55)
\]

축구공(§6.5)과 **완전히 같은 구조**. 다만 여기서는 생산 상한이 고정(30)이 아니라 **인원에 따라 변동**한다는 점이 다르다.

---

### 7.8 작업시간·생산능력 — 인원 → 시간 → 개수 연쇄

이 문제의 **핵심 연결 고리**. 인원 변수가 어떻게 생산량 제약으로 이어지는지:

```
W_t(인원) ──→ 정규시간 = W_t × 160 ──┐
                                       ├→ 총작업시간 = 정규 + O_t ──→ 생산능력 = 총시간 / 4
O_t(초과작업) ─────────────────────────┘
```

#### (a) 가용 정규 작업시간

\[
\text{정규시간}_t = W_t \times 160 \quad \text{(시간)}
\]

#### (b) 초과 작업 상한

\[
O_t \le W_t \times 20 \quad \text{(제약)}
\]

**인과:** 1인당 최대 20시간 초과 가능. 인원 \(W_t\)명이면 전체 초과 상한 = \(20 W_t\).

#### (c) 총 작업시간

\[
\text{총시간}_t = W_t \times 160 + O_t
\]

#### (d) 생산능력(개) 및 생산량 제약

옷장 1개 = 4시간이므로:

\[
\text{생산능력}_t = \frac{\text{총시간}_t}{4} = \frac{W_t \times 160 + O_t}{4} = 40 W_t + \frac{O_t}{4}
\]

\[
\boxed{P_t \le 40 W_t + \frac{O_t}{4}} \quad \text{(생산량 ≤ 생산능력)}
\]

> **축구공과의 차이:** 축구공은 \(x_t \le 30\)(고정). 행복가구는 **\(W_t\)와 \(O_t\)에 따라 상한이 변동**. 인원을 늘리면 생산능력이 올라가지만 인건비도 올라간다 — 이것이 **총괄 계획의 트레이드오프**.

---

### 7.9 제약식 — 전체 정리

#### 제약 ① 인원 수지 (Balance Eq.)

\(W_t = W_{t-1} + H_t - F_t\) — 엑셀에서는 **수식 셀**로 구현.

#### 제약 ② 초과작업 상한

\[
O_t \le 20 \times W_t \quad (t=1,\ldots,5)
\]

**인과:** 1인당 초과 20시간 한도. 인원이 작으면 초과작업도 적게만 가능.

#### 제약 ③ 생산량 상한

\[
P_t \le 40 W_t + \frac{O_t}{4} \quad (t=1,\ldots,5)
\]

또는 동치로: \(4 P_t \le 160 W_t + O_t\) (정수 계수로 쓰고 싶을 때).

**인과:** 총 작업시간으로 만들 수 있는 옷장 수를 초과할 수 없다.

#### 제약 ④ 재고 수지 (Balance Eq.)

\(I_t = I_{t-1} + P_t - d_t\) — 엑셀에서는 **수식 셀**로 구현.

#### 제약 ⑤ 백오더 불허

\[
I_t \ge 0 \quad (t=1,\ldots,5)
\]

**인과:** 축구공과 동일. 수요 미충족 → 주문 잔고 발생 불허.

#### 제약 ⑥ 비음 조건

\[
H_t,\; F_t,\; O_t,\; P_t \ge 0 \quad (t=1,\ldots,5)
\]

#### 제약 정리표

| # | 제약 | 수식 | 개수 | 인과 |
|---|------|------|:---:|------|
| ① | 인원 수지 | \(W_t = W_{t-1}+H_t-F_t\) | 5 | 엑셀 수식 (Solver 제약 아님) |
| ② | 초과 상한 | \(O_t \le 20 W_t\) | 5 | 1인 20h 한도 |
| ③ | 생산 상한 | \(P_t \le 40 W_t + O_t/4\) | 5 | 총시간/4 = 능력 |
| ④ | 재고 수지 | \(I_t = I_{t-1}+P_t-d_t\) | 5 | 엑셀 수식 |
| ⑤ | 백오더 불허 | \(I_t \ge 0\) | 5 | 주문잔고 없음 |
| ⑥ | 비음 | \(H,F,O,P \ge 0\) | 20 | 물리적 제약 |

---

### 7.10 목적함수 — 6가지 비용 항목

축구공은 생산비+재고비 **2항**이었지만, 행복가구는 **6항**이다.

#### 월별 비용 분해

| 비용 항목 | 수식 | 단위(만원) | 인과 |
|-----------|------|:---:|------|
| **① 고용비** | \(170 \times H_t\) | 만원/명 × 명 | 새 인원 채용 비용 |
| **② 해고비** | \(210 \times F_t\) | 만원/명 × 명 | 인원 감축 비용 (고용비보다 비쌈!) |
| **③ 정규 임금** | \(150 \times W_t\) | 만원/명·월 × 명 | 월급. 인원 수에 비례 |
| **④ 초과 임금** | \(2 \times O_t\) | 만원/h × 시간 | 초과근무 수당 |
| **⑤ 재료비** | \(3 \times P_t\) | 만원/개 × 개 | 생산에 필수 |
| **⑥ 재고비** | \(2 \times I_t\) | 만원/개·월 × 개 | 보관 비용 |

> **해고비(210) > 고용비(170):** 해고가 더 비싸다. 따라서 "많이 뽑았다가 바로 자르기" 전략은 비용이 크다. LP는 이 비대칭을 반영해 **적정 인원을 유지**하는 쪽으로 최적화한다.

#### 5개월 총비용 (목적함수)

\[
\boxed{
\min\; Z = \sum_{t=1}^{5} \bigl(
170 H_t + 210 F_t + 150 W_t + 2 O_t + 3 P_t + 2 I_t
\bigr)
}
\]

> **축구공과의 비교:** 축구공은 \(\sum(c_t x_t + h_t y_t)\)로 2항. 행복가구는 6항 — **인력 관리 비용**이 3개(고용·해고·임금) 추가됨.

---

### 7.11 완전한 수리모형

\[
\boxed{
\begin{aligned}
\min\quad & Z = \sum_{t=1}^{5}\bigl(170 H_t + 210 F_t + 150 W_t + 2 O_t + 3 P_t + 2 I_t\bigr) \\[6pt]
\text{s.t.}\quad
& W_t = W_{t-1} + H_t - F_t \quad (t=1,\ldots,5;\; W_0=3) \quad\text{(인원 수지)} \\
& I_t = I_{t-1} + P_t - d_t \quad (t=1,\ldots,5;\; I_0=55) \quad\text{(재고 수지)} \\
& O_t \le 20\, W_t \quad (t=1,\ldots,5) \quad\text{(초과작업 상한)} \\
& P_t \le 40\, W_t + \tfrac{1}{4}\, O_t \quad (t=1,\ldots,5) \quad\text{(생산능력)} \\
& I_t \ge 0 \quad (t=1,\ldots,5) \quad\text{(백오더 불허)} \\
& H_t,\; F_t,\; O_t,\; P_t \ge 0 \quad (t=1,\ldots,5)
\end{aligned}
}
\]

### 7.12 Solver 설정 미리보기

| Solver 항목 | 설정 |
|-------------|------|
| **목적 셀** | 5개월 총비용 합 → **Min** |
| **변경 셀** | \(H_t, F_t, O_t, P_t\) (5×4 = **20개**) |
| **제약** | \(O_t \le 20 W_t\), \(P_t \le 40 W_t + O_t/4\), \(I_t \ge 0\), 비음 |
| **Balance Eq.** | \(W_t, I_t\)는 **수식 셀** — Solver 제약이 아님 |
| **해법** | 1차: **Simplex LP** (실수 최적) → 2차: **정수 제약** 추가 |

### 7.13 염두에 둘 것 — 예외 처리·주의사항

#### (1) 실수 해 → 정수 해

- LP를 먼저 풀면 "3.7명 고용" 같은 **비정수 해**가 나올 수 있다.
- 사람 수(H, F)는 현실적으로 **정수**여야 한다.
- **순서:** 먼저 **실수 최적(Simplex LP)** → 목적값 확인(슬라이드: **≈ 14,001**) → **정수 제약 추가** → 재실행(슬라이드: **≈ 14,065**).
- Solver 옵션에서 **정수 최적화 비율(허용한도) = 0%** 로 설정해야 정확한 정수 최적해를 얻는다.

#### (2) 같은 달에 고용과 해고 동시 발생?

- 수학적으로는 \(H_t > 0\), \(F_t > 0\)이 동시에 가능하지만, **비용만 낭비**(고용비 + 해고비 지출하면서 순증감 효과만 남음).
- LP 최적해에서는 **자동으로 한쪽만 양수**가 된다 — 별도 제약 불필요.
- 하지만 정수 해에서 간혹 동시에 나올 수 있으므로 결과를 **확인**할 것.

#### (3) 3월 수요(550) 대응 시나리오

- 1인당 월 최대 생산 = (160+20)/4 = **45개**.
- 550개를 만들려면 최소 \(\lceil 550/45 \rceil = 13\)명 필요 — 하지만 초기 재고(55개)가 있고, 1·2월에 미리 만들 수 있다.
- 따라서 **3월에 13명까지 늘릴 필요 없이**, 이전 달 재고 + 적정 인원으로 커버 가능.
- LP가 이 **인원 조정 vs 재고 비축 vs 초과작업** 트레이드오프를 최적화한다.

#### (4) 해고비(210) > 고용비(170)

- 인원을 "들쑥날쑥" 조절하면 고용+해고 비용이 크다.
- 특히 해고가 더 비싸므로, LP는 **가능한 한 안정적 인원 유지** + **초과작업으로 미세 조정**하는 경향.

#### (5) 단위 통일

모든 비용이 **만원** 단위. 목적함수의 Z도 만원. 슬라이드 최적값 14,001은 **14,001만원 ≈ 1억 4천만원**.

### 8.1 실습 #3 — 화물 적재·선박 밸런스 (완전 정식화)

#### 데이터

**화물:**

| Cargo | 무게(tons) | 부피(cu.ft/ton) | 이익($/ton) |
|:---:|:---:|:---:|:---:|
| A | 20 | 500 | 320 |
| B | 16 | 700 | 400 |
| C | 25 | 600 | 360 |
| D | 13 | 400 | 290 |

**선박 구역:**

| 위치 | 최대 허용 무게(tons) | 최대 허용 부피(cu.ft) |
|:---:|:---:|:---:|
| 앞(Front) | 12 | 7,000 |
| 중간(Mid) | 18 | 9,000 |
| 뒤(Rear) | 10 | 5,000 |

#### 결정변수 — 4×3 = 12개

\(x_{ij}\) = **화물 \(i\)를 구역 \(j\)에 싣는 톤수** (\(i \in \{A,B,C,D\},\; j \in \{F,M,R\}\))

| | 앞(F) | 중간(M) | 뒤(R) | 행합 = 화물별 적재량 |
|---|:---:|:---:|:---:|:---:|
| A | \(x_{AF}\) | \(x_{AM}\) | \(x_{AR}\) | ≤ 20 |
| B | \(x_{BF}\) | \(x_{BM}\) | \(x_{BR}\) | ≤ 16 |
| C | \(x_{CF}\) | \(x_{CM}\) | \(x_{CR}\) | ≤ 25 |
| D | \(x_{DF}\) | \(x_{DM}\) | \(x_{DR}\) | ≤ 13 |
| **열합** | ≤ 12 | ≤ 18 | ≤ 10 | |

#### 목적함수

이익은 화물 종류에만 의존(위치 무관):

\[
\max\; Z = 320\sum_j x_{Aj} + 400\sum_j x_{Bj} + 360\sum_j x_{Cj} + 290\sum_j x_{Dj}
\]

#### 제약

**(1) 화물 가용량** — 행합 ≤ 보유 톤수

\[
x_{AF}+x_{AM}+x_{AR} \le 20, \quad x_{BF}+x_{BM}+x_{BR} \le 16, \quad \ldots
\]

**(2) 구역 무게 상한** — 열합 ≤ 최대 허용 무게

\[
\sum_i x_{iF} \le 12, \quad \sum_i x_{iM} \le 18, \quad \sum_i x_{iR} \le 10
\]

**(3) 구역 부피 상한** — 부피/ton × 톤수의 합 ≤ 최대 부피

\[
500 x_{AF}+700 x_{BF}+600 x_{CF}+400 x_{DF} \le 7000 \quad \text{(앞)}
\]
\[
500 x_{AM}+700 x_{BM}+600 x_{CM}+400 x_{DM} \le 9000 \quad \text{(중간)}
\]
\[
500 x_{AR}+700 x_{BR}+600 x_{CR}+400 x_{DR} \le 5000 \quad \text{(뒤)}
\]

**(4) 밸런스 제약** — **핵심!**

"앞/중/뒤에 싣는 무게 대비 최대 허용 무게의 **비율이 모두 같아야** 한다."

\[
\frac{\sum_i x_{iF}}{12} = \frac{\sum_i x_{iM}}{18} = \frac{\sum_i x_{iR}}{10}
\]

등호 3개지만 **독립인 것은 2개:**

\[
18\cdot\sum_i x_{iF} = 12\cdot\sum_i x_{iM} \quad\Rightarrow\quad 3\sum_i x_{iF} - 2\sum_i x_{iM} = 0
\]
\[
10\cdot\sum_i x_{iM} = 18\cdot\sum_i x_{iR} \quad\Rightarrow\quad 5\sum_i x_{iM} - 9\sum_i x_{iR} = 0
\]

> **W사 품질 제약과의 비교:** W사는 "가중평균 ≥ 기준" → 분수→선형. 여기서는 "비율 = 비율" → 교차곱→선형 **등식**. 같은 "비율을 선형화" 기법이되 **부등식이 아니라 등식**이라는 점이 다르다.

**(5) 비음:** \(x_{ij} \ge 0\)

#### 완전한 수리모형

\[
\boxed{
\begin{aligned}
\max\quad & Z = 320\textstyle\sum_j x_{Aj} + 400\sum_j x_{Bj} + 360\sum_j x_{Cj} + 290\sum_j x_{Dj} \\[4pt]
\text{s.t.}\quad
& \textstyle\sum_j x_{ij} \le W_i \quad (i=A,B,C,D) \quad\text{(화물 가용)} \\
& \textstyle\sum_i x_{ij} \le C_j^w \quad (j=F,M,R) \quad\text{(구역 무게)} \\
& \textstyle\sum_i v_i\, x_{ij} \le C_j^v \quad (j=F,M,R) \quad\text{(구역 부피)} \\
& 3\textstyle\sum_i x_{iF} - 2\sum_i x_{iM} = 0 \quad\text{(밸런스 앞=중)} \\
& 5\textstyle\sum_i x_{iM} - 9\sum_i x_{iR} = 0 \quad\text{(밸런스 중=뒤)} \\
& x_{ij} \ge 0
\end{aligned}
}
\]

**답: 총이익 \$13,330**

## 10. 오늘의 핵심 정리 + 확인 질문

### 10.1 오늘 배운 핵심 7개

| # | 핵심 | 한 줄 요약 |
|---|------|-----------|
| 1 | **모형화의 세 층** | 의사결정변수(손잡이) · 목적함수(나침반) · 제약식(울타리) |
| 2 | **선형의 의미** | 한계효과 \(c_j, a_{ij}\)가 상수일 때 LP 구조가 닫힌다 |
| 3 | **Decora — 패턴이 변수** | 유한한 절단 패턴을 열거 → 각 패턴의 사용 횟수가 변수 |
| 4 | **Big M — 균형 운송** | 공급합=수요합 → 모든 제약이 등호(=); 독립 제약은 m+n−1개 |
| 5 | **Sellmore — 0-1 할당** | LP 완화로도 정수해 자동; 행합=열합=1 (겸임·공석 불가) |
| 6 | **W사 — 가중평균 선형화** | \(\frac{\sum g_k x_k}{\sum x_k} \ge G\) → \(\sum(g_k-G)x_k \ge 0\) |
| 7 | **동적 LP — Balance Equation** | \(y_t = y_{t-1} + \text{in} - \text{out}\); 기간 간 체인이 핵심 |

### 10.2 헷갈릴 수 있는 포인트 5개

1. **변수 vs 파라미터 구분:** "내가 정할 수 있는 양"만 변수. 이미 주어진 수요·용량·단가는 변수가 아니라 계수·우변.

2. **제약 부호의 인과:**
   - **≥** = "이 이상이어야" (Decora 수요, W사 품질)
   - **=** = "정확히" (Big M 공급/수요, Sellmore 배정)
   - **≤** = "이 이하로" (W사 자원, 축구공 용량)
   
   같은 구조라도 현실 제약의 **방향**이 달라지면 부호가 바뀐다.

3. **가중평균 선형화에서 분모 부호:** \(\sum x_k \ge 0\)이 보장될 때만 양변 곱이 유효. 생산량이 0이면 식이 \(0 \ge 0\)이 되어 자동 충족(공허 참).

4. **Balance Equation은 제약이 아니라 수식:** 엑셀에서 \(y_t\)를 수식 셀로 두면 Solver 변경 셀에 넣지 않아도 된다. 제약 조건으로는 \(y_t \ge 0\), \(y_t \le 10\)만 입력.

5. **단위 스케일:** W사의 2.7·3.5는 원/kg이 아니라 이미 스케일된 계수. 변수와 계수의 단위를 **맞추지 않으면** 목적값 자릿수가 엉망이 된다.

### 10.3 다음에 연결해서 보면 좋은 노드

1. **6강 — 심플렉스 해법:** 본 5강에서 만든 LP를 **표준형→정규형→타블로**로 푸는 알고리즘. 같은 Wyndor/식단 모형이 6강 실습 #1~#3에서 재등장.
2. **7강 — 쌍대·민감도:** W사 품질 제약의 **잠재가격**, 축구공 생산 상한의 **그림자가격** 해석. 5강의 모형이 그대로 쌍대 분석의 입력이 된다.

- **§1**에서 **목적함수·의사결정변수·제약**이 현실에서 **어떤 인과로 도출되는지**(손잡이·나침반·울타리, 한계효과·선형/비선형)를 먼저 고정하고 예제로 넘어간다.  
- CH.3에서 **같은 LP**라도 **문제 유형**(절단·운송·할당·혼합·다기간 재고·총괄계획)에 따라 **변수·제약의 의미**가 어떻게 달라지는지 익힌다.  
- **등급 혼합**, **재고 수지**, **고용 수지**처럼 **비율·동적 제약**을 **선형 부등식/등식**으로 바꾸는 연습을 한다.  
- 엑셀에서는 **문제별 시트 분리**와 **단위 통일**을 지킨다.
