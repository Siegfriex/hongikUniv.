# Part A. 1강 — 의사결정이란 · 기본 틀

## 1. 의사결정(Decision Making)이란

- **정의:** 여러 대안 중에서 하나를 선택하는 과정. 제한된 정보·자원·시간 안에서 **목표에 맞는 선택**을 하는 행위.
- **핵심:** “무엇을 할지”를 정하는 것 = **행동(action)** 을 고르는 것.

> 참고: [Decision theory - Wikipedia](https://en.wikipedia.org/wiki/Decision_theory)

## 2. 기본 용어 (행동 · 상태 · 결과)

| 용어 | 설명 |
|------|------|
| **행동(Action)** | 선택할 수 있는 옵션들. 예: A안, B안, “하지 않음” |
| **상태(State)** | 우리가 통제 못 하는 불확실한 요인. 예: 날씨, 수요, 경쟁자 행동 |
| **결과(Outcome)** | “어떤 행동 + 어떤 상태”가 만든 최종 결과 (이득/손실 등) |

- 의사결정 = **행동**을 정하는 것. **상태**는 나중에 확률로, **결과**는 숫자(돈, 점수, 효용)로 다룸.

## 3. 간단 예제: 외출 시 우산 챙기기

- **행동:** 우산 챙김 / 안 챙김  
- **상태:** 비 옴 / 비 안 옴  
- **결과:** 챙기고 비 옴→편함, 챙기고 비 안 옴→가방 무거움, 안 챙기고 비 옴→젖음, 안 챙기고 비 안 옴→가벼움  
- “비 올 확률”에 따라 챙길지/안 챙길지가 달라짐 → 이후 확률·기대값·유틸리티로 이어짐.

# Part B. OR / 경영과학 정의 · 시스템 · 수리모형

## 1. OR / MS 정의 (웹·교재 통합)

| 용어 | 정의 |
|------|------|
| **Operations Research (OR)** | 의사결정에 대한 **과학적 접근**. 수학적 모형으로 복잡한 시스템을 **설계·개선·운영**하는 연구. |
| **Management Science (MS)** | 수학적 모형·통계·알고리즘으로 **의사결정 지원**, 성과 **개선·최적화**. |
| **경영과학 정의** | **시스템의 설계와 운영 과정에서 발생하는 경영문제**를 종합적으로 **모형화**하고, 체계적으로 **분석**하여 **의사결정**하는 **과학**이며, **최적의 해**를 찾는 **기법과 도구**. |

> 참고: [Operations research - Wikipedia](https://en.wikipedia.org/wiki/Operations_research), [Britannica - OR History](https://www.britannica.com/topic/operations-research/History)

## 2. 시스템 (System)

- **정의:** 공동의 목표를 달성하기 위해 **유기적으로 작용하는 구성요소들의 조직체**.
- **예:** 생산공장, 창고, 공항, 선박 제조, 플랜트, 투자회사, 병원, 도서관 등.
- **OR vs MS:** 시스템 **운영(Operations)** → OR · 시스템 **관리(Management)** → MS.

## 3. 수리모형의 기본 요소

| 요소 | 설명 |
|------|------|
| **결정변수 (Decision variables)** | 의사결정자가 정하는 값 (예: 생산량 \(Q\), 주문량). |
| **파라미터 (Parameters)** | 문제에서 **고정된 상수** (단가, 고정비, 수요량, 자원 한도). **변하지 않는 것**. |
| **목적함수 (Objective function)** | 최대화 또는 최소화할 식 (이익, 비용, 시간 등). |
| **제약식 (Constraints)** | 결정변수가 만족해야 하는 제한. |

### 선형 vs 비선형

- **선형:** 목적함수·제약식이 **1차항만** (예: \(c_1 x_1 + c_2 x_2\)). → **선형계획(LP)**, 심플렉스법.
- **비선형:** **제곱, 루트, 곱(\(xy\)), 지수·로그** 등이 **하나라도** 있으면 비선형. → **비선형계획(NLP)**.

## 4. 확정적 vs 확률적 모형

| 구분 | 디터미니스틱 (Deterministic) | 스토캐스틱 (Stochastic) |
|------|------------------------------|---------------------------|
| **파라미터** | 시간·가격·수요 등 **고정값**. | 일부 **확률변수**. |
| **결과** | 같은 입력 → 같은 해. | 기대값·분포로 다룸. |
| **예** | EOQ, LP, 손익분기. | 재고(수요 확률), 대기행렬, 의사결정(확률). |

- 수업에서는 **각각 별도**로 다룸.

> 참고: [Stochastic programming - Wikipedia](https://en.wikipedia.org/wiki/Stochastic_programming)

# Part C. 트레이드오프 · EOQ · OR 역사

## 1. 트레이드오프와 재고·EOQ

- **트레이드오프:** 목표와 직결된 **상충 관계**. 제고·스케줄·재고관리 등 대부분의 경영 선택이 트레이드오프.
- **재고관리:** 자주 주문(소량) → 주문비용 ↑·재고비용 ↓ / 가끔 주문(대량) → 주문비용 ↓·재고비용 ↑.
- **해리스 경제적 주문량(EOQ) (1915년 경):** 주문비용과 재고비용을 **함께 고려**해, 한 번에 몇 개씩 주문하면 **전체 기간 비용을 최소화**할 수 있는가? → 상충비용 균형의 **최적 주문량**.

> 참고: [Ford W. Harris - Wikipedia](https://en.wikipedia.org/wiki/Ford_Whitman_Harris), [Harris EOQ 1915 - JSTOR](https://www.jstor.org/stable/2632315)

## 2. OR 역사 (웹 그라운딩)

| 시기 | 내용 |
|------|------|
| **1915년 경** | Harris, 웨스팅하우스 — EOQ. 재고관리. |
| **1917년** | Erlang — 자동전화교환 대기·확률 → 대기행렬 모형. |
| **2차대전** | 영국/미국 OR팀 — U보트 격침, 미드웨이, 암호·작전 최적화. **최적해·효율** 비약적 발전. |
| **1947년** | **Dantzig**, 심플렉스 해법 — LP 해법. “선형계획의 아버지”. |
| **1970년대~** | 컴퓨터 — LP 대규모화, 시뮬레이션, MIS·DSS, 데이터마이닝·AI. |

> 참고: [Britannica - OR History](https://www.britannica.com/topic/operations-research/History), [INFORMS - Dantzig](https://www.informs.org/Explore/History-of-O.R.-Excellence/Biographical-Profiles/Dantzig-George-B)

## 3. 심플렉스 방법 (Simplex Method)

- **정의:** **선형계획(LP) 문제의 해법(알고리즘)**.
- **역할:** 목적함수·제약식이 모두 선형일 때 **최적해**를 유한 단계에 찾는 수치적 방법.
- **특징:** 가능해 영역의 **꼭짓점**을 따라 이동, Tableau·pivot으로 손계산 가능.

# Part E. CH.1 도입 · OR 절차 · 손익분기 예제

## 1. OR 연구 절차 (6단계)

1. 문제 정의 및 데이터 수집  
2. **수리모형 수립** — 결정변수, 목적함수, 제약식, 파라미터  
3. **해법 개발** — 선형/정수/비선형, 확정/확률  
4. 모형 검증  
5. 지속 적용 준비  
6. 구현  

## 2. Special Products Co. 손익분기 (요약)

- **결정변수:** \(Q\) = iWatch 생산량  
- **비용:** 고정비 $10M, 단위 변동비 $1,000 → 총비용 = $10M + $1{,}000 Q  
- **매출:** 단위 $2,000, 생산=판매 가정 → 이익 = \(-10{,}000{,}000 + 1{,}000Q\)  
- **손익분기점:** \(Q^* = 10{,}000\). 수요 30,000이면 \(Q=30{,}000\) 시 이익 $20M → **생산 권장.**

# Part F. Week 1 연습문제 풀이 (Toys R4U)

**조건:** 고정비 $500,000, 단위 변동비 $15, 단위 매출 $35, 생산=판매.

**a) 이익 식 및 손익분기점**

- 이익: \(P = 35Q - (500{,}000 + 15Q) = 20Q - 500{,}000\)  
- 손익분기: \(P=0 \Rightarrow Q = 25{,}000\)  
- **손익분기점 25,000개 초과** 시 도입 유리.

**b) 25,000개 생산 시 이익**

- \(P = 20 \times 25{,}000 - 500{,}000 = 0\) → **$0** (손익분기점).

*(엑셀 제출 시 해당 답 셀에 색 표시.)*
