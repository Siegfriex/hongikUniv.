# Decision Making · 1차시 1강

**일자:** 2025-03-09  
**주제:** 의사결정이란 무엇인가 · 기본 틀과 용어

---

## 1. 의사결정(Decision Making)이란

- **정의:** 여러 대안 중에서 하나를 선택하는 과정.  
  제한된 정보·자원·시간 안에서 **목표에 맞는 선택**을 하는 행위.
- **핵심:** “무엇을 할지”를 정하는 것 = **행동(action)** 을 고르는 것.

> 참고: [Decision theory - Wikipedia](https://en.wikipedia.org/wiki/Decision_theory)

---

## 2. 이번 강에서 쓸 기본 용어 (2~3개 개념)

| 용어 | 설명 |
|------|------|
| **행동(Action)** | 선택할 수 있는 옵션들. 예: A안, B안, “하지 않음” |
| **상태(State)** | 우리가 통제 못 하는 불확실한 요인. 예: 날씨, 수요, 경쟁자 행동 |
| **결과(Outcome)** | “어떤 행동 + 어떤 상태”가 만든 최종 결과 (이득/손실 등) |

- 의사결정 = **행동**을 정하는 것.  
  **상태**는 나중에 확률로 다루고, **결과**는 보통 숫자(돈, 점수, 효용)로 나타낸다.

---

## 3. 간단 예제: 외출 시 우산 챙기기

- **행동:** 우산 챙김 / 안 챙김  
- **상태:** 비 옴 / 비 안 옴  
- **결과(느낌):**  
  - 챙기고 비 옴 → 편함  
  - 챙기고 비 안 옴 → 가방만 무거움  
  - 안 챙기고 비 옴 → 젖음  
  - 안 챙기고 비 안 옴 → 가벼움  

→ “비 올 확률”을 어떻게 보느냐에 따라 **챙길지/안 챙길지**가 달라짐.  
  (다음 시간부터 확률·기대값·유틸리티로 이어짐.)

---

## 4. 오늘 정리

- 의사결정 = **행동** 선택.
- **행동 · 상태 · 결과** 세 가지를 구분해서 보는 것이 기본 틀.
- 다음 강의: 확률, 기대값, 유틸리티로 “어떤 행동이 이성적인가”를 다룸.
