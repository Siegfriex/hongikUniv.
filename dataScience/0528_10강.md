## 인텔리전스 브리핑

오늘 0528 세션의 중심은 **머신러닝을 데이터사이언스의 예측 엔진으로 이해하는 것**이다. 9강까지는 데이터를 어떻게 보고, 시각화하고, R/Python으로 처리할 수 있는지를 다뤘다. 10강은 그 다음 단계다. 데이터를 사람이 해석하는 수준을 넘어, 컴퓨터가 데이터 안의 패턴을 학습하고 새 데이터에 대해 예측·분류·판단을 수행하게 만드는 방법을 정리한다.

강의 흐름은 크게 두 부분이다.

첫째, Part 1은 머신러닝의 기본 구도를 잡는다. 지도학습, 비지도학습, 강화학습을 구분하고, 지도학습 안에서 출력값의 성격에 따라 **회귀(regression)**와 **분류(classification)**가 어떻게 갈라지는지 본다. 회귀에서는 선형회귀, 최소제곱법, 결정계수, 이상치와 다중공선성을 다루고, 분류에서는 로지스틱 회귀와 혼동행렬을 통해 모델 성능을 평가한다.

둘째, Part 2는 대표 알고리즘을 넓게 훑는다. **SVM**은 마진을 최대화하는 분류 경계, **k-NN**은 가까운 이웃의 투표, **의사결정나무**는 질문 기반 분기와 불순도 감소, **앙상블/Random Forest**는 여러 약한 모델의 결합, **인공신경망**은 가중합과 활성함수로 입력을 출력에 연결하는 구조를 설명한다.

한 줄로 압축하면 다음이다.

```text
데이터의 패턴을 학습한다
→ 출력값의 형태에 따라 회귀/분류 문제로 구분한다
→ 모델이 좋은지 손실·정확도·혼동행렬 등으로 평가한다
→ 데이터 구조와 목적에 맞는 알고리즘을 선택한다
```

오늘의 본질은 알고리즘 이름 암기가 아니라 **문제 유형, 모델 학습, 평가 기준, 알고리즘 선택 논리**를 연결하는 것이다.

## 3. 머신러닝의 기본 정의와 학습 유형

### 3.1 한 줄 정의

머신러닝은 데이터 안의 패턴을 자동으로 탐지하고, 그 패턴을 이용해 미래 데이터 예측이나 불확실한 상황의 의사결정을 수행하는 방법들의 집합이다.

### 3.2 세 가지 학습 유형

| 유형 | 데이터 구성 | 핵심 질문 | 예시 |
|------|-------------|-----------|------|
| 지도학습 | 입력 `X`와 정답 `Y`가 함께 있음 | 새 `X`가 들어오면 `Y`를 어떻게 예측할까? | 스팸/정상 메일 분류, 강수량 예측, 전력 사용량 예측 |
| 비지도학습 | 입력 `X`만 있음 | 데이터 안에 어떤 패턴이나 그룹이 숨어 있는가? | 고객 군집, 문서 군집, 차원 축소 |
| 강화학습 | 상태, 행동, 보상 | 어떤 행동을 선택해야 누적 보상이 커지는가? | 게임 AI, 로봇 제어, 동적 의사결정 |

오늘 PDF는 지도학습을 중심으로 전개된다. 특히 회귀와 분류를 구분하고, 여러 분류 알고리즘을 비교한다.

### 3.3 텍스트 마이닝과 지도학습

7강의 텍스트 마이닝과도 연결된다. 문서는 그대로 모델에 들어가지 않는다. 문서를 Bag-of-Words, Doc2Vec 같은 수치형 벡터로 바꾸고, 각 문서에 스팸/정상 같은 label이 붙어 있으면 지도학습 분류 문제가 된다.

```text
문서 원문
→ 수치형 벡터
→ label과 함께 학습
→ 새 문서의 class 예측
```

## 4. 지도학습: 회귀와 분류의 구분

지도학습은 정답이 있는 데이터를 학습한다. 이때 정답 `Y`의 형태가 모델 문제를 나눈다.

| 구분 | 출력 `Y` | 문제 성격 | 예시 |
|------|----------|-----------|------|
| 회귀 / 예측 | 연속형, 실수값 | 값을 예측 | 내일 KOSPI 200 종가, 강수량, 5일 뒤 전력 사용량 |
| 분류 | 이산형, 범주형 | class를 선택 | 제품 품질 정상/불량, 메일 정상/스팸 |

시험에서 가장 흔한 실수는 “예측”이라는 말을 모두 회귀로 보는 것이다. 분류도 넓게 보면 새 데이터의 class를 예측하지만, 출력값이 범주형이면 분류다. 반대로 출력값이 숫자 자체이면 회귀다.

## 5. 모델 학습의 의미: 성능, 손실, 가중치

머신러닝 모델 학습은 모델을 구성하는 파라미터를 데이터에 맞게 정하는 과정이다. 예를 들어 다음과 같은 모델이 있다고 하자.

```text
y = a*x1 + b*x2 + c*x3
```

여기서 학습은 `a`, `b`, `c` 값을 아무렇게나 정하는 것이 아니라, 모델 성능이 높아지도록 또는 손실이 낮아지도록 찾는 과정이다.

| 개념 | 의미 |
|------|------|
| 성능 | 모델이 문제를 얼마나 잘 맞히는가 |
| 손실 / 오류 | 실제값과 예측값 사이의 차이 |
| 가중치 | 입력 변수가 결과에 미치는 정도를 모델 안에서 표현한 값 |
| 학습 | 성능을 최대화하거나 손실을 최소화하는 가중치·규칙·경계를 찾는 과정 |

핵심 관계:

```text
좋은 모델 = 높은 성능 = 낮은 손실 = 일반화 가능한 패턴
```

## 6. 회귀분석: 관계 설명과 연속값 예측

### 6.1 회귀분석의 출발점

회귀분석은 변수들 사이의 관계를 추정하는 분석방법이다. 원래 회귀라는 표현은 부모와 자식의 키 관계에서 평균으로 되돌아가는 경향을 설명한 Galton의 연구에서 출발했다. 데이터사이언스 관점에서는 변수 간 경향성을 설명하고, 한 변수로 다른 변수를 예측하는 데 사용한다.

### 6.2 상관분석과 회귀분석의 차이

| 구분 | 질문 | 결과 |
|------|------|------|
| 상관분석 | 두 변수 사이에 선형적 관련성이 있는가? | 관련성의 강도와 방향 |
| 회귀분석 | 한 변수를 다른 변수로 설명하거나 예측할 수 있는가? | 직선 또는 함수 형태의 예측식 |

상관분석이 “같이 움직이는가”를 보는 단계라면, 회귀분석은 그 관계를 식으로 표현해 예측에 사용하는 단계다.

### 6.3 선형회귀

선형회귀는 독립변수 `X`와 종속변수 `Y` 사이의 관계를 직선으로 표현한다.

| 유형 | 독립변수 수 | 예 |
|------|-------------|----|
| 단순선형회귀 | 1개 | 키로 몸무게 예측 |
| 다중선형회귀 | 2개 이상 | 부모 키, 영양, 운동량으로 자녀 키 예측 |

목적은 두 가지다.

- 변수 사이 관계를 수치로 설명한다.
- 미래의 종속변수 값을 예측한다.

### 6.4 선형회귀의 주요 가정

| 가정 | 의미 |
|------|------|
| 선형성 | 독립변수와 종속변수 사이 관계가 직선으로 근사 가능해야 한다. |
| 독립변수 측정 | 독립변수는 정확히 측정된 값으로 취급한다. |
| 오차 정규성·등분산성 | 오차는 평균 0, 일정한 분산을 가진다고 본다. |
| 오차 독립성 | 오차들끼리는 서로 독립이어야 한다. |
| 낮은 다중공선성 | 독립변수들끼리 너무 강하게 겹치면 계수 해석이 불안정해진다. |

### 6.5 다중공선성

다중공선성은 독립변수들끼리 강한 선형관계를 갖는 현상이다. 예를 들어 `아빠 키`, `엄마 키`, `부모 평균 키`를 동시에 넣으면 세 변수는 서로 강하게 관련된다. 이 경우 데이터가 조금만 바뀌어도 회귀계수가 크게 달라질 수 있고, 각 변수의 고유한 효과를 분리하기 어렵다.

VIF는 다중공선성을 진단하는 대표 지표다. 일반적으로 VIF가 5 이상이면 주의, 10 이상이면 심각한 다중공선성으로 본다.

### 6.6 잔차와 최소제곱법

잔차는 실제 관측값과 회귀모델 예측값의 차이다.

```text
잔차 = 실제값 - 예측값
```

최소제곱법은 잔차를 제곱해 모두 더한 값이 가장 작아지는 직선을 찾는다.

```text
좋은 회귀선 = 잔차제곱합이 가장 작은 선
```

왜 제곱을 쓰는가?

- 양수/음수 오차가 서로 상쇄되는 문제를 막는다.
- 큰 오차에 더 큰 벌점을 준다.
- 계산 가능한 최적화 문제로 만들 수 있다.

### 6.7 SST, SSR, SSE

회귀모델의 설명력은 전체 변동을 어떻게 나누는지로 이해한다.

| 지표 | 의미 |
|------|------|
| SST | 전체 변동량. 실제 관측값이 평균에서 얼마나 떨어져 있는가 |
| SSR | 회귀로 설명된 변동량. 모델 예측값이 평균에서 얼마나 벗어나는가 |
| SSE | 설명하지 못한 오차 변동량. 실제값과 예측값의 차이 |

관계식:

```text
SST = SSR + SSE
전체 변동 = 모델이 설명한 변동 + 설명하지 못한 오차
```

### 6.8 결정계수 R²

결정계수 `R²`는 전체 변동 중 회귀모델이 설명한 비율이다.

```text
R² = SSR / SST
```

| 값 | 해석 |
|----|------|
| 1에 가까움 | 모델이 데이터 변동을 잘 설명 |
| 0에 가까움 | 모델이 변수 간 관계를 거의 설명하지 못함 |

주의할 점은 `R²`가 높다고 항상 좋은 모델이라는 뜻은 아니라는 것이다. 불필요한 변수를 많이 넣거나 이상치에 맞춰진 경우에는 해석과 일반화가 나빠질 수 있다.

### 6.9 이상치의 영향

회귀분석은 전체 오차를 최소화하기 때문에 멀리 떨어진 이상치에 민감하다. 하나의 이상치만 추가되어도 회귀선의 기울기와 절편이 크게 달라질 수 있다. 따라서 회귀모델을 해석할 때는 산점도와 잔차를 함께 확인해야 한다.

## 7. 로지스틱 회귀: 확률로 분류하기

### 7.1 왜 선형회귀로 분류하면 안 되는가

분류 문제의 출력은 범주형이다. 예를 들어 스팸이면 1, 정상 메일이면 0이다. 그런데 선형회귀의 출력은 `-∞`에서 `∞`까지 아무 실수나 될 수 있다. 따라서 선형회귀를 그대로 분류에 쓰면 다음 문제가 생긴다.

- 0보다 작거나 1보다 큰 값이 나올 수 있다.
- class가 여러 개인 경우 해석이 어렵다.
- 확률로 해석하기 어렵다.

### 7.2 로지스틱 회귀의 아이디어

로지스틱 회귀는 어떤 데이터가 class 1에 속할 확률 `p`를 예측한다. 이 확률은 0과 1 사이에 있어야 한다. 그래서 확률 `p`를 odds와 logit으로 변환해 선형모델과 연결한다.

```text
p = class 1에 속할 확률
odds = p / (1 - p)
logit = log(odds)
```

핵심은 다음이다.

```text
선형모델의 출력
→ logit
→ 0과 1 사이의 확률 p
→ threshold 기준으로 class 결정
```

### 7.3 모델 학습과 likelihood 직관

로지스틱 회귀도 가중치를 학습한다. 좋은 모델은 실제 class가 1인 데이터에는 높은 `p`를 주고, 실제 class가 0인 데이터에는 높은 `1-p`를 준다. 슬라이드의 비교처럼 실제 정답에 해당하는 확률들의 곱이 큰 모델이 더 좋은 모델이라는 직관을 갖는다.

즉 로지스틱 회귀의 학습은 다음과 같이 이해할 수 있다.

```text
실제 정답이 나온 확률을 크게 만드는 가중치를 찾는다
```

### 7.4 이진분류와 다중분류

로지스틱 회귀는 기본적으로 이진분류에서 출발하지만, 여러 class를 분류하는 다중분류로 확장할 수 있다. 중요한 것은 여전히 class별 확률을 계산하고, 가장 적절한 class를 선택한다는 점이다.

## 8. 분류 모델 평가: Confusion Matrix

혼동행렬은 실제 class와 모델 예측 class를 비교하는 표다. 분류 모델의 성능을 단순 정확도보다 자세히 볼 수 있다.

| 구분 | 의미 |
|------|------|
| TP | 실제 positive를 positive로 맞힘 |
| TN | 실제 negative를 negative로 맞힘 |
| FP | 실제 negative를 positive로 잘못 예측 |
| FN | 실제 positive를 negative로 잘못 예측 |

여기서 다음 지표가 나온다.

| 지표 | 질문 | 해석 |
|------|------|------|
| Accuracy | 전체 중 얼마나 맞혔는가? | 클래스 비율이 균형적일 때 직관적 |
| Precision | positive라고 한 것 중 진짜 positive는 얼마인가? | 오탐을 줄이는 데 중요 |
| Recall | 실제 positive 중 얼마나 찾아냈는가? | 놓치면 큰 비용이 드는 문제에서 중요 |
| F1-score | precision과 recall의 균형은 어떤가? | 불균형 데이터에서 유용 |

시험 포인트:

> 분류 모델 평가는 “몇 개 맞혔는가”에서 끝나지 않는다. 어떤 오류가 더 위험한지에 따라 precision, recall, F1을 함께 봐야 한다.

## 9. SVM: 마진을 최대화하는 분류 경계

### 9.1 기본 정의

Support Vector Machine은 주어진 데이터가 어느 범주에 속할지 판단하는 이진 선형 분류 모델로 소개된다. 핵심은 두 class를 나누는 여러 초평면 중에서 **마진이 가장 큰 결정경계**를 찾는 것이다.

### 9.2 마진과 서포트 벡터

| 개념 | 의미 |
|------|------|
| 결정경계 | 두 class를 나누는 선 또는 초평면 |
| 마진 | 결정경계와 가장 가까운 데이터 points 사이의 거리 |
| 서포트 벡터 | 마진 결정에 영향을 주는, 경계에 가장 가까운 관측치 |

SVM은 단순히 훈련데이터를 맞히는 선을 찾지 않는다. 새 데이터에도 안정적으로 작동할 가능성이 높은 경계를 찾기 위해 마진을 최대화한다.

### 9.3 선형 SVM과 비선형 SVM

데이터가 선형으로 나뉘면 직선이나 초평면으로 분류할 수 있다. 하지만 현실 데이터는 비선형 경계를 갖는 경우가 많다. 이때 kernel 함수를 사용해 입력 벡터를 고차원 공간으로 사상하고, 그 공간에서 선형 분리가 가능하도록 만든다.

```text
낮은 차원에서 비선형
→ kernel mapping
→ 높은 차원에서 선형 분리
```

### 9.4 장점과 단점

| 장점 | 단점 |
|------|------|
| 수치형·범주형 예측 문제에 사용 가능 | 데이터 양이 커지면 학습 계산량이 커짐 |
| 추론이 빠름 | outlier에 민감함 |
| 고차원 데이터에도 잘 작동 | class 수가 많아질수록 복잡도 증가 |
| 마진 개념으로 일반화 직관이 명확 | kernel 선택이 쉽지 않음 |

## 10. k-NN: 가까운 이웃으로 판단하기

### 10.1 기본 정의

k-nearest neighbor는 새 데이터와 가장 가까운 `k`개의 과거 자료를 찾아 그 결과로 새 데이터를 분류하거나 예측하는 지도학습 알고리즘이다.

분류에서는 가까운 이웃의 다수결로 class를 정한다.

```text
새 관측치
→ 거리 계산
→ 가까운 k개 선택
→ 다수결 또는 거리 가중 투표
→ class 결정
```

### 10.2 lazy learning

k-NN은 별도의 학습 모델을 미리 만들기보다 데이터를 저장해 두고, 새 데이터가 들어올 때마다 전체 데이터와 거리를 비교한다. 그래서 instance-based learning 또는 lazy learning으로 볼 수 있다.

장점은 직관적이라는 점이고, 단점은 예측할 때마다 계산량이 크다는 점이다.

### 10.3 거리와 scaling

k-NN은 거리 기반 알고리즘이므로 변수 scale에 민감하다. 예를 들어 소득 10원 차이와 나이 10살 차이를 같은 10으로 보면 잘못된 거리 계산이 된다. 따라서 표준화나 정규화가 중요하다.

사용 가능한 거리:

- Euclidean distance
- Manhattan distance
- Minkowski distance
- Correlation distance

### 10.4 k 선택

| k 값 | 효과 | 위험 |
|------|------|------|
| 작음 | 국소 패턴을 민감하게 반영 | 이상치 영향이 커져 overfitting 가능 |
| 큼 | 더 부드러운 경계 | 세밀한 구조를 놓쳐 underfitting 가능 |

일반적으로 k는 동률 문제를 피하기 위해 홀수를 자주 사용하고, 최적 k는 cross validation으로 찾는다.

### 10.5 majority voting의 한계와 거리 가중 투표

기본 k-NN은 다수 class에 영향을 크게 받는다. 데이터가 불균형하면 다수 class로 예측되기 쉽다. 이를 보완하기 위해 가까운 이웃에 더 큰 가중치를 주는 distance-weighted voting을 사용할 수 있다.

## 11. 의사결정나무: 질문으로 데이터를 나누는 모델

### 11.1 기본 정의

의사결정나무는 예/아니오 질문을 반복하며 데이터를 나누는 지도학습 알고리즘이다. 나무 구조의 규칙으로 전체 자료를 소집단으로 분류하거나 값을 예측한다.

| 구성 | 의미 |
|------|------|
| root node | 전체 데이터가 들어가는 최상위 마디 |
| parent node | 하위 마디로 분기되는 상위 마디 |
| child node | 분기 후 생성되는 하위 마디 |
| terminal / leaf node | 더 이상 분기되지 않는 최종 마디 |
| split | 데이터를 나누는 가지분할 |
| pruning | 불필요한 가지를 잘라 모델을 단순화 |

### 11.2 분류나무와 회귀나무

| 유형 | 목표변수 | 목적 |
|------|----------|------|
| 분류나무 | 범주형 | class 분류 |
| 회귀나무 | 연속형 | 수치 예측 |

의사결정나무는 분류와 회귀 모두에 사용할 수 있다. 특히 비선형 관계나 변수 간 상호작용을 조건 분기로 표현할 수 있어, 선형모델이 어려워하는 패턴을 잡을 수 있다.

### 11.3 불순도

의사결정나무에서 중요한 질문은 “어떤 변수와 기준값으로 나눌 것인가?”이다. 기준은 불순도다.

| 상태 | 의미 |
|------|------|
| 불순도 높음 | 한 노드 안에 여러 class가 섞여 있음 |
| 불순도 낮음 | 한 노드 안에 같은 class가 많이 모여 있음 |

좋은 split은 자식 노드의 불순도를 낮추는 split이다. 즉, 노드 안에서는 동질성이 커지고 노드 간에는 이질성이 커지도록 나누는 것이다.

### 11.4 Gini Index

Gini Index는 분류나무에서 많이 쓰는 불순도 지표다. 값이 0에 가까울수록 잘 분리된 상태이고, 0.5에 가까울수록 class가 섞여 있어 좋지 않은 상태다.

```text
좋은 분기 기준 = split 후 Gini Index가 낮아지는 기준
```

### 11.5 가지치기

트리가 깊어질수록 훈련데이터는 잘 맞힐 수 있지만, 일정 수준을 넘으면 새 데이터에 대한 오분류율이 증가할 수 있다. 이를 과적합이라고 한다. 가지치기는 이런 불필요한 분기를 제거하거나 합쳐서 모델을 단순화하는 과정이다.

중요한 해석:

> 가지치기는 데이터를 버리는 것이 아니라, 과하게 세분화된 규칙을 합쳐 일반화 성능을 높이는 작업이다.

### 11.6 장점과 단점

| 장점 | 단점 |
|------|------|
| 분류와 회귀 모두 가능 | 데이터가 조금만 바뀌어도 구조가 크게 바뀔 수 있음 |
| 결과를 조건 규칙으로 설명 가능 | 트리가 깊어지면 과적합 발생 |
| 선형성·정규성·다중공선성 가정이 거의 없음 | 연속형 예측은 계단형으로 나타날 수 있음 |
| 수치형·범주형 변수 모두 사용 가능 | 트리가 커지면 오히려 해석이 어려움 |
| 비선형 관계와 상호작용 반영 | 경계 근처 예측이 불안정할 수 있음 |

## 12. 앙상블과 Random Forest

### 12.1 앙상블의 기본 아이디어

앙상블은 여러 개의 학습 모델을 결합해 하나의 모델보다 안정적이고 정확한 예측을 수행하는 방법이다.

```text
여러 weak model
→ 각자 예측
→ 투표 또는 평균
→ 최종 예측
```

핵심은 한 모델의 편향이나 불안정성을 여러 모델의 조합으로 완화하는 것이다.

### 12.2 Bagging

Bagging은 Bootstrap Aggregating의 줄임말이다. 원 데이터에서 복원 랜덤 샘플링으로 여러 표본을 만들고, 각 표본에 모델을 학습시킨 뒤 결과를 집계한다.

| 문제 유형 | 집계 방식 |
|-----------|-----------|
| 분류 | 투표 |
| 회귀 | 평균 |

Bagging은 여러 모델의 예측을 평균화하므로 variance를 줄이고 overfitting을 완화하는 효과가 있다.

### 12.3 Boosting

Boosting은 약한 분류기를 순차적으로 학습시키며, 이전 모델이 틀린 데이터에 더 높은 가중치를 부여한다. 오답에 집중하므로 정확도를 높일 수 있지만, outlier에 민감해질 수 있다.

대표 알고리즘:

- AdaBoost
- Gradient Boosting
- XGBoost

### 12.4 Bagging vs Boosting

| 구분 | Bagging | Boosting |
|------|---------|----------|
| 학습 방식 | 병렬적 | 순차적 |
| 핵심 | 복원 샘플링 후 결과 집계 | 오답에 가중치를 주며 보완 |
| 주효과 | variance 감소, 과적합 완화 | bias 감소, 성능 향상 |
| 취약점 | 계산량 증가 | outlier에 민감 |
| 사용 직관 | 개별 나무가 과대적합이면 bagging | 개별 나무 성능이 낮으면 boosting |

### 12.5 Random Forest

Random Forest는 의사결정나무와 bagging을 결합한 앙상블 알고리즘이다. 여러 개의 의사결정나무를 만들고, 분류에서는 투표를 통해 최종 class를 정한다.

특징:

- 관측치를 복원 추출해 각 나무를 학습한다.
- split 기준을 찾을 때 전체 변수가 아니라 일부 변수만 후보로 사용한다.
- 일부 나무가 과적합되어도 다수 나무의 집계로 영향이 줄어든다.

| 장점 | 단점 |
|------|------|
| 일반 의사결정나무보다 과적합 경향이 낮음 | 많은 컴퓨팅 연산 필요 |
| 고차원 데이터에도 잘 작동 | 모델 구조가 복잡해 해석이 어려울 수 있음 |
| 전처리를 상대적으로 덜 요구 | 단일 나무보다 직관적 설명력은 낮음 |
| 비교적 좋은 성능 | 실행마다 결과가 조금씩 달라질 수 있음 |

## 13. 인공신경망과 MLP

### 13.1 생물학적 직관

인공신경망은 인간 두뇌의 뉴런과 시냅스 구조에서 아이디어를 얻은 모델이다. 생물학적 뉴런은 여러 입력 자극을 받아 종합하고, 일정 임계값 이상이면 다음 뉴런으로 신호를 전달한다. 인공신경망은 이 과정을 수식적으로 모형화한다.

### 13.2 퍼셉트론

퍼셉트론은 뉴런을 모방한 기본 단위다.

```text
입력 x
→ 각 입력에 가중치 w 부여
→ 가중합 계산
→ 활성함수 적용
→ 출력 전달
```

| 구성 | 의미 |
|------|------|
| node | 뉴런에 해당하는 계산 단위 |
| weight | 입력 신호의 중요도 |
| bias | 기준점을 조정하는 상수 |
| activation function | 가중합을 출력 신호로 바꾸는 함수 |

### 13.3 MLP

Multi-Layer Perceptron은 입력층, 은닉층, 출력층으로 구성된다.

| 층 | 역할 |
|----|------|
| 입력층 | 입력값을 받음 |
| 은닉층 | 입력층에서 넘어온 데이터를 처리하고 변환 |
| 출력층 | 최종 결과값 또는 class 확률 계산 |

단층 퍼셉트론은 표현력이 제한적이지만, 은닉층을 가진 MLP는 더 복잡한 비선형 패턴을 표현할 수 있다.

## 14. 알고리즘 선택 매트릭스

| 알고리즘 | 주 문제 | 핵심 아이디어 | 강점 | 주의점 |
|----------|---------|---------------|------|--------|
| 선형회귀 | 회귀 | 직선으로 연속값 예측 | 해석 쉬움, 기본 모델 | 선형성·이상치·다중공선성 주의 |
| 로지스틱 회귀 | 분류 | class 1 확률 예측 | 확률 해석 가능 | 선형 결정경계 한계 |
| SVM | 분류 | 마진 최대화 | 고차원 데이터에 강함 | scale, outlier, kernel 선택 |
| k-NN | 분류/회귀 | 가까운 이웃의 투표·평균 | 직관적, 구현 쉬움 | 계산량, scale, k 선택 |
| 의사결정나무 | 분류/회귀 | 질문으로 데이터 분기 | 설명력, 비선형 처리 | 과적합과 불안정성 |
| Random Forest | 분류/회귀 | 여러 나무의 투표·평균 | 안정적, 과적합 완화 | 계산량과 해석력 저하 |
| Boosting | 분류/회귀 | 오답에 집중해 순차 보완 | 높은 성능 | outlier 민감 |
| 신경망/MLP | 분류/회귀 | 가중합과 활성함수의 층 구조 | 복잡한 비선형 표현 | 데이터·계산량·튜닝 필요 |

모델 선택은 다음 순서로 생각한다.

```text
1. 출력값이 연속형인가, 범주형인가?
2. 해석력이 중요한가, 예측 성능이 더 중요한가?
3. 선형 관계인가, 비선형 관계인가?
4. 데이터 scale과 이상치가 문제인가?
5. 데이터 양과 계산 비용은 감당 가능한가?
```

## 15. 오늘 요약 및 시험 포인트

### 15.1 핵심 요약

- 머신러닝은 데이터 패턴을 학습해 미래 데이터 예측이나 불확실한 상황의 의사결정을 수행하는 방법이다.
- 지도학습은 정답 `Y`가 있으며, `Y`가 연속형이면 회귀, 범주형이면 분류다.
- 모델 학습은 성능을 높이거나 손실을 낮추는 파라미터, 경계, 규칙을 찾는 과정이다.
- 회귀분석은 변수 간 관계를 직선 또는 함수로 표현하고, 최소제곱법은 잔차제곱합이 가장 작은 회귀선을 찾는다.
- 로지스틱 회귀는 선형모델을 logit과 확률로 연결해 분류 문제를 해결한다.
- 혼동행렬은 실제 class와 예측 class를 비교해 정확도뿐 아니라 precision, recall, F1을 계산하게 해준다.
- SVM은 마진을 최대화하는 결정경계를 찾고, kernel을 통해 비선형 분류로 확장한다.
- k-NN은 가까운 이웃의 다수결 또는 거리 가중 투표로 분류하며, scale과 k 선택이 중요하다.
- 의사결정나무는 질문 기반 분기로 데이터를 나누며, 불순도와 가지치기가 핵심이다.
- 앙상블은 여러 모델을 결합해 성능과 안정성을 높이며, Random Forest는 bagging과 의사결정나무의 결합이다.
- 인공신경망은 입력, 가중치, bias, 활성함수, 층 구조를 통해 복잡한 패턴을 학습한다.

### 15.2 시험 답안형 한 줄

| 주제 | 답안형 문장 |
|------|-------------|
| 지도학습 | 입력과 정답 label이 함께 있는 데이터로부터 `X → Y` 함수를 학습하는 방법이다. |
| 회귀 vs 분류 | 출력값이 연속형이면 회귀, 범주형이면 분류다. |
| 최소제곱법 | 실제값과 예측값의 잔차를 제곱해 모두 더한 값이 최소가 되는 회귀계수를 찾는 방법이다. |
| 결정계수 | 전체 변동 중 회귀모델이 설명한 변동의 비율이다. |
| 로지스틱 회귀 | class에 속할 확률을 logit 변환을 통해 선형모델과 연결한 분류 모델이다. |
| 혼동행렬 | 실제 class와 예측 class를 비교해 맞힌 경우와 틀린 경우를 정리한 분류 성능 평가표다. |
| SVM | class 사이 마진이 최대가 되는 결정경계를 찾는 분류 모델이다. |
| k-NN | 새 데이터와 가까운 k개 이웃의 결과를 이용해 분류 또는 회귀를 수행하는 거리 기반 알고리즘이다. |
| 의사결정나무 | 질문과 분기를 반복해 데이터를 동질적인 하위 집단으로 나누는 모델이다. |
| Bagging | 복원 샘플링으로 여러 모델을 학습하고 결과를 집계해 variance와 과적합을 줄이는 앙상블 방법이다. |
| Boosting | 이전 모델의 오답에 가중치를 부여하며 순차적으로 약한 모델을 강한 모델로 만드는 앙상블 방법이다. |
| Random Forest | 여러 의사결정나무를 bagging 방식으로 학습해 투표 또는 평균으로 예측하는 모델이다. |
| MLP | 입력층, 은닉층, 출력층으로 구성된 다층 퍼셉트론 신경망이다. |

### 15.3 헷갈리기 쉬운 구분

| 헷갈리는 쌍 | 구분 기준 |
|-------------|-----------|
| 상관분석 vs 회귀분석 | 상관은 관련성 확인, 회귀는 관계를 식으로 표현해 설명·예측 |
| 회귀 vs 분류 | 출력값이 연속형이면 회귀, class면 분류 |
| 선형회귀 vs 로지스틱 회귀 | 선형회귀는 실수값 예측, 로지스틱 회귀는 확률 기반 class 예측 |
| SVM vs k-NN | SVM은 경계 학습, k-NN은 저장된 데이터와 거리 비교 |
| 의사결정나무 vs Random Forest | 단일 규칙 나무 vs 여러 나무의 앙상블 |
| Bagging vs Boosting | 병렬 집계 vs 순차적 오답 보완 |
| 과적합 vs 과소적합 | 훈련데이터에 과하게 맞춤 vs 패턴을 충분히 못 잡음 |
