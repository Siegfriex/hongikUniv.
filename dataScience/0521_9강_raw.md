### PDF 텍스트 추출 원문 요지 2: R & Python

- 제목: `[140316] DATA SCIENCE / R & Python / Introduction to programming, R language, RStudio installation`
- Table of Contents:
  1. What is Programming?
  2. Introduction to R Language
  3. Introduction to Python
- What is Programming?
  - Computational Thinking: 컴퓨터가 문제를 분석하고 해결하는 방식으로 사고하는 것. 복잡한 문제를 단순화하고 논리적·효율적으로 해결하는 사고방식.
  - Programming: 컴퓨터가 처리할 수 있도록 문제 해결 절차를 체계적으로 기술하고, 컴퓨터에서 실행되는 소프트웨어를 만드는 과정.
  - 컴퓨터는 본래 지능이 없으므로 명확하고 단계적인 지시가 필요.
- Hardware / Software:
  - Hardware: 키보드, 모니터, 마우스, CPU, 메모리, 하드디스크 등 물리 장치.
  - Software: 하드웨어가 작동하도록 하는 명령어 집합. Excel, PowerPoint, KakaoTalk, Facebook 등.
  - 같은 하드웨어라도 소프트웨어에 따라 할 수 있는 작업이 달라짐.
  - 소프트웨어 실행에는 CPU와 메모리 등 하드웨어 자원이 필요.
- Programming and Programming Languages:
  - 프로그래밍은 요리 레시피처럼 정해진 순서의 단계가 필요.
  - 단계의 순서가 명확하지 않으면 컴퓨터는 기대한 결과를 만들 수 없음.
  - 자연어는 ambiguity가 많아 컴퓨터가 그대로 실행하기 어렵다.
  - 최근 LLM(ChatGPT 등)으로 자연어 의도에서 유용한 코드를 쉽게 생성할 수 있게 됨.
  - Programming language는 컴퓨터가 작업을 수행하도록 프로그램을 작성하는 언어.
  - 각 언어마다 고유 문법(grammar)이 있음.
  - 자연어와 달리 프로그래밍 언어에는 방언, 속어, 신조어가 없음.
- What is the best programming language?
  - 대표 언어: C, Java, Python 등.
  - PYPL index는 Google tutorial 검색 빈도로 언어 인기도를 산정.
- Why R & Python?
  - 비전공자도 배우고 업무에 적용할 수 있는 프로그래밍 언어가 필요.
  - 이를 위해 R과 Python을 학습.
  - C와 R 배열 조작 비교: 10x10 배열에서 2번째 행, 5번째 열 제거 문제. R은 약 3줄, C는 약 20줄.
- Introduction to R Language:
  - R은 1993년 뉴질랜드 오클랜드대학교 Ross Ihaka와 Robert Gentleman이 개발.
  - S-PLUS의 무료 버전 성격.
  - 데이터분석에 특화, 컴파일 없이 바로 실행, R 코드는 program보다 script라고 부르는 경우가 많음.
  - 강력한 사용자 커뮤니티, 학습자료 풍부, 한글 자료 증가.
  - 다양한 패키지 제공. 새로운 이론을 반영한 패키지가 빠르게 개발.
  - ggplot2: The Grammar of Graphics 기반 선언적 그래픽 시스템.
  - RStudio: R 프로그래밍 통합 개발 환경(IDE).
  - R은 open-source, 무료, Windows/Linux/macOS 사용 가능, 정기 업데이트.
- Example of R:
  - Iris 데이터셋의 `Petal.Length`, `Petal.Width`로 scatter plot 생성.
  - `library(ggplot2)`
  - `ggplot(data=iris, aes(x=Petal.Length, y=Petal.Width, color=Species)) + geom_point(size=3) + ggtitle(...) + theme(...)`
  - `shape = Species`를 `aes()` 안에 넣으면 품종별 점 모양 변경 가능.
- Introduction to Python:
  - PDF 텍스트 일부 누락/혼합 있으나 scikit-learn 선형회귀 예시 포함.
  - `make_regression`, `train_test_split`, `LinearRegression`, `fit`, `predict`, `matplotlib` 시각화 흐름.
  - scikit-learn은 Python에서 가장 널리 사용되는 머신러닝 라이브러리.
  - 데이터 전처리, 회귀, 분류, 군집화, 모델평가를 일관된 인터페이스로 제공.
