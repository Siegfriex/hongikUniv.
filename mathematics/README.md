# Mathematics (수학)

## 과목 목표
- 수학 기초·이론을 정리하고, 통계·데이터사이언스·ML에 필요한 수학적 도구를 다룬다.
- 강의·정리 노트는 `YYYYMMDD.md` 형식으로 누적·보강한다.

## 난이도
- 기초부터 시작해, 선형대수·미적분·확률 등 응용까지 연계한다.

## 예제 스타일
- 정의·정리·예제·참고(출처) 블록 사용. 수식은 LaTeX 또는 코드블록. 표는 markdown 테이블.

## 선행 과목 / 연관
- (선행 과목이 정해지면 링크 추가)
- 통계학·데이터사이언스·ML 과목과 연계 가능.

## 사용 언어
- 한글 중심, 용어는 한·영 병기.

## 파일 네이밍 예시
- 강의·정리 파일 예: `mathematics/20260304.md`

## 대표 키워드 / 토픽 리스트
- 선형대수, 미적분, 확률, 행렬, 벡터, 최적화, 수식·증명.

## 브랜치
- `mathematics` (26_1에서 분기)
