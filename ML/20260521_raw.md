- 핵심 문제의식: 지난주 코드는 2-2-1 구조에 가까운 고정 구현이어서, 임의의 층과 깊이를 조립하기 어렵다.
- Layer는 조립 가능한 블록이다. 공통 인터페이스는 `forward`, `backward`, `update` 3개로 통일한다.
- `forward(self, x)`: 입력을 받아 출력을 반환한다. 출력은 다음 층의 입력이 된다.
- `backward(self, grad_output)`: 이 층의 출력에 대한 \(\partial L\)을 받아 이 층의 입력에 대한 \(\partial L\)을 반환한다.
- `update(self, lr)`: 자신의 파라미터만 업데이트한다. 파라미터 없는 층은 no-op.
- Local Gradient 사고법:
  - 각 층은 전체 chain rule을 모두 알 필요가 없다.
  - 자기 옆의 local 미분만 알고, Network가 backward 호출을 역순으로 돌린다.
  - \(\partial L / \partial(\text{이 층 입력}) = (\text{이 층 local 미분}) \times \partial L / \partial(\text{이 층 출력})\)
- Dense:
  - forward: \(Z = XW^\top + b\)
  - `x`: `(B, n_in)`, `W`: `(n_out, n_in)`, output: `(B, n_out)`
  - backward:
    - `dW = grad_output.T @ x`
    - `db = grad_output.sum(axis=0)`
    - `dx = grad_output @ W`
- Activation:
  - ReLU: forward `x * (x > 0)`, backward `grad_output * (x > 0)`
  - Sigmoid: forward \(\sigma(x)\), backward `grad_output * out * (1-out)`
- Softmax + Cross Entropy:
  - Softmax: \(p_i = \exp(z_i)/\sum_j \exp(z_j)\)
  - Cross entropy: \(L = -\sum_i y_i \log p_i\)
  - 결합 gradient: \(\partial L/\partial z = p-y\), batch 평균 시 `(p-y)/B`
- 분류와 회귀:
  - 분류: Softmax + Cross Entropy, one-hot target, gradient \(p-y\)
  - 회귀: linear output + MSE, 실수 target, gradient \(\hat{y}-y\)
- Network:
  - forward는 층 리스트를 순서대로 호출한다.
  - backward는 `reversed(self.layers)`로 역순 호출한다.
  - update는 각 layer의 `update(lr)`를 호출한다. 파라미터 없는 층은 no-op.
- Mini-batch:
  - 배치 크기는 보통 32~256.
  - batch dimension은 0번째 축.
  - Week 11 단일 샘플 `(n_in,)`에서 Week 12 mini-batch `(B, n_in)`으로 확장.
  - `outer(grad, x)`가 `grad.T @ X`로 일반화된다.
  - epoch = 전체 데이터 1회 통과.
- Sigmoid vs ReLU:
  - Sigmoid 미분 최대값은 0.25.
  - ReLU 미분은 양수 영역에서 1, 음수 영역에서 0.
  - 깊은 Sigmoid 네트워크는 첫 층 gradient가 \(0.25^L\)처럼 작아져 vanishing gradient 발생.
  - ReLU는 현대 딥러닝 기본 활성화. Dying ReLU는 Leaky ReLU, ELU, GELU 등으로 보완 가능.
- Vanishing 실험:
  - 동일한 10층 네트워크를 Sigmoid와 ReLU로 구성.
  - forward + backward 1회 뒤 첫 층 `dW` 평균 절댓값 측정.
  - 예상: Sigmoid 첫 층 gradient 약 `1e-6`, ReLU 약 `1e-3`.
- Iris:
  - 샘플 150개, 특징 4개, 클래스 3개.
  - `Dense(4,8) -> ReLU -> Dense(8,3)`, `SoftmaxCE`.
  - train/test accuracy 약 96~98%.
- MNIST:
  - 샘플 70,000장, 특징 784개, 클래스 10개.
  - `Dense(784,128) -> ReLU -> Dense(128,64) -> ReLU -> Dense(64,10)`.
  - 20 epoch, batch_size 128, lr 0.01.
  - test 정확도 슬라이드 표기 약 93%, 코드만으로 약 97% 가능하다는 설명도 있음. 문서화 시 실행 결과 기준으로 분리 필요.
  - 파라미터 약 109,386개. Week 11의 9개 편미분이 10만 개로 늘어난 것일 뿐 원리는 같다.
- Keras 대응:
  - 우리 구조와 Keras 구조는 일대일 대응.
  - framework는 자동미분, GPU/TPU, Adam/AdamW/RMSprop, 정규화/Dropout, CNN/RNN/Transformer layer, 분산학습, 저장/로딩을 추가 제공한다.

### 사용자 중점 요청

- 이번 강의의 핵심 주안은 “미리 scale/planning된 고정 코드”가 아니라, `Layer`라는 공통 개념을 두고 `forward`, `backward`, `update` 메서드를 각 층이 오버라이드해 적용하는 구조다.
- `Layer` 개념을 중심으로 Dense, ReLU, Sigmoid, Softmax/SoftmaxCE를 각각 설명해야 한다.
- 각 메서드가 왜 쓰이고, 입력으로 무엇을 받고, 무엇을 출력/저장하는지 구체화한다.
- `Network.add`가 왜 필요한지, `for layer in self.layers`가 왜 필요한지, backward에서 왜 `reversed()`를 쓰는지 설명한다.
- Softmax에서 Cross Entropy를 같이 잡는 이유를 수식과 코드 관점에서 깊게 설명한다.
- Loss 함수가 backprop 시작 gradient를 만든다는 점, activation이 local gradient를 조절한다는 점을 분리해서 설명한다.
