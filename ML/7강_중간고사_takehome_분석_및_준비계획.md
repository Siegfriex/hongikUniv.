## 4. Part 1 — 회귀: 1-3·1-4 방법론 (고정 테스트·R²·α)

**데이터:** `fetch_california_housing` — 타깃 `MedHouseVal`  
**흐름 (시험지):** 1-1 준비 → 1-2에서 **상관 절댓값 상위 4개** 수치형 피처 선택 → 1-3 세 모델 → 1-4 해석

### 4-1. 고정 홀드아웃으로 R² “피킹”

| 단계 | 할 일 |
|------|--------|
| 분할 | **8:2**, `random_state=42` — **한 번만** 나누고 이 `X_test`, `y_test`를 **모든 모델 공통**으로 사용 |
| 피처 | 1-2 이후 **동일 4개 열**만 사용 (전부 수치형) |
| 지표 | 회귀 `score` = **R²**. **Train R²**와 **Test R²**를 **항상 쌍**으로 기록 |

**과적합 판단 (1-4 (1)용):**  
- Train R² ≫ Test R² 이거나 Test R²가 **음수**·급락하면 복잡 모델이 훈련 분포에 과도하게 맞춘 신호.  
- **수치 인용:** “Linear Test R² = …, Polynomial Test R² = …, Ridge Test R² = …”처럼 **세 줄 비교**.

### 4-2. 세 모델 적용 순서 (1-3)

| 모델 | 구현 체크 |
|------|-----------|
| Linear | `LinearRegression` on 4 features |
| Polynomial(2) | `PolynomialFeatures(degree=2, include_bias=False)` **train에 fit** → `transform` train/test **동일 객체**로 |
| Ridge | 동일 2차 특성 + `Ridge(alpha=10)` |

**흔한 실수:** `PolynomialFeatures`를 test에 다시 `fit`하거나, 스케일러를 전체 데이터에 `fit`.

### 4-3. 1-4 (2) 페널티 항 (수업 연계)

`20250313.md`의 Ridge(L2)와 같이, 손실에 **\(\alpha \|\mathbf{w}\|^2\)** 형태의 항을 더해 **계수 폭주를 억제** → 고차 다항 특성에서의 과적합 완화. **서술 시:** “경험적 손실 + 정규화(페널티) 항의 균형”으로 한 문단.

### 4-4. 1-4 (3) α 스윕 및 응용 (+a 후보)

문항 요구: `alpha=10` 외 **여러 α** 실험 후 설명.

| 확장 | 목적 |
|------|------|
| α 로그 스케일 그리드 | 예: `np.logspace(-3, 3, 13)` — 안정적인 곡선 |
| Train vs Test R² **동시 플롯** | 과적합 구간(Train↑ Test↓) vs 과소적합(둘 다 낮음) 시각화 |
| **검증 곡선** `validation_curve` | sklearn 내장 — 훈련/검증 점수 vs α |
| **K-fold CV**로 최적 α 탐색 | 수업 CV 개념과 연결 — 단, **시험 답안**에서는 문항이 요구한 **고정 test R²**와 혼동하지 말고, “CV는 모델 선택 보조, 최종 보고는 문항대로 hold-out”처럼 **역할 분리** 한 줄 |

## 5. Part 2 — 유방암 분류: EDA→KNN→SVM→DT→2-5 정합 비교

**데이터:** `sklearn.datasets.load_breast_cancer` — **30개 수치 피처**, 이진 타깃(악성/양성; 라벨 인코딩은 sklearn 설명과 `target_names` 확인).

### 5-1. 웹 그라운딩·EDA (간단히 +a)

**데이터 출처 맥락:** UCI / Wisconsin Breast Cancer Diagnostic 등으로 검색하면 **피처 의미**(반지름·질감·오목점 등)와 **임상 해석** 예시가 많다. 논문 검색 시 키워드 예: `breast cancer wisconsin machine learning`, `medical imaging tabular classification interpretability`, `clinical decision support false negative`.

**EDA 최소 세트 (노트북에 코드·1~2문단):**

- `shape`, `describe()`, 타깃 `value_counts()` (불균형 여부)
- 상관 히트맵 또는 타깃과 상위 상관 피처 몇 개
- 이상치 감(극단값) 스캔 — **시험 범위 밖 심화**이면 한 줄로만 언급해도 됨

### 5-2. 전처리: 7:3 + StandardScaler

- `train_test_split(test_size=0.3, random_state=42, stratify=y)` — **이진 분류에서 층화**하면 클래스 비율 유지(+a로 짧게 언급 가능).
- **스케일러를 쓰는 이유 (2-2 서술):** KNN·SVM(선형)은 **거리·내적**에 민감해 **단위가 큰 피처가 거리를 지배**한다. 트리는 스케일 불변에 가깝지만, **문항에서 KNN/SVM 전에 스케일**을 요구하므로 파이프라인 일관성 유지.

### 5-3. KNN: k=1~15

- 문항: 홀수 k 목록 — **train/test accuracy 곡선** 플롯.
- **최적 k:** test 최고점 또는 train–test 갭이 작은 지점 — **과적합(k 작음: train↑ test 상대 낮음)** vs **과소적합(k 큼: 둘 다 둔탁)** 언어로 근거.

### 5-4. SVM: Accuracy 중심 + 수업식 확장 (+a)

- 문항: `Pipeline(StandardScaler + LinearSVC(C=..., loss='hinge', max_iter=10000))`, **C 스윕** + 그래프.
- **추가 지표 (같은 test에서 일관되게):** `classification_report` → **precision, recall, F1**; `confusion_matrix` → **FP, FN** 명시. Accuracy만으로는 2-5·Part 3 서술이 빈약해지기 쉬움.
- **주의:** 2-1에서 이미 스케일한 배열을 쓰면 Pipeline 안 scaler와 **이중 스케일** — **raw feature + Pipeline** 또는 **스케일된 배열 + SVC만** 중 하나로 통일 (주석으로 선택 이유).

### 5-5. Decision Tree: max_depth, min_samples_leaf

- 문항: gini vs entropy, `max_depth=5`, `min_samples_leaf=3` + `plot_tree`, `classification_report`.
- **실험 확장:** `max_depth=None` vs `3,5,10`, `min_samples_leaf` `1,3,5,10` 등 **격자** — train/test accuracy **표**로 변화율 요약.
- **해석:** 깊이↑ → 용량↑·과적합 위험; `min_samples_leaf`↑ → 잎 노드 샘플 수 제약으로 **분할 완화·일반화**.

### 5-6. 2-5 세 모델 표 + 정합론

- 표: **최적 k의 KNN**, **C=1 SVM**, **gini DT**의 **test accuracy** (문항 요구).
- **성능 차이가 작을 때:** “데이터가 선형 경계와 비선형 경계 모두에서 비슷한 마진으로 분리 가능”, “피처 공간이 비교적 낮은 잡음”, “표본 크기 대비 문제 난이도” 등 **정합적 설명**을 제시 — 단순 “다 비슷하다”가 아니라 **왜 비슷해도 타당한지** 한 단락.

## 6. Part 3 — 종합: 귀납·연역, 지표 다각도, 도메인·문헌

### 6-1. Regression vs Classification (3-1)

- **출력:** 연속값 vs 이산 라벨.
- **지표:** R²·MSE vs accuracy·F1 등.
- **귀납적 관점:** 데이터에서 관찰된 패턴 일반화(경험적 위험 최소화).  
- **연역적 관점:** 문제 정의(회귀냐 분류냐)에 따라 **선택 가능한 가정·해석 프레임**이 달라짐(예: 선형 회귀의 오차 가정 vs 분류의 결정 경계).

### 6-2. MedHouseVal 이진화 장단점 (3-1 (2))

- **장점:** 정책·리스크 구간을 명확히 나눔, 분류 지표로 **민감도/특이도** 트레이드오프 논의 가능.  
- **단점:** 연속 정보 손실, 경계 근처 주택의 **오분류 비용**.

### 6-3. Accuracy 외 지표 (요청 반영: 오탐·정오·특이도·민감도)

| 용어 | 의미 (이진, 악성=positive로 정의 예시 시) |
|------|---------------------------------------------|
| **민감도(Recall, TPR)** | 실제 양성 중 모델이 양성으로 맞춘 비율 — **놓치면 안 되는 질병**에서 중요 |
| **특이도(Specificity, TNR)** | 실제 음성 중 음성으로 맞춘 비율 |
| **오탐(FP)** | 음성인데 양성으로 예측 |
| **미탐(FN)** | 양성인데 음성으로 예측 — 임상에서 **고비용**인 경우가 많음 |
| **정밀도(Precision)** | 양성 예측 중 실제 양성 비율 |

Accuracy는 **클래스 비율·FP/FN 비용**이 다를 때 **왜곡**될 수 있음 — Part 3에서 한 문단.

### 6-4. 최적 모델 선택 (3-2) — KNN vs SVM vs DT

| 관점 | KNN | SVM(선형) | Decision Tree |
|------|-----|-----------|----------------|
| **일반화** | k·거리 척도에 민감, 국소적 | 마진 최대화, 차원·선형 가정 | 가지치기 없으면 과적합 쉬움 |
| **해석·설명** | “이웃” 설명은 가능하나 **전역 규칙**은 약함 | 초평면·계수(스케일 후)로 부분 설명 | **if-then 규칙**으로 비전문가 설명에 유리 |
| **임상 메시지** | “유사 사례” 논리 | “경계선 너머” 논리 | “조건 조합” 논리 |

실제 **한 모델을 고르는 답**은 본인 실험 수치 + **FN 최소화** 등 가치 판단을 **함께** 서술.

### 6-5. 의료 AI 도메인 — 문헌·사례 (+a)

직접 논문을 인용할 때는 **본인이 읽은 문헌의 제목·연도**를 적는 것이 안전하다. 검색 채널 예:

- [arXiv](https://arxiv.org/) — `breast cancer` + `interpretable` / `tabular` / `clinical`
- PubMed, IEEE Xplore — clinical decision support, model explanation
- **이슈 사례:** 데이터 편향(특정 인구 집단), 라벨 노이즈, **설명 가능성 요구**(규제·임상 신뢰), **책임·동의**, 외적 검증 부족

**해석 가능 모델:** 얕은 트리, 규칙 리스트, 선형 모델+계수 부호 등이 **설명력** 논의와 연결된다.

## 7. 채점 철학: 기본 만점선과 +a

**원문 보존 요지:**  
기본 **100/100**에 가깝게 **직관적·구체적** 문제가 출제되었고, **+a**는 **수업과 연결된 확장**(다른 α, CV, 추가 지표, EDA, 문헌 기반 도메인 논의)을 **해 보았을 뿐 아니라**, 그 결과에 대해 **타당·합리적 해석**이 붙을 때 드러난다.  
즉 **“실험 나열”이 아니라 “선응·특징이 왜 그런지”**가 글로 정리되는 것이 +a에 가깝다.
