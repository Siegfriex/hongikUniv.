SVM과 커널 트릭

Margin 최대화부터 RBF 커널까지 — 체계적 정리

표기 통일 기준
xᵢi번째 학습 데이터 포인트 (벡터)
yᵢi번째 클래스 레이블 (+1 또는 -1) — 항상 레이블만
x*새로 들어온 예측 대상 데이터
K(xᵢ, xⱼ)두 데이터 포인트의 유사도 (커널 함수)

1단계 — SVM의 목표: Margin 최대화

1

결정 경계를 찾는다

두 클래스 사이의 margin을 최대화하는 평면을 찾는 것이 목표.
수식으로는 w의 크기를 줄이는 것과 수학적으로 동일.
min ½‖w‖² s.t. yᵢ(w·xᵢ + b) ≥ 1 xᵢ : i번째 학습 데이터 포인트 yᵢ : i번째 클래스 레이블 (+1 또는 -1)
2

라그랑지안으로 변환 → αᵢ 등장

최적화 문제를 풀면 자연스럽게 αᵢ (각 데이터의 중요도)가 나옴.
따로 학습하는 게 아니라, margin을 최대화하다 보면 생기는 값.
w = Σ αᵢ yᵢ xᵢ 경계에 딱 걸친 점 (서포트벡터) → αᵢ > 0 경계에서 멀리 있는 점 → αᵢ = 0 (자동으로!)

2단계 — 내적이 등장하는 이유

3

w를 대입하면 내적이 나온다

w = Σαᵢyᵢxᵢ 를 결정 경계에 대입하면:
f(x*) = w·x* + b = (Σ αᵢ yᵢ xᵢ)·x* + b = Σ αᵢ yᵢ (xᵢ·x*) + b ↑ 내적 등장 — 학습데이터 xᵢ 와 새 데이터 x* 의 방향 유사도
내적 xᵢ · x* 의 의미: 서포트벡터 xᵢ 와 새 데이터 x* 가 얼마나 같은 방향을 가리키는가

→ 같은 방향 → 양수 기여 → xᵢ 의 클래스(yᵢ) 방향으로 당김
→ 다른 방향 → 영향 거의 없음
→ 최종적으로 부호(+/-)로 클래스 판정
4

새 데이터 예측 흐름

f(x*) = α₁y₁(x₁·x*) + α₂y₂(x₂·x*) + ... + b f(x*) > 0 → 클래스 +1 f(x*) < 0 → 클래스 -1 * αᵢ = 0인 데이터(서포트벡터 아님)는 자동으로 무시됨
yᵢ 는 항상 레이블 (+1/-1) 이고, 내적의 두 인자 xᵢ 와 x* 는 항상 데이터 포인트입니다. 커널 함수에서도 이 구분은 동일하게 유지됩니다.

3단계 — 커널 트릭: 내적 자리를 교체

5

비선형 문제는 고차원 변환으로 해결

직선으로 나눌 수 없는 데이터 → 고차원으로 변환 φ(xᵢ) → 그 공간에서 선형 분리.
그런데 SVM은 내적값만 필요하고, 변환된 벡터 자체는 필요 없다.
φ(xᵢ)·φ(x*) ← 이 내적값만 있으면 됨 벡터 자체는 필요 없음 K(xᵢ, x*) = φ(xᵢ)·φ(x*) → 커널 함수로 고차원 변환 없이 바로 계산
6

내적 자리에 커널을 꽂는다

선형: f(x*) = Σ αᵢyᵢ (xᵢ·x*) + b Polynomial: f(x*) = Σ αᵢyᵢ K(xᵢ,x*) = (xᵢ·x* + c)^d + b RBF: f(x*) = Σ αᵢyᵢ K(xᵢ,x*) = exp(-γ‖xᵢ-x*‖²) + b yᵢ = 클래스 레이블 (항상) K(xᵢ, x*) = 두 데이터 포인트의 유사도 (항상)

4단계 — Polynomial vs RBF 비교

Polynomial

K(xᵢ, xⱼ) = (xᵢ·xⱼ + c)^d


변환 방식: d차까지의 고차원 변환을 한 것과 동일. 변환 차원이 유한.

파라미터: d (차수), c (저차항 반영 비율)

언제 유리: 데이터가 몇 차에서 분리될지 예측 가능할 때

RBF

K(xᵢ, xⱼ) = exp(-γ‖xᵢ - xⱼ‖²)


변환 방식: 무한차원 변환을 한 것과 동일. Polynomial의 무한 버전.

파라미터: γ (각 차수 가중치 감소 속도)

언제 유리: 일반적 상황, 차수 예측이 어려울 때

γ

gamma 파라미터 역할

γ 는 exp(-γ‖xᵢ - xⱼ‖²) 에서 거리에 얼마나 민감하게 반응할지 결정.
gamma영향 범위결정 경계위험
큰 값 xᵢ 근처만 구불구불함 Overfitting
작은 값 xᵢ 에서 멀리까지 부드러움 Underfitting

최종 요약

SVM은 margin을 최대화하는 과정에서 서포트벡터와 αᵢ가 자동으로 결정되고,
새 데이터 x* 는 서포트벡터 xᵢ 들과의 내적(유사도)의 가중합으로 클래스가 판단됩니다.

이때 yᵢ 는 항상 클래스 레이블이고, 커널 함수 K(xᵢ, x*) 안의 두 인자는 항상 데이터 포인트입니다.

비선형 데이터는 커널 트릭으로 해결하는데, Polynomial은 유한한 고차원 변환, RBF는 무한차원 변환을 exp 함수 하나로 대체합니다.
