Forward Pass — 2-2-1 MLP

슬라이더로 입력과 가중치를 조절하면, 모든 수식과 결과가 함께 갱신됩니다.

입력 & 파라미터

$x_0$ (입력 0)1.00
$x_1$ (입력 1)1.00
$y$ (타겟)0.00
$W^{(1)}_{00}$0.10
$W^{(1)}_{01}$0.20
$W^{(1)}_{10}$0.30
$W^{(1)}_{11}$0.40
$W^{(2)}_{0}$0.50
$W^{(2)}_{1}$0.60
강의 슬라이드 예제: $\mathbf{x}=[1,1]$, $y=0$, 위 기본값
STEP 0

주어진 값 (매트릭스 표기)

은닉층 가중치 $\mathbf{W}^{(1)}$ 은 (2×2) 행렬입니다. 행 인덱스 $i$ 는 은닉 뉴런 번호, 열 인덱스 $j$ 는 입력 번호입니다. 즉 $W^{(1)}_{ij}$ 는 "$j$번째 입력 → $i$번째 은닉 뉴런"으로 가는 가중치입니다.

STEP 1

은닉층 pre-activation

선형 변환

$\mathbf{z}^{(1)} = \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}$

STEP 2

시그모이드 통과

비선형 활성화

$\mathbf{a}^{(1)} = \sigma(\mathbf{z}^{(1)})$, 단 $\sigma(z) = \dfrac{1}{1 + e^{-z}}$

시그모이드는 손계산이 어려우므로 아래 근사값 표를 참조합니다. 현재 $z^{(1)}_0$, $z^{(1)}_1$ 값에 가장 가까운 행이 강조됩니다.

STEP 3

출력층 pre-activation

선형 변환

$z^{(2)} = \mathbf{W}^{(2)}\mathbf{a}^{(1)} + b^{(2)}$

STEP 4

출력 (활성화 없음)

회귀이므로 σ 생략

$a^{(2)} = z^{(2)}$

STEP 5

손실 (MSE)

단일 샘플 기준

$L = \dfrac{1}{2}(y - a^{(2)})^2$

한 페이지 요약

1$\mathbf{z}^{(1)} = \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}$—
2$\mathbf{a}^{(1)} = \sigma(\mathbf{z}^{(1)})$—
3$z^{(2)} = \mathbf{W}^{(2)}\mathbf{a}^{(1)} + b^{(2)}$—
4$a^{(2)} = z^{(2)}$—
5$L = \tfrac{1}{2}(y - a^{(2)})^2$—
