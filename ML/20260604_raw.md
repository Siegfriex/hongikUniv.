3.2  L2 Regularization
직관: Loss에 가중치 페널티 추가
원래 :  L = MSE
L2 :  L = MSE + λ · Σ wᵢ²
가중치가 클수록 페널티 ↑
→ 모델이 작은 가중치 선호
→ 단순한 함수 학습
→ 과적합 ↓
from keras.regularizers import l2
reg = l2(0.01)     # λ = 0.01
model = keras.Sequential([
Dense(128, activation='relu',
kernel_regularizer=reg,
input_shape=(n,)),
Dense(128, activation='relu',
kernel_regularizer=reg),
Dense(64, activation='relu',
kernel_regularizer=reg),
Dense(1)
])
L2 (Ridge): Σ wᵢ²  → 가중치를 작게 ·   L1 (Lasso): Σ |wᵢ|  → 정확히 0으로 (feature 선택)  ·   신경망은 보통 L2

Image Filters
• Image Filters Overview: Image filters, also known as kernels, are core tools in digital image processing. They are
used to enhance images or extract information by applying various effects such as edge detection, blurring, and
sharpening.
• How Image Filters Work: An image filter is a small matrix that modifies the image by applying a convolution
operation. This involves overlaying the filter on the image, multiplying its values by the original pixel values, and
summing the result to produce a new pixel value.
• Common Uses: Filters can highlight edges, reduce noise, or blur images to remove detail. For example, an edge
detection filter highlights the boundaries of objects, while a blur filter can reduce image noise.
• Custom vs. Learned Filters: Traditionally, image filters were hand-designed, with specific patterns to achieve
desired effects. However, a significant advancement in image processing has been the development of systems
that can learn the most effective filters for a given task.

### wk_14_cnn (1).pdf p.8

Learnable filters for image analysis?
8
• In the context of Convolutional Neural Networks (CNNs), image filters (also known as kernels)
are small matrices used to apply effects like edge detection, blurring, sharpening, and more to
images.
• How They Work: These filters are applied to the original image through a process called
convolution. By sliding the filter over the image and computing the dot product at each position,
new feature maps that highlight specific attributes of the image are created.
• Role in CNNs: Filters in CNNs automatically learn to detect important features during training,
such as edges, textures, or shapes, which are critical for understanding and analyzing images.
• Feature Extraction: As the image passes through successive convolutional layers in a CNN, filters
can capture increasingly complex aspects of the image. The network learns which filters are most
effective for the specific tasks (e.g., classification, recognition) it's being trained on.

### wk_14_cnn (1).pdf p.11

Composition of a Convolutional Layer
11
• Filters/Kernels: Small, learnable matrices that scan over the input to extract features. Each filter
detects different aspects of the input (e.g., edges, colors, gradients).
• Stride: The number of pixels by which the filter moves across the input. A stride of 1 moves the
filter one pixel at a time.
• Padding: Adding zeros or copying edge values around the input image to preserve the spatial
size of the output feature map.
• Feature Map: The output generated by a filter over the input is called a feature map. It
represents the detected features of the input.
• Activation Function: Often, a non-linear function like ReLU is applied to the feature map to
introduce non-linearity, allowing for the detection of complex patterns.

RGB image has three channels: Red, Green, and Blue.
2. Kernel: The convolutional layer uses a set of filters
(kernels). Each filter has the same depth as the
number of input channels. For example, if there are
three input channels, each filter will also have three
channels.
Source: CVPR 2014 tutorial by Marc'Aurelio Ranzato

---

### wk_14_cnn (1).pdf p.14

3. Convolution Operation:
• Each filter slides (convolves) over the input feature
maps.
• For each position, element-wise multiplication is
performed between the filter and the corresponding
region of the input feature maps.
• The results of these multiplications are summed up
to produce a single value. This operation is repeated
for every spatial position in the input feature maps,
resulting in a single 2D feature map.
Source: CVPR 2014 tutorial by Marc'Aurelio Ranzato

---

### wk_14_cnn (1).pdf p.15

4. Summing Across Channels:
• Since each filter spans all input channels, the
convolution operation involves summing the results
across all channels.
• Specifically, for each position, the element-wise
multiplications and summing are performed
separately for each channel and then summed across
all channels to obtain a single output value for that
position.
5. Bias and Activation Function:
After the convolution operation, a bias term is added to
each element of the resulting feature map.
6. Output Feature Map: The process is repeated for
each filter in the convolutional layer. If the layer has
N filters, it produces N output feature maps, each
corresponding to a filter.
Source: CVPR 2014 tutorial by Marc'Aurelio Ranzato

• Key Components of Convolutional Neural Networks (CNNs):
• Convolutional Layer: The cornerstone layer of CNNs, responsible for extracting features from the
input image using filters (or kernels) to learn local patterns.
• Activation Function: Introduces non-linearity into the network, allowing it to learn complex
patterns. The Rectified Linear Unit (ReLU) is a commonly used activation function.
• Pooling Layer: Reduces the spatial size of the representation, decreasing the number of
parameters and computation in the network. Max pooling is frequently utilized to reduce
sensitivity to the exact location of features.
• Basic Working Principle of CNNs:
• CNNs progressively extract higher-level features from the input image by passing it through
multiple convolutional and pooling layers, culminating in a classifier that performs tasks such as
image classification.
• Importance of Feature Maps:
• Feature maps generated at each layer contain important information about the image, becoming
increasingly refined as the network learns during training.
• Fully Connected Layer for Final Classification:
• At the end of the network, fully connected layers utilize all extracted features to make the final
classification decision, identifying the class to which the image belongs.

```markdown
### 처리 전략 3가지

| 방법 | 코드 | 언제 쓰나 |
|------|------|----------|
| **삭제** | `df.dropna()` | 결측치가 적을 때 (<5%) |
| **대체 (수치)** | `df['age'].fillna(df['age'].mean())` | 정규분포에 가까울 때 |
| **대체 (범주)** | `df['city'].fillna('Unknown')` | 범주형 변수 |
```

#### Cell 7 (code)

```python
# 전략 1: 삭제 (결측치 있는 행 제거)

# 전략 2 & 3: 대체

toy_filled['age']    = toy_filled['age'].fillna(toy_filled['age'].mean())      # 평균 대체
toy_filled['salary'] = toy_filled['salary'].fillna(toy_filled['salary'].median())  # 중앙값
toy_filled['city']   = toy_filled['city'].fillna('Unknown')                    # 새 범주
```

#### Cell 8 (markdown)

```markdown
> ⚠️ **중요 — Data Leakage 방지**
>
> 대체값(평균, 중앙값)은 **train 데이터에서만** 계산해야 한다.
> test의 평균을 쓰면 미래 정보가 학습에 누수됨 (data leakage).
```

```markdown
## 1.2 수치형 정규화

### 왜 정규화하나?

```
변수 A: [1, 2, 3, 4]        ← 작은 스케일
변수 B: [100, 200, 300, 400] ← 큰 스케일
```

신경망은 큰 값에 *과민*하게 반응 → 학습 불안정.

### 두 가지 방법

| Scaler | 변환 후 범위 | 수식 | 언제 |
|--------|-------------|------|------|
| **MinMaxScaler** | [0, 1] | `(x - min) / (max - min)` | 이미지 픽셀, 경계 명확 |
| **StandardScaler** | 평균 0, 분산 1 | `(x - mean) / std` | 정규분포에 가까울 때 |
```

#### Cell 10 (code)

```python
# 예시 데이터
data = np.array([[1.0, 100.0],
                 [2.0, 200.0],
                 [3.0, 300.0],
                 [4.0, 400.0]])

# StandardScaler
ss = StandardScaler().fit_transform(data)
print('StandardScaler 결과 (평균 0, 분산 1):')
print(ss)
print()

# MinMaxScaler
mm = MinMaxScaler().fit_transform(data)
print('MinMaxScaler 결과 ([0, 1] 범위):')
```

```markdown
## 1.5 Train/Val/Test 3분할

### 왜 3분할인가?

Week 13에서는 train/test 2분할만 썼다. 이건 *간단한 예제에서만* OK.

```
2분할의 문제:
  Train ─→ 모델 학습
  Test ─→ 하이퍼파라미터 튜닝
         ↑↑↑ 이 시점에 test가 "새는" 셈
→ 최종 성능을 평가할 깨끗한 데이터가 없어진다.
```

### 3분할

```
Train ─→ 모델 학습 (가중치 업데이트)
Val   ─→ 하이퍼파라미터 결정 + 과적합 진단
Test  ─→ 마지막 단 한 번만 평가 (절대 건드리지 않음)
```
```

```markdown
# Part 2. 과적합 진단

## 2.1 과적합이란

```
좋은 모델: train에서 잘 맞추고, 새 데이터에서도 잘 맞춤
과적합:   train에서만 잘 맞추고, 새 데이터에서는 못 맞춤
         (= "암기"는 했는데 "이해"는 못 한 상태)
```

### Bias-Variance Trade-off

| 상태 | Train Loss | Val Loss | 진단 / 처방 |
|------|-----------|----------|------------|
| **Underfit** | 높음 | 높음 | 모델 너무 단순 → *모델 키우기* |
| **Good fit** | 낮음 | 낮음 | 적절 |
| **Overfit** | 매우 낮음 | 높음 | 모델 너무 복잡 → *정규화* |
```

```python
    '''모델 학습 + 결과 출력 + history 반환'''
    keras.utils.set_random_seed(42)  # 재현성

    final_val   = history.history['val_loss'][-1]
    print(f'{name:15s} | Train: {final_train:.4f} | Val: {final_val:.4f} | Gap: {final_val - final_train:+.4f}')
    return history
```

```markdown
## 3.2 L2 Regularization

### 직관

Loss에 *가중치 크기 페널티*를 추가:

```
원래 loss:        L = MSE
L2 추가 loss:     L = MSE + λ · Σ wᵢ²
```

가중치가 클수록 페널티 ↑ → 모델이 작은 가중치 선호 → 단순한 함수 → 과적합 ↓
```

#### Cell 42 (code)

```python
from keras.regularizers import l2

keras.utils.set_random_seed(42)
reg = l2(0.01)   # λ = 0.01
model_l2 = keras.Sequential([
    keras.layers.Dense(128, activation='relu',
                       kernel_regularizer=reg,
                       input_shape=(X_train.shape[1],)),
    keras.layers.Dense(128, activation='relu', kernel_regularizer=reg),
    keras.layers.Dense(64, activation='relu', kernel_regularizer=reg),
    keras.layers.Dense(1)
])
model_l2.compile(optimizer='adam', loss='mse', metrics=['mae'])

histories['L2'] = train_and_eval(model_l2, 'L2')
```

Output:

```text
L2              | Train: 0.3985 | Val: 0.4704 | Gap: +0.0720

```

#### Cell 43 (markdown)

```markdown
### L1 vs L2

| 종류 | 페널티 | 효과 |
|------|--------|------|
| **L2 (Ridge)** | Σ wᵢ² | 가중치를 *작게* (0에 가깝게) |
| **L1 (Lasso)** | Σ \|wᵢ\| | 가중치를 *정확히 0*으로 (feature 선택) |

신경망에서는 **L2가 표준**.

### 하이퍼파라미터
- `l2(λ)`: λ는 보통 1e-4 ~ 1e-2
```

```markdown
## 3.3 Early Stopping

### 직관

Val loss가 *더 이상 개선되지 않으면* 학습을 멈춘다.
**"최선의 시점"에서 자동으로 정지** → 과적합 시점에 도달하기 전에 종료.
```

#### Cell 45 (code)

```python
from keras.callbacks import EarlyStopping

keras.utils.set_random_seed(42)
model_es = keras.Sequential([
    keras.layers.Dense(128, activation='relu', input_shape=(X_train.shape[1],)),
    keras.layers.Dense(128, activation='relu'),
    keras.layers.Dense(64, activation='relu'),
    keras.layers.Dense(1)
])
model_es.compile(optimizer='adam', loss='mse', metrics=['mae'])

es = EarlyStopping(
    monitor='val_loss',          # 감시할 지표
    patience=10,                 # 10 epoch 동안 개선 없으면 정지
    restore_best_weights=True    # 최선의 가중치로 복원 (필수!)
)

histories['EarlyStop'] = train_and_eval(model_es, 'EarlyStop', callbacks=[es])
print(f'  → 실제 학습된 epoch 수: {len(histories["EarlyStop"].history["loss"])}')
```

Output:

```text
EarlyStop       | Train: 0.0941 | Val: 0.3836 | Gap: +0.2895
  → 실제 학습된 epoch 수: 48

```

#### Cell 46 (markdown)

```markdown
### 핵심 옵션 3가지

| 옵션 | 의미 | 권장값 |
|------|------|--------|
| `monitor` | 무엇을 볼까 | `'val_loss'` (회귀), `'val_accuracy'` (분류) |
| `patience` | 몇 epoch 참을까 | 10~20 |
| `restore_best_weights` | 최선의 모델로 복원 | **반드시 True** |

### 왜 가장 실용적인가
- **하이퍼파라미터 거의 없음** (patience만 설정)
- **epochs를 크게 잡아도 안전** (학습 시간 자동 단축)
- **다른 정규화와 조합 가능** (서로 충돌하지 않음)

> 💡 **권장**: 새 문제에는 *항상* Early Stopping부터 적용한다.
```

#### Cell 47 (markdown)

```markdown
## 3.4 Batch Normalization

### 직관

각 층의 입력을 *미니배치 단위로 정규화* (평균 0, 분산 1):

```
Dense → BatchNorm → Activation → Dense → BatchNorm → Activation → ...
        ↑↑↑↑↑↑↑↑↑
        매 layer마다 입력 분포를 안정시킴
```

### 왜 효과적인가
1. **학습 안정성**: 각 층의 입력 분포가 일정
2. **약한 정규화 효과**: 미니배치마다 약간씩 다른 통계량 → 일종의 noise
3. **초기값 민감도 ↓**
```

#### Cell 48 (code)

```python
from keras.layers import BatchNormalization, Activation

keras.utils.set_random_seed(42)
model_bn = keras.Sequential([
    keras.layers.Dense(128, input_shape=(X_train.shape[1],)),  # activation 분리
    BatchNormalization(),
    Activation('relu'),
    keras.layers.Dense(128),
    BatchNormalization(),
    Activation('relu'),
    keras.layers.Dense(64),
    BatchNormalization(),
    Activation('relu'),
    keras.layers.Dense(1)
])
model_bn.compile(optimizer='adam', loss='mse', metrics=['mae'])

histories['BatchNorm'] = train_and_eval(model_bn, 'BatchNorm')
```

Output:

```text
BatchNorm       | Train: 0.1506 | Val: 0.3444 | Gap: +0.1938

```

#### Cell 49 (markdown)

```markdown
> 💡 **순서가 중요**: `Dense → BatchNorm → Activation` 순서가 표준.
> `Dense(activation='relu')`처럼 한 번에 쓰면 BN을 *활성화 후*에 적용하게 되어 효과 감소.
```
