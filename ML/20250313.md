## 1. 1강 복습 및 2강 개요

**1강 요약**
- **머신러닝:** 데이터 속 패턴 찾기. 톰 미첼 정의: 작업(T), 경험(E), 성능(P).
- **지도학습:** E = (x, y), T = y 예측(회귀·분류), P = 오차 최소화.
- **선형회귀:** \(\hat{y} = m x + b\), MSE 손실, 경사하강법으로 m, b 업데이트.
- **데이터사이언스:** 5단계(컨셉 → 데이터 프리퍼레이션 → 모델 플래닝 → 모델 빌딩 → 최종).

**2강에서 다룰 내용**
- **비지도 학습:** 정답 y 없이 x만으로 패턴 찾기(군집, 차원축소).
- **분류:** y가 범주(0/1, A/B/C)일 때 — 로지스틱 회귀로 확률·결정경계.
- **다변수 선형회귀:** \(\hat{y} = \theta_0 + \theta_1 x_1 + \cdots + \theta_p x_p\), 벡터/행렬 표기.
- **정규화·교차검증:** 과적합 완화, 일반화 성능 평가(간단 소개).

## 2. 비지도 학습 개요

**정의:** 경험 E에 **정답 레이블 y가 없다**. 입력 x만 주어졌을 때, 데이터 안의 **구조·패턴**을 찾는 학습.

| 구분 | 지도 학습 | 비지도 학습 |
|------|-----------|-------------|
| E | (x, y) 쌍 | x만 |
| T | y 예측(회귀/분류) | 군집, 차원축소, 밀도 추정 등 |
| P | 정답과의 오차(MSE, 정확도 등) | 재구성 오차, 군집 품질, 비지도 지표 |

**대표 작업**
- **군집화(Clustering):** 비슷한 x끼리 묶기. K-means, 계층적 군집 등. 레이블 없이 “그룹” 발견.
- **차원축소(Dimensionality reduction):** 고차원 x를 저차원 표현으로 압축. PCA, t-SNE 등. 시각화·노이즈 제거·저장량 절감.
- **밀도 추정:** 데이터가 어떤 분포에서 나왔는지 추정. 이상치 탐지 등에 활용.

**왜 쓰나:** 레이블이 없거나 비싼 경우, 탐색적 분석(EDA), 전처리(차원축소 후 지도학습) 등.

## 3. 분류 문제와 로지스틱 회귀

### 3.1 분류(Classification)란

기계학습에서 **분류**는 **지도학습(supervised)** 기법이다. “어떤 데이터가 **어떤 클래스**에 속하는가”를 다루며, **결과(출력)는 클래스**이고, 클래스는 **이산적인(discrete) 카테고리**로 구분된다. 주어진 데이터란, 그런 **클래스를 구분할 수 있는 특징(feature)**들을 입력으로 줄 수 있는 데이터를 말하고, 머신러닝에는 “어떤 특징 → 어떤 클래스”로 가야 한다는 **정답(레이블)**이 함께 주어진다. 학습은 이 정답지를 바탕으로 **특징과 클래스 사이의 관계**를 추론하는 과정이며, 그 결과 “어떤 특징을 넣으면 어떤 클래스에 속하는가”를 **예측**할 수 있게 되는 것이 곧 분류에서의 기계학습이다.

**쉽게 보면:** 분류는 결국 그리 어려운 개념이 아니다. 이메일을 보냈을 때 **스팸으로 처리될지 여부**, 어떤 **항목·카테고리**에 속하는지, **영상의학**에서 병변 유무·종류 판독처럼—“이런 것 있음/없음”, “A구역/B구역”처럼 **있는다/없는다** 또는 **어느 클래스인가**로 나누는 문제로 치환할 수 있다. 즉 **“있음/없음” 또는 “어떤 항목인가”라는 분류 문제**로 이해하면 된다.

### 3.2 분류 vs 회귀
- **회귀:** y가 연속값(숫자). 예: 집 값, 온도.
- **분류:** y가 **범주(클래스)**. 예: 스팸/정상(이진), 품종 A/B/C(다중).

### 3.3 로지스틱 회귀(Logistic Regression)
- **목표:** 이진 분류(y ∈ {0, 1}). 주어진 x에 대해 “1일 확률” \(P(y=1|x)\)를 추정.
- **가설:** 선형 함수 \(\theta^T x\)를 **시그모이드**에 넣어 0~1 사이 확률로 만든다.
  \[
  P(y=1|x) = h_\theta(x) = \sigma(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}}
  \]
- **시그모이드:** \(\sigma(z) = 1/(1+e^{-z})\). z가 크면 1에 가깝고, 작으면 0에 가깝다.
- **결정경계:** \(h_\theta(x) = 0.5\)인 곳이 경계. \(\theta^T x = 0\)이 되는 **초평면**이 클래스를 나눔.

**손실 함수**
- 회귀에서는 MSE. 분류에서는 **교차엔트로피(Cross-entropy)** 등으로 정의.
- 목적: 예측 확률이 정답 클래스에 가깝도록 \(\theta\)를 조정. 경사하강법(또는 Newton 등)으로 최적화.

**정리:** 분류는 “연속값 예측”이 아니라 “범주 확률·경계”를 학습. 로지스틱 회귀 = 선형 모델 + 시그모이드로 이진 분류.

### 3.4 나이브 베이즈 분류(Naive Bayes Classification)

**나이브 베이즈**는 **베이즈 정리**와 **특성의 조건부 독립 가정**으로, 주어진 입력 \(\mathbf{x}\)가 각 클래스에 속할 **사후확률** \(P(C_k|\mathbf{x})\)를 구해, 그중 가장 큰 클래스로 분류하는 알고리즘이다. 로지스틱 회귀는 \(P(y=1|\mathbf{x})\)를 선형·시그모이드로 직접 모델링하는 반면, 나이브 베이즈는 우도 \(P(\mathbf{x}|C_k)\)와 사전확률 \(P(C_k)\)를 이용해 베이즈 정리로 사후확률을 계산하고, 최대인 클래스를 고른다. 텍스트 분류(스팸/정상), 문서 카테고리 예측에서 자주 쓰이며, 가정이 단순해 학습·예측이 빠르고 구현이 쉽다는 장점이 있다.

**중요한 점:** 확률을 “구하는 것”이 중요해 보일 수 있지만, 나이브 베이즈에서 진짜 중요한 것은 **그 확률을 바탕으로 어떤 클래스인지 예측하는 것**이다. 즉 \(P(\text{Yes}|\cdots)\)와 \(P(\text{No}|\cdots)\)를 비교해 **더 큰 쪽 클래스로 찍어내는 것**이 목표다.

**나이브 베이즈 슬라이드 흐름 (한눈에):** (1) 베이즈 식 \(P(C_k|X)=P(X|C_k)P(C_k)/P(X)\) → (2) 가정: 피처들은 클래스가 주어졌을 때 서로 조건부 독립 → (3) 우도 \(P(X|C_k)\)를 \(\prod_i P(x_i|C_k)\)로 대입 → (4) 분모 \(P(X)\)는 모든 클래스에 공통이므로 **분자만** 클래스별로 계산해 \(\arg\max_{C_k}\)로 결정. 상세는 아래 §4와 동일.

## 4. 나이브 베이즈: 식 · 용어집 · 분모

### 4.1 베이즈 식과 조건부 독립

**베이즈 정리**
\[
P(C_k\,|\,X) = \frac{P(X\,|\,C_k)\,P(C_k)}{P(X)}.
\]
- **가정:** n개 피처로 구성된 벡터 \(X = (x_1, x_2, \ldots, x_n)\)에 대해, **클래스 \(C_k\)가 주어졌을 때** 각 피처는 **서로 조건부 독립**이다. 물론 실제로는 독립이 아닐 수 있으나, **우선 그렇게 가정**하여 식을 단순화한다.
- **우도 분해:** \(P(X\,|\,C_k) = P(x_1\,|\,C_k)\,P(x_2\,|\,C_k)\,\cdots\,P(x_n\,|\,C_k) = \prod_{i=1}^{n} P(x_i\,|\,C_k)\).
- **분류 규칙:** 분모 \(P(X)\)는 **모든 클래스에 공통**이므로, **분자만** 클래스별로 계산해 비교하면 된다. 예측은 **분자텀** \(P(C_k)\prod_{i=1}^{n} P(x_i\,|\,C_k)\)이 **가장 큰 \(C_k\)**를 고르는 것:
\[
\hat{C} = \arg\max_{C_k} \left\{ P(C_k) \times \prod_{i=1}^{n} P(x_i\,|\,C_k) \right\}.
\]

**분모 \(P(X)\)에 대해:** \(P(X)\)는 “입력 \(X\)가 관측될 전체 확률”로, 클래스와 무관하게 **공통**이다. **정확한 사후확률값**을 숫자로 쓰려면 전확률 법칙 \(P(X) = \sum_k P(X\,|\,C_k)\,P(C_k)\)로 구해야 하지만, **분류 단계**에서는 “어느 클래스가 최대인가”만 보면 되므로 분모는 **최대값 비교에 영향을 주지 않아** 깊게 다루지 않는다. **클래스피케이션 단에서는 최대값의 공통으로 두기에** 분모에 대해 다소 딥하게 다루지 않는다는 뜻이다.

### 4.2 용어집 (세부 정리)

| 용어 | 기호 | 의미 · 역할 |
|------|------|-------------|
| **사전확률** | \(P(C_k)\) | 클래스 \(C_k\)가 데이터에서 차지하는 **비율**. 기존 데이터·전문가 지식으로 추정. “클래스 분포 자체”가 예측에 중요한 변수. |
| **우도** | \(P(x_i\,|\,C_k)\) | **클래스 \(C_k\)가 주어졌을 때** 피처 \(x_i\)가 관측될 확률. 클래스별로 각 피처의 출현 비율로 추정. |
| **사후확률** | \(P(C_k\,|\,X)\) | **새 입력 \(X\)가 주어졌을 때** 그 입력이 클래스 \(C_k\)에 속할 확률. 베이즈 식으로 사전×우도(곱)를 \(P(X)\)로 나눔. |
| **결정** | \(\hat{C}\) | 사후확률이 최대인 클래스를 선택. 실전에서는 **분자** \(P(C_k)\prod_i P(x_i\,|\,C_k)\)만 비교: \(\hat{C} = \arg\max_{C_k} \bigl( P(C_k) \prod_{i=1}^{n} P(x_i\,|\,C_k) \bigr)\). |

**보강:** **사전확률** — 어떤 데이터가 오던간에 **클래스 분포 자체**가 예측에 중요한 변수가 된다. 예: 이메일 중 스팸이 20%라면 \(P(\text{Spam})=0.2\). **우도** — 클래스가 주어졌을 때 그 피처(또는 단어)가 나올 확률. 예: 스팸일 때 단어 "free"가 나올 확률 \(P(\text{"free"}\,|\,\text{Spam})\).

### 4.3 Play 문제에 적용 (Weather is good to play or not)

- **예측 조건 (예시):** "Outlook=Sunny, Temp=Cool, Humidity=High, Windy=True 일 때 Play Yes인가 No인가?" — 이 조건에서 \(P(\text{Play=Yes}\,|\,\text{Conditions})\)와 \(P(\text{Play=No}\,|\,\text{Conditions})\)를 비교한다.
- **3단계:** (1) **사전:** \(P(\text{Play=Yes})=9/14\), \(P(\text{Play=No})=5/14\) (전체 14일 중 9일 Yes, 5일 No). (2) **우도:** Yes인 9일 기준 \(P(\text{Sunny}\,|\,\text{Yes})=2/9\), \(P(\text{Cool}\,|\,\text{Yes})=3/9\) 등; **Play=No**에 대해서도 동일하게 \(P(\text{Sunny}\,|\,\text{No})\), \(P(\text{Cool}\,|\,\text{No})\) 등 각각 구함(슬라이드에 omit 되어 있으나 필수). (3) **사후:** \(P(\text{Yes}\,|\,\text{Conditions}) = \frac{P(\text{Conditions}\,|\,\text{Yes})\,P(\text{Yes})}{P(\text{Conditions})}\), \(P(\text{No}\,|\,\text{Conditions}) = \frac{P(\text{Conditions}\,|\,\text{No})\,P(\text{No})}{P(\text{Conditions})}\). 분모는 \(P(\text{Conditions}) = P(\text{Conditions}\,|\,\text{Yes})\,P(\text{Yes}) + P(\text{Conditions}\,|\,\text{No})\,P(\text{No})\)로 구할 수 있으나, **분류**에서는 분자만 비교하면 된다.
- **입력:** 4개 피처 — Outlook, Temp(카테고리: Hot/Mild/Cool), Humidity, Windy. **출력:** Play = Yes / No (이진 분류).
- **적용 방식:** 클래스(Yes/No)가 주어졌을 때 각 피처의 확률을 **각각** 구한 뒤 **전부 곱**한다. Play=**Yes**일 때만 예를 들면: \(P(\text{Outlook=Sunny}\,|\,\text{Yes})=2/9\), \(P(\text{Temp=Cool}\,|\,\text{Yes})=3/9\), \(P(\text{Humidity=High}\,|\,\text{Yes})=3/9\), \(P(\text{Windy=True}\,|\,\text{Yes})=3/9\) 등(Yes인 9일 기준). **Play=No**에 대해서도 동일하게 \(P(\text{Outlook=Sunny}\,|\,\text{No})\), \(P(\text{Windy=True}\,|\,\text{No})\) 등 **각각 구해줘야** 한다. 이유는 **사후확률**을 Yes에 대해서도, No에 대해서도 만들기 위해서다.
- **사후확률과 결정:** 원래 묻는 건 “이 조건이 주어졌을 때 Play=Yes일 확률이 얼마냐?”이지만, **분류**에서는 **분자만** 구하면 된다. Yes일 때 분자 \(P(\text{Conditions}\,|\,\text{Yes})\,P(\text{Yes})\)와 No일 때 분자 \(P(\text{Conditions}\,|\,\text{No})\,P(\text{No})\)를 각각 구한 뒤, **Yes가 더 크냐, No가 더 크냐**만 비교해 더 큰 쪽을 선택한다. 이렇게 **분자텀만 가지고 클래스 중 가장 높은 쪽을 찍어내는 것**이 나이브 베이즈 분류다.

**질병–증상 예제 (전개):** \(P(D\,|\,S_1,S_2) = \frac{P(S_1,S_2\,|\,D)\,P(D)}{P(S_1,S_2)}\). 조건부 독립 가정: \(P(S_1,S_2\,|\,D)=P(S_1\,|\,D)\,P(S_2\,|\,D)\), \(P(S_1,S_2\,|\,\neg D)=P(S_1\,|\,\neg D)\,P(S_2\,|\,\neg D)\). 전확률: \(P(S_1,S_2)=P(S_1,S_2\,|\,D)P(D)+P(S_1,S_2\,|\,\neg D)P(\neg D) = P(S_1\,|\,D)P(S_2\,|\,D)P(D)+P(S_1\,|\,\neg D)P(S_2\,|\,\neg D)P(\neg D)\). 수치 예(이미지 기준): \(0.8\times 0.7\times 0.01 + 0.1\times 0.2\times 0.99\) (원문에서 \(P(S_1\,|\,D)=0.01\)과 계산식의 0.8 불일치 시 원문 확인). 분류 시에는 분자만 비교하면 된다.

*(참고: 위와 동일하게 질병 D와 증상 S1, S2 예제에서도 분모 \(P(S_1,S_2)\)는 전확률 법칙으로 구할 수 있으나 분류 시에는 분자만 비교하면 된다.)*

### 4.4 가우시안 나이브 베이즈 (Gaussian Naive Bayes) — 나이브 베이즈에서 어떻게 이어지는가

**나이브 베이즈 → 가우시안 나이브 베이즈:** 앞에서 우도 \(P(x_i\,|\,C_k)\)를 “클래스가 주어졌을 때 피처가 관측될 확률”이라고만 두었는데, **피처가 연속값일 때**는 이 확률을 **어떤 분포로 정의할지**가 필요하다. 그때 **피처의 우도가 가우시안(정규) 분포를 따른다고 가정**할 때 쓰는 형태가 **가우시안 나이브 베이즈**다.

**가우시안(정규분포) 가정의 니즈:**  
- **연속형 피처**는 이산 개수로 세는 게 아니라 구간·밀도로 다뤄야 하므로, \(P(x_i\,|\,y)\)를 하나의 “수”가 아니라 **확률 밀도**로 모델링해야 한다.  
- 정규분포를 쓰면 **평균 \(\mu\)**와 **분산 \(\sigma^2\)** 두 파라미터만으로 분포가 정해지고, 수식이 단순해 학습·예측이 쉽다.  
- **피처가 실제로 정규분포를 따르지 않더라도**, 나이브 베이즈에서는 **피처 각각**이 클래스가 주어졌을 때 **정규분포를 따른다고 가정**한다. (산점도·분포에서 각 입력 변수는 클래스 조건 하에 서로 독립이라 했듯이, “각 피처별로 클래스 내 분포”를 정규로 두는 것이다.)

**정규분포를 결정하는 요소:** **평균 \(\mu_y\)**와 **분산 \(\sigma_y^2\)**. 클래스 \(y\)에 대해, 그 클래스 안에서 피처 \(x_i\)의 평균과 분산을 추정해 우도를 계산한다.

**우도 공식 (가우시안 PDF):** 클래스 \(y\)가 주어졌을 때 피처 \(x_i\)의 값이 관측될 **확률 밀도**는, 해당 클래스 내 피처의 평균 \(\mu_y\)와 분산 \(\sigma_y^2\)로 정의된 가우시안 함수로 계산한다.
\[
P(x_i\,|\,y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} \exp\left(-\frac{(x_i - \mu_y)^2}{2\sigma_y^2}\right).
\]
- **\(x_i\):** 피처 값 (연속).
- **\(\mu_y\):** 클래스 \(y\)에 대한 그 피처의 **평균**.
- **\(\sigma_y^2\):** 클래스 \(y\)에 대한 그 피처의 **분산**.
- **\(P(y)\):** 클래스 \(y\)의 사전확률 (베이즈 식에서 그대로 사용).

**가장 중요한 점 — 피처 타입에 따라 우도를 달리 정의하는 능력:**  
클래스피케이션의 **결과(출력)**는 항상 **이산·카테고리(디스크리트)**뿐이다. 반면 **입력 피처**는 연속값일 수도, 이산·범주일 수도, 그 외일 수도 있다. **카테고리컬이 아닌 연속형 데이터**에 대해 확률(우도)을 구하기 위해서 **가우시안(정규분포)**을 쓰게 된다. 그래서 **피처가 연속이냐, 이산/범주이냐, 다른 타입이냐에 따라** 우도 \(P(x_i\,|\,C_k)\)를 **달리 적용·정의하는 능력**이 가장 중요하다.  
- **연속형 피처** → 가우시안 나이브 베이즈: 위 식처럼 정규분포로 \(P(x_i\,|\,y)\) 정의.  
- **이산·범주형 피처** (예: Play 문제의 Outlook, Temp) → 출현 비율·멀티노미얼/베르누이 등으로 우도 정의.  
즉, “나이브 베이즈”라는 뼈대는 같고, **피처 종류에 맞게 우도만 바꿔 끼우는 것**이 가우시안/멀티노미얼 나이브 베이즈로 이어지는 구조다.

**예측(Predict) 흐름 — conditional(우도)과 최종적으로 맥시멈값(argmax):**  
`predict` 같은 메소드를 보면, 예측 시 **항상 conditional(즉 likelihood, 우도)**을 구하게 된다. 각 클래스에 대해 사전확률 \(P(C_k)\)와 우도 \(\prod_i P(x_i\,|\,C_k)\)를 곱해 **사후확률**에 비례하는 값을 얻고, **최종적으로 그중 가장 큰 클래스**를 고른다. 즉 **맥시멈값을 취하는 것(argmax)**이 핵심이다. “어느 클래스가 최대인가?”만 알면 되므로, 첨부한 구현처럼 \(\hat{C} = \arg\max_{C_k} \bigl( P(C_k) \prod_i P(x_i\,|\,C_k) \bigr)\)에서 **argmax**로 최종 예측을 내는 부분을 반드시 이해해야 한다.

**사후확률 계산 시 곱셈이 덧셈으로 바뀌는 이유 — 로그 사용:**  
이전에는 사후에 비례하는 값을 **곱셈** \(P(C_k)\prod_i P(x_i\,|\,C_k)\)으로 구했다. 그런데 **구현(코딩)에서는 사후확률을 구할 때 더해준다**. 왜 그럴까? **Prior(사전확률)**와 **Likelihood(우도)** 각 항에 **로그(log)**를 취했기 때문이다. 조건부 독립이므로 각 \(P(x_i\,|\,C_k)\)는 다 구한 뒤, 여기서는 그 값들을 **로그값으로 치환**해서 다룬다.  
- **수식:** \(\log\bigl(P(C_k)\prod_i P(x_i\,|\,C_k)\bigr) = \log P(C_k) + \sum_i \log P(x_i\,|\,C_k)\). 즉 **곱셈이 덧셈**으로 바뀐다.  
- **정확한 확률값은 안 나온다:** 로그를 취하면 절대적인 사후확률 숫자는 나오지 않아 의아할 수 있다. 다만 **상대적인 크기(비율, ratio)**는 로그에서도 유지되므로, **어느 클래스가 최대인지**는 그대로다. 분류에서는 **상대값·비율**이 중요하므로 로그로 계산해도 된다.  
- **코딩 측면:** 곱셈보다 **덧셈**이 수치적으로 안정하고 구현하기 수월하다. 매우 작은 확률을 여러 번 곱하면 언더플로우(underflow)가 나기 쉽고, 로그 공간에서 덧셈으로 바꾸면 이를 피할 수 있다.  
정리하면, “prior와 likelihood에 로그를 취해 로그값으로 치환했기 때문에” 사후에 비례하는 값이 **곱이 아니라 합**으로 구해지고, 그 합(로그 사후) 중 **최대인 클래스**를 argmax로 선택하는 것이 실전 구현이다.

### 4.5 구현 코드 및 해설 (Iris · 가우시안 나이브 베이즈)

슬라이드에 나온 **가우시안 나이브 베이즈** 클래스와 **Iris 데이터셋** 사용 예시를 코드로 넣고, 구간별로 해설한다.

---

#### (1) 클래스 정의 · 초기화

```python
import numpy as np

class GaussianNB:
    def __init__(self):
        self.classes = None      # 타깃 클래스 레이블 (예: [0,1,2])
        self.mean = None        # 클래스별 피처 평균 (클래스수 × 피처수)
        self.var = None         # 클래스별 피처 분산 (클래스수 × 피처수)
        self.priors = None      # 클래스별 사전확률 P(y)
```

**해설:** 가우시안 나이브 베이즈는 **클래스 종류**, **클래스별 피처 평균·분산**, **사전확률**만 저장하면 된다. 정규분포를 결정하는 요소가 평균과 분산이므로 `mean`, `var`가 핵심 속성이다.

---

#### (2) 학습 — `fit(self, X, y)`

```python
    def fit(self, X, y):
        self.classes = np.unique(y)
        n_classes = len(self.classes)
        n_features = X.shape[1]
        self.mean = np.zeros((n_classes, n_features))
        self.var = np.zeros((n_classes, n_features))
        self.priors = np.zeros(n_classes)

        for idx, c in enumerate(self.classes):
            X_c = X[y == c]                          # 클래스 c에 속하는 샘플만
            self.mean[idx, :] = X_c.mean(axis=0)      # 클래스 c 내 각 피처의 평균
            self.var[idx, :] = X_c.var(axis=0)       # 클래스 c 내 각 피처의 분산
            self.priors[idx] = X_c.shape[0] / float(X.shape[0])  # P(y=c)
```

**해설:**  
- **입력:** `X`는 (샘플 수 × 피처 수), `y`는 클래스 레이블.  
- **클래스별로** 해당 클래스에 속하는 행만 모아 `X_c`로 두고, **평균·분산**을 `axis=0`으로 구해 저장한다. 즉 "피처 각각이 클래스가 주어졌을 때 정규분포를 따른다"는 가정 아래, 그 정규분포를 결정하는 **평균·분산**을 학습하는 부분이다.  
- **사전확률** \(P(y=c)\)는 "전체 중 클래스 c 비율"로 추정한다.

---

#### (3) 우도(확률 밀도) — `_pdf(self, class_idx, x)`

```python
    def _pdf(self, class_idx, x):
        mean = self.mean[class_idx]
        var = self.var[class_idx]
        numerator = np.exp(- (x - mean) ** 2 / (2 * var))
        denominator = np.sqrt(2 * np.pi * var)
        return numerator / denominator
```

**해설:**  
- **역할:** 클래스 `class_idx`가 주어졌을 때 입력 벡터 `x`(각 피처 값)에 대한 **가우시안 확률 밀도** \(P(x_i\,|\,y)\)를 계산한다.  
- **수식:** \(P(x_i\,|\,y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} \exp\bigl(-\frac{(x_i-\mu_y)^2}{2\sigma_y^2}\bigr)\).  
- `numerator`는 지수 부분, `denominator`는 정규화 상수. 연속형 데이터에 대해 확률을 구하기 위해 가우시안(정규) PDF를 쓰는 부분이다.

---

#### (4) 단일 샘플 예측 — `_predict(self, x)` (conditional · 로그 · argmax)

```python
    def _predict(self, x):
        posteriors = []
        for idx, c in enumerate(self.classes):
            prior = np.log(self.priors[idx])              # log P(y)
            conditional = np.sum(np.log(self._pdf(idx, x)))  # sum_i log P(x_i|y)
            posterior = prior + conditional               # 로그 공간에서 곱 → 합
            posteriors.append(posterior)
        return self.classes[np.argmax(posteriors)]       # 맥시멈값으로 클래스 선택
```

**해설:**  
- **항상 conditional(우도)을 구한다:** 각 클래스에 대해 `_pdf`로 \(P(x_i\,|\,y)\)를 구한 뒤, 조건부 독립이므로 그 곱이 우도다.  
- **로그로 치환:** \(P(y)\prod_i P(x_i\,|\,y)\) 대신 \(\log P(y) + \sum_i \log P(x_i\,|\,y)\)를 계산한다. 곱셈이 덧셈으로 바뀌어 수치 안정성·구현이 수월해지고, 상대 크기만 유지하면 되므로 argmax에는 로그값으로 충분하다.  
- **최종:** `posteriors`는 클래스별 "로그 사후에 비례하는 값"의 리스트. **맥시멈값을 취하는 것**이 핵심이므로 `np.argmax(posteriors)`로 최대 인덱스를 구하고, 그에 해당하는 클래스를 반환한다.

---

#### (5) 배치 예측 — `predict(self, X)`

```python
    def predict(self, X):
        y_pred = [self._predict(x) for x in X]
        return np.array(y_pred)
```

**해설:** 입력 배열 `X`의 **각 행(인스턴스)**에 대해 `_predict`를 호출해 클래스를 예측하고, 결과를 하나의 배열로 묶어 반환한다.

---

#### (6) Iris 데이터셋으로 학습·예측·평가

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report

# 데이터 로드 (연속형 피처 4개, 클래스 3종)
iris = load_iris()
X, y = iris.data, iris.target

# 훈련/테스트 분할
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 가우시안 나이브 베이즈: 학습 후 예측
model = GaussianNB()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# 정확도 및 분류 리포트
print(f"Accuracy: {accuracy_score(y_test, y_pred) * 100:.2f}%")
print(classification_report(y_test, y_pred, target_names=iris.target_names))
```

**해설:**  
- **Iris:** 꽃받침·꽃잎 길이/너비 등 **연속형 피처**, 품종(클래스)은 **이산 카테고리**. 연속형 데이터에 대해 확률(우도)을 구하기 위해 가우시안 나이브 베이즈를 쓰는 대표 예이다.  
- **흐름:** 데이터 분할 → `fit`으로 클래스별 평균·분산·사전확률 학습 → `predict`로 각 테스트 샘플에 대해 conditional(우도) 계산 후 **argmax**로 클래스 선택 → 정확도·리포트로 평가.

---

**전체 개괄:**  
위 코드는 (1) **초기화**에서 클래스·평균·분산·사전확률을 담을 구조를 두고, (2) **fit**에서 클래스별 평균·분산·사전확률을 추정하고, (3) **_pdf**에서 가우시안 PDF로 우도(확률 밀도)를 구하며, (4) **_predict**에서 prior·likelihood에 로그를 취해 **곱을 합으로** 바꾼 뒤 **argmax**로 최종 클래스를 고르고, (5) **predict**는 그걸 배치로 반복한다. Iris 예시는 이 흐름을 연속형 데이터에 적용해 학습·예측·평가까지 한 번에 보여준다.

## 5. 다변수 선형회귀

**설정:** 입력이 **여러 개**일 때. \(x = (x_1, x_2, \ldots, x_p)\), 각각 특성(feature) 하나.

**모델**
\[
\hat{y} = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_p x_p = \theta^T x
\]
(\(x_0=1\) 편향 항 포함해 벡터로 쓰면 \(\theta^T x\).)

**행렬 표기**
- 데이터 n개, 특성 p개: 설계행렬 \(X \in \mathbb{R}^{n \times (p+1)}\), 타깃 \(\mathbf{y} \in \mathbb{R}^n\).
- 예측: \(\hat{\mathbf{y}} = X\theta\).
- MSE: \(L(\theta) = \frac{1}{n}\| \mathbf{y} - X\theta \|^2\).

**학습**
- **경사하강법:** 1강과 동일한 아이디어. \(L\)을 \(\theta\)에 대해 미분한 뒤 반대 방향으로 업데이트.
- **정규방정식(선형회귀만):** \(\frac{\partial L}{\partial \theta} = 0\)을 풀면 \(\theta^* = (X^T X)^{-1} X^T \mathbf{y}\). 한 번에 해를 구할 수 있음(역행렬 존재 시).

**정리:** 변수가 여러 개여도 “목적함수(MSE) + 경사하강(또는 정규방정식)” 구조는 동일. 벡터·행렬로 일괄 계산.

---

## 6. 정규화와 교차검증 소개

**과적합(Overfitting)**
- 학습 데이터에서는 오차가 작은데, **새 데이터**에서는 오차가 커지는 현상.
- 원인: 모델이 데이터의 노이즈까지 맞추려 함(파라미터가 너무 많거나 복잡).

**정규화(Regularization)**
- 손실에 **파라미터 크기 패널티**를 더해, 과도하게 큰 \(\theta\)를 억제.
- **Ridge(L2):** \(L + \lambda \|\theta\|^2\). 계수를 작게 유지.
- **Lasso(L1):** \(L + \lambda \|\theta\|_1\). 일부 계수를 정확히 0으로 만들어 변수 선택 효과.
- \(\lambda\): 정규화 강도(하이퍼파라미터).

**교차검증(Cross-validation)**
- 데이터를 **train / validation(또는 test)** 로 나누고, 학습은 train만 사용.
- **K-fold:** 데이터를 K묶음으로 나누어, 돌아가며 한 묶음을 검증용으로 쓰고 나머지로 학습. K번의 성능을 평균해 **일반화 성능** 추정.
- 목적: 모델·하이퍼파라미터 선택 시 “실제로 새 데이터에 잘 맞는지” 확인.

**정리:** 2강에서는 개념만. 구체적 수식·실습은 다음 강의에서 다변수 회귀·로지스틱과 함께 진행 가능.

## 7. 복습 및 다음 강의 플랜

**2강 복습**
- **비지도 학습:** y 없이 x만으로 군집·차원축소·밀도 추정.
- **분류:** 로지스틱 회귀 — 시그모이드로 \(P(y=1|x)\) 추정, 결정경계 \(\theta^T x = 0\). 분류란 지도학습, 클래스=이산 카테고리, 특징–클래스 관계 추론 → 예측. 쉽게 보면 스팸/영상의학 등 “있음·없음” 문제로 치환 가능.
- **나이브 베이즈:** 사전확률 \(P(C_k)\), 우도 \(P(x_i\,|\,C_k)\), 조건부 독립 → \(P(X\,|\,C_k)=\prod_i P(x_i\,|\,C_k)\). 분모 \(P(X)\)는 공통이라 분류 시 분자만 비교. Play 문제(예측 조건·3단계·\(P(\text{Conditions})\)). 질병–증상 예제 전개. **가우시안 나이브 베이즈:** 카테고리컬이 아닌 **연속형 데이터**에 대해 확률을 구하기 위해 가우시안 사용. 평균 \(\mu_y\)·분산 \(\sigma_y^2\)로 \(P(x_i\,|\,y)\) 계산. **Predict:** 항상 conditional(likelihood) 구함 → 사후에 비례하는 값 → **argmax(맥시멈값)** 취하는 것이 핵심. **로그 사용:** prior·likelihood에 로그 취하면 곱→합; 정확한 확률값은 안 나오지만 **상대값·비율(ratio)**이 중요하므로 로그로 충분; 코딩 시 덧셈이 곱셈보다 수월·안정(언더플로우 방지).
- **다변수 선형회귀:** \(\hat{y} = \theta^T x\), MSE + 경사하강 또는 정규방정식.
- **정규화·교차검증:** 과적합 완화, 일반화 평가(간단 소개).

**다음 강의 예정**
- 로지스틱 회귀 손실(교차엔트로피) 유도 및 경사하강.
- 나이브 베이즈: 베이즈 정리·조건부 독립 가정·우도 모델(멀티노미얼, 가우시안 등), Play/스팸 손계산.
- K-means 등 비지도 알고리즘 하나 골라 실습.
- Ridge/Lasso 수식 및 교차검증 실습(코드 또는 손계산).
- 데이터사이언스 5단계와 연결: “어떤 단계에서 분류/비지도/정규화를 쓰는가”.

### 디벨롭된 내용 (이번 세션에서 반영한 것)

**퀴즈 일정**  
2강 상단에 퀴즈 1(3/19 목 수업 20분 전), 퀴즈 2(3/26 목 수업 20분 전)를 명시.

**분류(§3.1)**  
- 분류의 정의: 지도학습, “어떤 데이터가 어떤 클래스에 속하는가”, 결과=클래스(이산 카테고리). 주어진 데이터=클래스를 구분할 수 있는 특징들을 입력으로 주는 데이터, 정답(레이블)=“어떤 특징→어떤 클래스”. 학습=정답지를 바탕으로 특징–클래스 관계 추론 → “어떤 특징을 넣으면 어떤 클래스에 속하는가” 예측.  
- 쉽게 보면: 분류는 어렵지 않다. 이메일 스팸 여부, 항목·카테고리, 영상의학 병변 유무·종류처럼 “있음/없음” 또는 “어떤 항목인가”로 치환 가능.

**로지스틱 회귀(§3.2–3.3)**  
분류 vs 회귀(연속 vs 범주), 이진 분류에서 \(P(y=1|x)=\sigma(\theta^T x)\), 시그모이드·결정경계 \(\theta^T x=0\), 손실=교차엔트로피·경사하강. (2강 기존 골격 유지.)

**나이브 베이즈 소개 및 강조(§3.4)**  
- 나이브 베이즈=베이즈 정리+특성의 조건부 독립 가정으로 사후확률 구해 최대 클래스로 분류. 로지스틱과의 차이(우도·사전으로 사후 계산 vs 선형·시그모이드 직접 모델링). 스팸/문서 분류, 구현 용이.  
- **핵심 강조:** 확률을 “구하는 것”보다 **그 확률을 바탕으로 어떤 클래스인지 예측하는 것**이 중요. \(P(\text{Yes}|\cdots)\) vs \(P(\text{No}|\cdots)\) 비교해 더 큰 쪽으로 찍어내는 것이 목표.
- **슬라이드 흐름:** (1) 베이즈 식 → (2) 가정(피처 조건부 독립) → (3) 우도 곱 대입 → (4) 분자만 arg max로 결정.

**나이브 베이즈: 식·용어집·분모(§4 전체)**  
- **베이즈 식:** \(P(C_k|X) = P(X|C_k)P(C_k)/P(X)\). 가정: 클래스 \(C_k\)가 주어졌을 때 n개 피처는 서로 조건부 독립 → 우도 분해 \(P(X|C_k)=\prod_{i=1}^{n} P(x_i|C_k)\).  
- **분류 규칙:** 분모 \(P(X)\)는 모든 클래스에 공통이므로 **분자만** 비교. \(\hat{C} = \arg\max_{C_k} \bigl( P(C_k) \prod_{i=1}^{n} P(x_i|C_k) \bigr)\). 즉 분자텀만 구해 최대인 \(C_k\)를 찍어내는 것이 나이브 베이즈 분류.  
- **분모 P(X):** “입력 X가 관측될 전체 확률”, 클래스와 무관해 공통. 정확한 사후확률값을 쓰려면 전확률 \(P(X)=\sum_k P(X|C_k)P(C_k)\)로 구해야 하나, **분류 단계**에서는 최대값만 비교하면 되므로 분모는 깊게 다루지 않음.  
- **용어집(표):** 사전확률 \(P(C_k)\)(클래스 비율, 데이터·전문가 기준), 우도 \(P(x_i|C_k)\)(클래스 주어졌을 때 피처 \(x_i\) 관측 확률), 사후확률 \(P(C_k|X)\)(입력 X 주어졌을 때 클래스 \(C_k\)일 확률), 결정 \(\hat{C}\)(분자만 비교한 arg max).  
- **Play 문제 적용:** 입력=4개 피처(Outlook, Temp 카테고리, Humidity, Windy), 출력=Play Yes/No. 클래스(Yes/No)가 주어졌을 때 각 피처 확률을 각각 구해 전부 곱. Yes일 때 예: Sunny|Yes=2/9, Cool|Yes=3/9 등(9일 기준). **Play=No도 동일하게** 각 우도 구해야 함(사후 Yes·No 둘 다 만들기 위해). 분류 시에는 Yes 분자 vs No 분자만 비교해 큰 쪽 선택.  
- **질병–증상 예제 전개:** \(P(D|S_1,S_2)\) 베이즈 식, 조건부 독립, 전확률 \(P(S_1,S_2)\) 식, 수치 \(0.8\times 0.7\times 0.01 + 0.1\times 0.2\times 0.99\). 분류 시 분자만 비교.

**가우시안 나이브 베이즈(§4.4)**  
- **연속형 데이터 → 가우시안:** 카테고리컬이 아닌 **연속형 데이터**에 대해 확률(우도)을 구하기 위해 가우시안(정규분포) 클래스를 쓰게 된다.  
- 가우시안 가정의 니즈: 연속형 피처는 확률밀도로 모델링; 정규분포는 평균·분산으로 결정되어 단순. 피처가 실제로 정규를 따르지 않더라도 클래스별로 정규라 가정.  
- 정규분포 결정 요소: **평균 \(\mu_y\)**, **분산 \(\sigma_y^2\)**. 공식 \(P(x_i|y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} \exp\bigl(-\frac{(x_i-\mu_y)^2}{2\sigma_y^2}\bigr)\).  
- **Predict 흐름:** 메소드를 보면 항상 **conditional(likelihood)**를 구함 → 사후에 비례하는 값 계산 → **최종적으로 맥시멈값(argmax)**을 취하는 것이 중요.  
- **사후확률 계산 시 곱→합(로그):** 원래는 곱해서 구하는데 구현에서는 **더해준다**. Prior와 Likelihood에 **로그**를 취했기 때문. 조건부 독립으로 각 우도는 다 구한 뒤 **로그값으로 치환**. \(\log(P(C_k)\prod_i P(x_i|C_k)) = \log P(C_k) + \sum_i \log P(x_i|C_k)\). 로그를 쓰면 정확한 확률값은 안 나오지만 **상대값·비율(ratio)**이 중요하므로 로그로 충분; **코딩 시** 곱셈보다 **덧셈**이 수월하고 안정(언더플로우 방지).

**구현 코드 및 해설(§4.5)**  
슬라이드/Iris 예시 코드를 코드 라인으로 넣고 각각 해설. (1) **초기화** `__init__`: classes, mean, var, priors. (2) **fit**: 클래스별 X_c 추출 → mean·var(axis=0), 사전확률 비율. (3) **_pdf**: 가우시안 PDF \(P(x_i|y)\) (numerator/denominator). (4) **_predict**: prior·conditional 로그 → posterior = prior + conditional → **argmax**로 클래스 반환. (5) **predict**: 각 행에 _predict 적용. (6) **Iris**: load_iris, train_test_split, fit/predict, accuracy_score·classification_report. **전체 개괄:** 초기화 → fit(평균·분산·사전) → _pdf(우도) → _predict(로그·argmax) → predict(배치) → Iris로 학습·예측·평가.

**다변수 선형회귀·정규화·교차검증(§5–§6)**  
\(\hat{y}=\theta^T x\), MSE, 경사하강·정규방정식. 과적합, Ridge/Lasso, K-fold. (2강 기존 분량 유지.)
