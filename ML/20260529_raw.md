Deep Neural Networks
• How is deep learning different from neural networks?
The “deep” in deep learning is referring to the depth of layers in a neural network. A neural network that consists of
more than three layers—which would be inclusive of the inputs and the output—can be considered a deep learning
algorithm.
• How is deep learning different from machine learning?
Deep learning automates much of the feature extraction piece of the process, eliminating some of the manual human
intervention required. It also enables the use of large data sets referring “scalable learning”. This capability will be
particularly interesting as we begin to explore the use of unstructured data more.

## Page 18

[Keras in Python]
• Keras is a high-level deep learning library written in Python that allows users to build and train neural networks
easily and intuitively.
• Originally developed as an independent library, it is now fully integrated into TensorFlow as tf.keras, making it one
of the most accessible tools for deep learning.
• Keras is designed for rapid experimentation and prototyping, enabling developers and researchers to create
powerful machine learning models with minimal code.
• At its core, Keras provides a simple and modular way to construct neural networks.
• The most common way to build a model is using the Sequential API, where layers are added one after another in
a linear stack.
• For more complex architectures, Keras also supports a functional API that allows for building models with multiple
inputs, outputs, or shared layers.
• Common layers like Dense, Conv2D, and LSTM are available for various types of tasks such as regression, image
classification, or sequence modeling.
• To train a model, Keras provides a clean workflow: first, you define the model structure; then you compile it by
specifying the optimizer, loss function, and evaluation metrics; finally, you train it using the .fit() method.
• The entire training process can be monitored and evaluated easily with built-in tools.

[Cross Entropy]
• Given two random variables X,Y and their respective distributions p,g
• Why use the Loss function to minimize Cross Entropy in classification?
✓ In supervised learning classification problems, we need to ensure that the ŷ (q) predicted by machine learning
follows a given distribution of labelings y(p).
✓ Take a look into Kullback-Leibler divergence) that is measuring the difference of two distributions
✓ -H(p), that is entropy of p, is fixed,
so CE minimization is has the same purpose of minimization of KL divergence
