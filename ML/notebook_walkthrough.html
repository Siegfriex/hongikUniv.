import numpy as np
import matplotlib.pyplot as plt

셀 3

네트워크 만들고 가중치를 강의 슬라이드와 동일하게 설정

학생들이 손계산한 결과와 비교 가능하도록, 슬라이드와 같은 가중치로 고정합니다.

# 슬라이드와 동일한 설정
mlp = MLP(n_input=2, n_hidden=2, n_output=1)
mlp.W1 = np.array([[0.1, 0.2], [0.3, 0.4]])
mlp.b1 = np.array([0.0, 0.0])
mlp.W2 = np.array([[0.5, 0.6]])
mlp.b2 = np.array([0.0])

x = np.array([1.0, 1.0])
y = np.array([0.0])

cache = mlp.forward_with_cache(x)
print("Forward pass 결과:")
print(f"  z⁽¹⁾ = {cache['z1']}")
print(f"  a⁽¹⁾ = {cache['a1']}")
print(f"  z⁽²⁾ = {cache['z2']}")
print(f"  a⁽²⁾ = {cache['a2']}")

L = 0.5 * (y - cache['a2'])**2
print(f"\nLoss L = {L[0]:.4f}")
처음 등장 np.array 행렬·벡터 만들기

수학의 행렬·벡터를 그대로 코드로 옮긴 것. 대괄호로 행을 감쌉니다.

np.array([0.1, 0.2]) = 원소 2개짜리 벡터.
np.array([[0.1, 0.2], [0.3, 0.4]]) = 2행 2열 행렬.

처음 등장 cache['a1'] dict에서 값 꺼내기

cache는 "이름표 붙은 사물함"입니다. cache['a1']은 "a1 칸에 든 값 꺼내기"라는 뜻.

forward_with_cache가 z1, a1, z2, a2 등을 한 dict로 묶어 돌려주기 때문에, 필요한 값을 이름으로 꺼냅니다.

이 셀이 하는 일:

코드 줄의미
mlp = MLP(...) 2-2-1 신경망 한 개를 만든다 (랜덤 가중치로 초기화됨).
mlp.W1 = np.array(...) 방금 만든 랜덤 가중치를 슬라이드 값으로 덮어쓴다.
cache = mlp.forward_with_cache(x) 입력 x를 넣어 예측하고, 중간값을 cache에 받는다.
예상 출력 (학생 손계산과 비교) Forward pass 결과: z⁽¹⁾ = [0.3 0.7] a⁽¹⁾ = [0.5744 0.6682] z⁽²⁾ = [0.6881] a⁽²⁾ = [0.6881] Loss L = 0.2368
검증 포인트 a²와 L이 슬라이드 5의 손계산 결과(0.6881, 0.2368)와 정확히 일치해야 합니다. 일치하지 않으면 mlp.W1 설정이 잘못된 것.
예제 2

출력층 편미분 3개 단계별 검증

대응 슬라이드 7~9
셀 5

출력층 backward를 손으로 한 줄씩 따라가기

backward() 메서드 한 번에 호출하지 않고, 슬라이드 흐름대로 한 줄씩 풀어쓰며 검증합니다.

# Step 1: ∂L/∂a⁽²⁾ (출발점)
dL_da2 = cache['a2'] - y
print(f"∂L/∂a⁽²⁾ = a⁽²⁾ - y = {dL_da2[0]:.4f}")

# Step 2: 출력층 3개 편미분
a1 = cache['a1']
dW2 = np.outer(dL_da2, a1)
db2 = dL_da2

print(f"  ∂L/∂W⁽²⁾₀ = {dW2[0, 0]:.4f}")
print(f"  ∂L/∂W⁽²⁾₁ = {dW2[0, 1]:.4f}")
print(f"  ∂L/∂b⁽²⁾  = {db2[0]:.4f}")
처음 등장 np.outer(a, b) 외적 (outer product)

두 벡터로 행렬을 만드는 연산. 모든 곱셈 조합을 표로 만든다고 생각하면 됩니다.

이 셀의 예: np.outer([0.6881], [0.5744, 0.6682])
= [[0.6881·0.5744, 0.6881·0.6682]] = [[0.3953, 0.4598]]

수식으로 $\delta^{(2)} \cdot (\mathbf{a}^{(1)})^\top$ 이 정확히 외적입니다.

수식 ↔ 코드 매핑:

수식코드
$\delta^{(2)} = a^{(2)} - y$ dL_da2 = cache['a2'] - y
$\partial L / \partial \mathbf{W}^{(2)} = \delta^{(2)} \cdot (\mathbf{a}^{(1)})^\top$ dW2 = np.outer(dL_da2, a1)
$\partial L / \partial b^{(2)} = \delta^{(2)}$ db2 = dL_da2
예상 출력 ∂L/∂a⁽²⁾ = a⁽²⁾ - y = 0.6881 ∂L/∂W⁽²⁾₀ = 0.3953 ∂L/∂W⁽²⁾₁ = 0.4598 ∂L/∂b⁽²⁾ = 0.6881
검증 포인트 세 값이 강의 슬라이드 9의 손계산(0.3953, 0.4598, 0.6881)과 일치하면 출력층 backward를 완벽히 이해한 것입니다.
예제 3

은닉층 편미분 6개 (chain rule 5단계)

대응 슬라이드 10~15
셀 8

에러를 은닉층으로 역전파하고, δ⁽¹⁾까지 계산

5단계 chain rule을 단계별로 코드로 풀어 보여줍니다.

# Step 3: 에러를 은닉층으로 역전파
# ∂L/∂a⁽¹⁾ = W⁽²⁾ᵀ · ∂L/∂a⁽²⁾
dL_da1 = mlp.W2.T @ dL_da2

# Step 4: 시그모이드 미분 통과해서 δ⁽¹⁾ 얻기
# δ⁽¹⁾ᵢ = ∂L/∂a⁽¹⁾ᵢ · a⁽¹⁾ᵢ · (1 - a⁽¹⁾ᵢ)
delta1 = dL_da1 * a1 * (1.0 - a1)
print(f"δ⁽¹⁾₀ = {delta1[0]:.4f}")
print(f"δ⁽¹⁾₁ = {delta1[1]:.4f}")

# Step 5: 은닉층 가중치와 바이어스 편미분
dW1 = np.outer(delta1, cache['x'])
db1 = delta1
print(f"dW1 =\n{dW1}")
print(f"db1 = {db1}")
처음 등장 .T 전치 (transpose)

변수 뒤에 .T를 붙이면 행과 열이 뒤바뀝니다.

이 셀에서 mlp.W2는 (1×2) 행렬 [[0.5, 0.6]]. .T를 붙이면 (2×1) 행렬 [[0.5], [0.6]]이 됩니다.

W2.T @ dL_da2는 "출력층 가중치 행렬을 뒤집어서 에러를 거꾸로 전파"하는 의미. 이게 backpropagation의 어원입니다.

처음 등장 * 원소별 곱 (Hadamard product, ⊙)

같은 위치끼리만 곱하는 연산. 두 벡터의 모양이 같아야 하고, 결과도 같은 모양.

이 셀의 예: dL_da1 * a1 * (1 - a1)은 세 벡터를 같은 위치끼리 곱합니다.

[0.3441, 0.4129] * [0.5744, 0.6682] * [0.4256, 0.3318]
= [0.3441·0.5744·0.4256, 0.4129·0.6682·0.3318] = [0.0841, 0.0915]

주의: @(행렬곱)과 *(원소별 곱)을 절대 헷갈리지 마세요. 결과 모양이 완전히 다릅니다.

수식 ↔ 코드 매핑:

수식코드
$\partial L / \partial \mathbf{a}^{(1)} = (\mathbf{W}^{(2)})^\top \cdot \delta^{(2)}$ dL_da1 = mlp.W2.T @ dL_da2
$\boldsymbol{\delta}^{(1)} = \partial L / \partial \mathbf{a}^{(1)} \odot \mathbf{a}^{(1)} \odot (1 - \mathbf{a}^{(1)})$ delta1 = dL_da1 * a1 * (1.0 - a1)
$\partial L / \partial \mathbf{W}^{(1)} = \boldsymbol{\delta}^{(1)} \cdot \mathbf{x}^\top$ dW1 = np.outer(delta1, cache['x'])
$\partial L / \partial \mathbf{b}^{(1)} = \boldsymbol{\delta}^{(1)}$ db1 = delta1
예상 출력 δ⁽¹⁾₀ = 0.0841 δ⁽¹⁾₁ = 0.0915 dW1 = [[0.0841 0.0841] [0.0915 0.0915]] db1 = [0.0841 0.0915]
검증 포인트 δ⁽¹⁾ 값(0.0841, 0.0915)이 슬라이드 15의 손계산과 일치합니다. 학생들이 두 번 헷갈릴 수 있는 지점: ① W2.T를 쓰는 이유, ② * 와 @ 의 차이.
예제 4

MLP.backward()로 한 번에 계산

대응 슬라이드 22~23
셀 10

예제 2~3에서 단계별로 한 것을 한 함수 호출로

단계별 계산이 backward() 안에 그대로 들어 있음을 확인합니다.

grads = mlp.backward(cache, y)

print("mlp.backward() 한 번 호출로 9개 편미분 모두 계산:")
print(f"  dW2 = {grads['dW2']}")
print(f"  db2 = {grads['db2']}")
print(f"  dW1 = \n{grads['dW1']}")
print(f"  db1 = {grads['db1']}")

# 위에서 단계별로 계산한 것과 일치 확인
assert np.allclose(grads['dW2'], dW2), "dW2 불일치"
assert np.allclose(grads['dW1'], dW1), "dW1 불일치"
print("\n✓ 단계별 계산과 backward() 결과가 완벽 일치")
처음 등장 np.allclose(a, b) 두 배열이 거의 같은가 확인

부동소수점 오차를 고려해 "두 배열이 사실상 같다"고 판단하면 True를 돌려줍니다. 정확히 같지는 않아도 차이가 매우 작으면 OK.

assert 뒤에 쓰이면 "이 조건이 거짓이면 에러 내고 멈추기"라는 뜻. 즉, 두 배열이 다르면 코드가 빨간 에러로 멈춥니다.

이 셀이 하는 일: 예제 2~3에서 학생이 직접 한 줄씩 계산한 결과와, backward() 메서드가 한 번에 계산한 결과가 같은지 확인합니다. 같으면 backward()가 강의에서 배운 수식 그대로 구현되어 있다는 증명.

예상 출력 mlp.backward() 한 번 호출로 9개 편미분 모두 계산: dW2 = [[0.3953 0.4598]] db2 = [0.6881] dW1 = [[0.0841 0.0841] [0.0915 0.0915]] db1 = [0.0841 0.0915] ✓ 단계별 계산과 backward() 결과가 완벽 일치
예제 5

Gradient Check — 수치 미분 vs 분석 미분

대응 슬라이드 25
셀 12

우리 backward 구현이 정말 수학적으로 정확한지 검증

독립적인 방법(수치 미분)으로 backward 결과가 맞는지 비교합니다. 두 방법이 일치하면 우리 구현이 수식적으로 정확하다는 증명.

# gradient_check는 각 파라미터마다:
#   1. 분석 미분 (우리의 backward로 계산)
#   2. 수치 미분 ((L(W+ε) - L(W-ε)) / 2ε)
# 를 비교해서 최대 상대 오차를 반환

max_rel_err = gradient_check(mlp, x, y)

print(f"최대 상대 오차: {max_rel_err:.2e}")

if max_rel_err < 1e-7:
    print("✓ 완벽! backward 구현이 정확합니다.")
elif max_rel_err < 1e-5:
    print("△ 작은 오차. 대체로 맞음 (수치 오차 범위).")
else:
    print("✗ 구현에 오류가 있습니다!")

두 방법이 어떻게 다른가?

방법설명
분석 미분 강의에서 배운 chain rule로 직접 유도한 수식 — 즉 우리의 backward()가 계산하는 값.
수치 미분 미분의 정의 그대로: (L(W+ε) - L(W-ε)) / 2ε. 즉 W를 살짝 흔들어 손실 변화량으로 미분을 추정.

이 둘은 서로 완전히 다른 방식인데, 결과가 거의 같다면 → 우리 구현이 옳다는 강력한 증거입니다.

예상 출력 최대 상대 오차: 6.2e-14 ✓ 완벽! backward 구현이 정확합니다.
왜 이게 중요한가 실제 연구에서 새로운 layer나 loss function을 구현했을 때, 가장 먼저 하는 일이 gradient check입니다. 1e-7 이하면 OK, 그 이상이면 어딘가 수식 실수가 있다는 신호.
예제 6

수치 미분 상세 비교

대응 슬라이드 26
셀 14

각 파라미터별로 분석/수치 미분을 표로 비교

예제 5는 "최대 오차 한 개"만 보여줬다면, 여기서는 9개 파라미터 각각의 값을 나란히 비교합니다.

def numerical_partial(mlp, param_name, index, x, y, eps=1e-5):
    """주어진 파라미터의 (index)번째 원소에 대해 수치 미분 계산."""
    param = getattr(mlp, param_name)
    original = param[index]
    
    param[index] = original + eps
    cache_plus = mlp.forward_with_cache(x)
    L_plus = 0.5 * float((y - cache_plus['a2'])**2)
    
    param[index] = original - eps
    cache_minus = mlp.forward_with_cache(x)
    L_minus = 0.5 * float((y - cache_minus['a2'])**2)
    
    param[index] = original  # 복원
    
    return (L_plus - L_minus) / (2 * eps)

# 각 파라미터에 대해 수치 미분과 분석 미분을 나란히 출력
# (생략 — 실제 셀에서는 모든 파라미터를 표로 출력)

수치 미분의 핵심 아이디어: W를 ε만큼 키워서 L 측정, ε만큼 줄여서 L 측정, 두 차이를 2ε로 나누면 그게 W에 대한 미분의 근사값. 강의에서 배운 chain rule 없이도 미분을 구할 수 있는 방법.

예상 출력 (요약 표 — 슬라이드 26 일치) 파라미터 분석 미분 수치 미분 차이 W²₀ 0.39529338 0.39529338 < 1e-9 W²₁ 0.45980267 0.45980267 < 1e-9 b² 0.68813392 0.68813392 < 1e-9 W¹₀₀ 0.08411003 0.08411003 < 1e-9 W¹₁₀ 0.09154089 0.09154089 < 1e-9
핵심 모든 차이가 1e-9 이하 → 우리 backward 구현이 수식적으로 정확하다는 증명. 학생들이 손계산한 값(0.3953, 0.4598 등)과도 일치.
예제 7

XOR 자동 학습

대응 슬라이드 27
셀 17

backprop으로 XOR를 자동 학습

9주차에서는 XOR 가중치를 손으로 설계했지만, 이제 backpropagation이 자동으로 학습합니다.

# XOR 데이터
X_xor = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
Y_xor = np.array([[0], [1], [1], [0]])

# 새 MLP 만들고 XOR 학습
np.random.seed(42)
mlp_xor = MLP(n_input=2, n_hidden=2, n_output=1)

history = mlp_xor.train(X_xor, Y_xor, epochs=10000, lr=0.5, verbose=True)

# 학습 후 예측
for x_test, y_true in zip(X_xor, Y_xor):
    cache = mlp_xor.forward_with_cache(x_test)
    pred = cache['a2'][0]
    print(f"{x_test} → 예측 {pred:.4f} (정답 {y_true[0]})")
처음 등장 np.random.seed(42) 재현성 고정

난수 생성기의 시작점을 고정합니다. 같은 seed를 쓰면 매번 똑같은 랜덤 가중치가 생성되어, 강의 결과가 학생 컴퓨터에서도 동일하게 재현됩니다.

42는 관례적으로 자주 쓰이는 숫자(특별한 의미는 없음).

이 셀이 하는 일:

코드 줄의미
X_xor, Y_xor = ... XOR 진리표 4개 샘플을 행렬로.
mlp_xor = MLP(...) 새 신경망 한 개 생성 (랜덤 가중치).
mlp_xor.train(...) forward → backward → 가중치 업데이트를 10,000번 반복.
cache = mlp_xor.forward_with_cache(x_test) 학습 끝난 신경망에 입력을 넣어 예측.
예상 출력 Epoch 0: loss = 0.31... Epoch 2000: loss = 0.05... Epoch 4000: loss = 0.02... ... Epoch 8000: loss = 0.005... [0 0] → 예측 0.04 (정답 0) [0 1] → 예측 0.93 (정답 1) [1 0] → 예측 0.93 (정답 1) [1 1] → 예측 0.06 (정답 0)

예측이 정답(0과 1)에 매우 가까움 → backprop이 XOR를 풀 가중치를 자동으로 찾아냈다는 증거.
