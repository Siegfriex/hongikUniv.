## 1. 머신러닝이란

**정의:** 머신러닝은 데이터 안에 숨어 있는 **패턴**을 찾아내는 것을 목적으로 한다. 수열·좌표 등 (x, y) 형태의 데이터가 주어졌을 때, 그 패턴을 이용해 “주어진 x에 대해 y는?”을 예측하는 식으로 학습한다.

**머신러닝의 종류:** 작업(T), 경험(E), 성능(P)에 따라 구분한다.
- **지도 학습:** E = (x, y) 쌍, T = y 예측(분류·회귀), P = 정답과의 오차(정확도, MSE 등).
- **비지도 학습:** E = x만, T = 군집·차원축소 등, P = 재구성 오차·군집 품질 등.
- **강화 학습:** E = 보상 신호, T = 행동 선택, P = 누적 보상.

> **참고:** Tom Mitchell, "A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E." — [Mitchell (1997), Machine Learning](https://www.cs.cmu.edu/~tom/mlbook.html)

## 2. 지도학습과 데이터·가설·오차

**정의:** 지도학습에서는 **정답으로 알려진 y**와 **현재 파라미터(m, b)로 얻은 예측 \(\hat{y}\)**를 비교한다. 그 차이가 **오차(잔차)**이고, 이 오차를 바탕으로 한 함수(손실)를 **최소화**하는 파라미터를 찾는 것이 목표다.

| 용어 | 의미 |
|------|------|
| 데이터 | 경험 E — 학습에 쓰는 (x, y) 쌍(지도학습) 또는 x만(비지도) |
| 가설 | 사용하는 **함수 클래스** (예: \(h_\theta(x)\), 선형·비선형 모델) |
| 오차 기반 함수 | **손실 함수** \(L\) — 예측 \(\hat{y} = h_\theta(x)\)와 실제 **y**의 차이를 재는 함수 (예: MSE) |
| θ 최소화 | **학습 = 최적화**: \(\theta^* = \arg\min_\theta L(\theta)\) |

정확한 해를 모르기 때문에 **반복적인 가정(업데이트)**을 통해, 오차가 줄어드는 방향으로 파라미터를 조정해 나간다.

## 3. 선형회귀 알고리즘 설계

**설정:** (x, y) 좌표 n개(예: 5개)가 주어졌을 때, 모델 \(\hat{y} = m x + b\)로 “다음 x에 대한 y”를 예측한다. 기존에 주어진 포인트들을 바탕으로 **현재의 m, b 값**으로 예측하고, 그 예측과 정답의 오차를 줄이기 위해 m, b를 반복해서 업데이트한다.

**알고리즘 단계:**
1. **파라미터 초기화:** m, b를 임의로 설정 (예: 0, 0).
2. **오차 계산:** 각 포인트에서 \(\hat{y}_i = m x_i + b\)를 구하고, 오차를 정의한 뒤 합산(예: MSE).
3. **업데이트:** 오차를 최소화하기 위한 규칙으로 m, b 갱신.
4. **반복:** 2~3을 오차가 충분히 줄어들 때까지 반복.

**정리:**
- **초기값:** m = 0, b = 0 (또는 작은 랜덤 값). 모델을 만드는 사람이 정하며, “0으로 만드는 것”이 목표가 아니라 **시작점**일 뿐이다. 목표는 **오차 최소화**이다.
- **오차 정의:** Mean Squared Error (MSE)
  \[
  L(m,b) = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2, \quad \hat{y}_i = m x_i + b.
  \]
- **업데이트 규칙 (경사하강법):**
  - \(m \leftarrow m + \alpha \cdot \frac{1}{n}\sum_i (y_i - \hat{y}_i) \cdot x_i\) (오차×x 합에 학습률 적용)
  - \(b \leftarrow b + \alpha \cdot \frac{1}{n}\sum_i (y_i - \hat{y}_i)\) (오차 합에 학습률 적용)
  여기서 \(\alpha\)는 학습률(learning rate)이다.

## 4. 목적함수와 경사하강법

**정의:** **목적함수(Objective function)**는 우리가 **최소화(또는 최대화)하려는 함수**이다. 지도학습·회귀 맥락에서는 **오차를 정량화한 손실 함수** \(L(m,b)\)가 목적함수이며, “목적”은 이 값을 **최소화**하는 것이다.

**경사하강법(Gradient Descent):**
- 목적함수 \(L\)를 **파라미터(m, b)에 대해 편미분**하면, 각 파라미터가 증가할 때 \(L\)이 얼마나 변하는지(기울기)를 알 수 있다.
- **그래디언트**는 함수값이 **가장 빨리 커지는** 방향을 가리킨다. 우리는 \(L\)을 **줄이고** 싶으므로 **그 반대 방향**으로 m, b를 조금씩 이동한다.
- 업데이트: \(m \leftarrow m - \alpha \frac{\partial L}{\partial m}\), \(b \leftarrow b - \alpha \frac{\partial L}{\partial b}\).

**정리:**
- **업데이트 규칙 = 경사하강법:** 목적함수를 파라미터에 대해 편미분한 뒤, 그 **반대 방향**으로 파라미터를 갱신한다.
- **백프로파게이션(Backpropagation):** 경사하강법을 하려면 각 파라미터에 대한 편미분이 필요하다. 레이어가 여러 개인 **신경망**에서는 **연쇄법칙(chain rule)**으로 이 그래디언트를 **역방향**으로 전파해 구하는 알고리즘을 백프로파게이션이라 부른다. 선형회귀 \(\hat{y}=mx+b\)에서는 편미분이 단순하므로 “경사하강법”만으로 충분하다.

## 5. 학습 과정과 최선의 의미

**학습 과정 (직선의 변화):**
- **처음:** m=0, b=0에 가까우면 예측 직선은 **거의 수평선**(y절편만 있는 형태)에 가깝다.
- **반복:** 오차를 이용해 m, b를 업데이트하면 직선이 점점 기울어지고, y절편도 조정된다.
- **수렴:** 오차 변동이 거의 없어지면 **수렴**한 것이며, 그때의 m, b가 최종 기울기와 y절편이 된다.

**한 직선이 5개 점을 하나도 지나가지 않아도 되는가?**
맞다. 선형회귀에서 구하는 것은 **한 개의 직선**이며, 이 직선이 5개 데이터 점을 **하나도 정확히 지나가지 않는 경우가 일반적**이다. 목표는 “모든 점을 지나가는 직선”이 아니라 **전체 오차(예: MSE)를 최소화하는 직선**을 찾는 것이다. 점이 5개이고 미지수는 m, b 두 개뿐이므로, 5개 점이 정확히 한 직선 위에 있지 않으면 한 직선이 5개를 모두 지나가는 것은 불가능하다. 따라서 **한 직선으로 5개를 다 맞추는 것이 목표가 아니라, 손실을 최소화하는 절충선**을 찾는 것이 맞다.

**경사하강법을 이용한 학습에서 “최선”의 의미:**
우리가 정한 **손실(목적함수)**을 **최소화하는 파라미터**를 찾은 것이 “최선”이다. 그 결과로 나온 한 개의 직선이 5개 점을 하나도 지나가지 않더라도, **선택한 모델(한 직선)과 손실(MSE) 기준으로는 그게 할 수 있는 최선**이다.

## 6. 데이터사이언스 개요

**데이터사이언스 vs 데이터 드리븐**
- **데이터 드리븐:** "데이터를 보고 결정한다"는 **사고방식·원칙**. 데이터를 중요시하는 모든 활동에 두루 쓰는 말.
- **데이터사이언스:** 데이터의 **수집·정제·탐색·모델링·해석**까지 이어지는 **과정·방법·분야**. 통계, ML, 도메인, 시각화, 프로그래밍이 결합된 실무 파이프라인.

**파이프라인 요약:** (1) 데이터 탐색 — 필터링, 조직화, 정규화. 로 데이터에서 분포·특성 파악. (2) 모델링 — 다변수·알고리즘 적용. (3) 옵티마이징 — 데이터·**컨텍스트(문맥)**를 고려해 최적화. **문맥을 찾아내는 것**이 데이터사이언스의 목적이자 목표.

**전처리·정규화:** 로 데이터 → **어떤 분포·특성인지 먼저 파악** → 수집 이후 이해 → 정제된 데이터로 분석. 전처리·정규화는 "로 데이터를 이해하고 그에 맞게 정제하는 단계". 분석은 정제된 데이터에 **통계적 방법** 또는 **데이터사이언스적 방법(모델링·ML)**을 적용하는 단계이며, **문맥(컨텍스트)**을 찾아내는 것이 목표.

## 7. 데이터사이언스 니즈·예시

**데사 니즈:** (1) **어떤 결정? A 또는 B** — 의사결정 지원. (2) **예측 가능 분석** — 미래 값·사건 추정. (3) **발견 패턴** — 데이터 안의 구조·규칙·연관 탐색.

**예시: AlphaFold (단백질 구조 예측)**
Highly accurate protein structure prediction. 기존 통계·실험만으로는 미식별 구조를 체계적으로 다루기 어려웠음. **데이터(서열·구조 DB) + ML**로 미식별 구조를 대량·저비용 예측 가능하게 함. AlphaFold 3는 단백질·DNA·RNA·리간드 상호작용까지 all-atom 예측. 2026년 초 기준 190개국 이상·300만 명 이상 사용, Hit-to-Lead 단계 수 년→수 개월로 압축. **게임 체인저**인 이유: 기존 방법으로 인식·활용 못 하던 정보(잠재 구조, 상호작용)를 패턴 학습·예측으로 포괄하고 전 세계에 개방.

**기존 통계 vs 데이터사이언스:** 기존 통계 이론으로도 분석은 가능했으나, 데이터사이언스는 **미식별 요인·기회 요인**을 포괄적으로 다루어 "데이터로 할 수 있는 일"을 확장·완성한다. 통계 = 가설·모형이 정해진 상태에서 추정·검정. 데사 = 잠재 요인, 고차원·비선형, 대규모 데이터, ML/딥러닝으로 새 인사이트·가능성 포착.

**나우캐스팅 예시:** 강수·기상 나우캐스팅에서 **3차원** = 2D 공간+시간, 또는 대기 3D 볼륨. 기존 방법(40%대) → 딥러닝(MetNet, DGMR, FuXi-Nowcast 등)으로 **90%에 가까운 기술점수** 개선. "불특정·다양한 경우의 수"를 한 모델로 도출 가능해짐. **데이터사이언스(문제·데이터·평가) + ML/딥러닝(모델)**이 세트로 맞물려 이뤄진 결과.

## 8. 데이터사이언스 요구 스킬

| 스킬 | 역할 |
|------|------|
| **머신러닝** | 데이터에 맞는 **러닝 방법 선택** + 그 안에서 **알고리즘·하이퍼파라미터(바이어스) 구체화·조절**. |
| **수학적 모델링** | **함수로서의 모델** 설계. 수식으로 해결이 안 되면 **수치 백본**으로 모델/방법을 바꾸고, 정확도 한계 시 **수학적 개선**으로 구체적 향상. |
| **통계** | 전반적 추론·검정·불확실성·실험 설계. |
| **컴퓨터 프로그래밍** | 구현·실험·자동화. **프로그래밍 없어도 ML 가능?** 겉보기엔 노코드·AutoML 등으로 가능해 보이지만, 실무에서 **기계가 학습·작업하도록 시키는 것**은 결국 우리가 정해 주는 것. **근본적으로 프로그래밍 능력이 필요.** |
| **데이터베이스** | **데이터를 어떻게 수집·저장**할지, **더 효율적으로 잡아내는지**(인덱싱, 파이프라인, 캐싱 등). |

**진입 vs 깊이:** ML/데사는 도구·튜토리얼 덕분에 **진입은 상대적으로 쉽게** 느껴질 수 있으나, **하면 할수록** 모델 선택·수학·최적화·데이터 품질·해석·도메인이 쌓여 **더 딥해짐**.

## 9. 데이터사이언스 5단계 상세·예방정비 예시

**5단계:** (1) **컨셉 스터디** — 문제 정의, 비즈니스/과학 모델. **가장 필요 = 데이터.** "어떤 데이터가 필요한가?" 정의. 도메인 이해·스터디. (2) **데이터 프리퍼레이션** — 데이터 이해 기반 정제. 수집·구조화, **클리닝**, **리덕션**(다변수·사이즈 축소·동일 변수 조절), **트랜스폼**(정규화, ETL, aggregation). **변환 선택이 인사이트를 바꿈:** 예) FFT에서 T(시간) vs F(주파수) vs 시간·주파수 병렬 시 각각 다른 인사이트. **인테그레이션** — 줄이기·제거 또는 통합. (3) **모델 플래닝** — EDA. 변수·데이터 간 관계 이해. (4) **모델 빌딩** — 다변수 분석 도구·툴링으로 의미 있는 인사이트 도출. (5) **최종** — 리포트, 코드, 기술문서. 1단계 초기 목표에 대한 최종 언급, 리디렉션, 디벨로핑.

**예방정비 예시 (베어링 고장 예측, 딥러닝)**
- **컨셉 스터디:** 3상 유도 전동기. 주 문제 = **베어링**(로터/샤프트와 스테이터 사이, 마모 방지, 소모 수명). 목표 = 베어링 고장 시점 예측.
- **데이터:** 모터 구매·센서 부착(전압, 온도, 진동 등). 지도학습·분류: 정상 vs 고장, 고장 유형. **모집단 문제:** 정상 데이터는 많고 고장 데이터는 희귀 → **인위적 고장 생성**(내부 균열, 외부 구멍). 정상 / 고장(내) / 고장(외) 타입 확보.
- **모델 플래닝:** 진동 데이터를 **주파수 축**으로 변환. 정상 vs 고장에서 3kHz·4kHz 대역 등에서 차이. T만이 아니라 **트랜스폼**으로 차이가 극대화되는 표현 탐색. 밴드패스 필터, 2차원 표현(NSP 등): 컨테인먼트, 아우터/이너레이스 H·M·L. **질문:** ML이 사람이 인식하기 어려운 미세·희귀 케이스를 식별할 수 있는가? → **CNN** 시도.
- **결과·괴리:** 각 타입 1만 건 학습 시 성능은 좋음. **현실:** 정상 vs 고장 비율이 현장에서는 균형이 아님. 고장 데이터는 **절대적으로 적음**. → 현재 모델링(균형 데이터)과 **현실(고장 희귀)** 괴리. 고장 데이터 양과 결과가 현실과 **반비례**.
- **불균형 극복:** **생성 모델**(가짜 고장 데이터)·프로시저·행동 연구 등 시도 → 일부 개선. 최종 **가설검정** 논문까지로 5단계 마무리.

## 10. 지도학습: 정의에서 실제 러닝까지 (예제 중심)

**정의(톰 미첼):** 작업 T, 성능 P, 경험 E. E가 쌓일수록 P가 좋아지면 "학습"한다. 지도학습에서는 T = y 예측, E = (x, y) 데이터, P = 오차(예: MSE) 최소화.

**예제: 선형 회귀 \(\hat{y} = m x + b\)**

1. **문제 정의:** (x, y) 좌표 n개가 주어졌을 때, "다음 x에 대한 y"를 예측. 가설 = 한 직선(파라미터 m, b).
2. **목적:** 정답 y와 예측 \(\hat{y} = m x + b\)의 **오차**를 최소화. 목적함수 = MSE: \(L(m,b) = \frac{1}{n}\sum_i (y_i - \hat{y}_i)^2\).
3. **실제 러닝 절차:**
   - **초기화:** m=0, b=0 (또는 작은 랜덤 값).
   - **반복:** (a) 현재 m, b로 모든 \((x_i, y_i)\)에 대해 \(\hat{y}_i = m x_i + b\) 계산. (b) 오차 \(e_i = y_i - \hat{y}_i\)와 손실 \(L\) 계산. (c) **경사하강:** \(L\)을 m, b에 대해 편미분한 뒤, 그 **반대 방향**으로 m, b를 학습률 \(\alpha\)만큼 갱신.
     - \(m \leftarrow m - \alpha \frac{\partial L}{\partial m}\) → 실전에서는 \(m \leftarrow m + \alpha \cdot \frac{1}{n}\sum_i e_i \cdot x_i\).
     - \(b \leftarrow b - \alpha \frac{\partial L}{\partial b}\) → \(b \leftarrow b + \alpha \cdot \frac{1}{n}\sum_i e_i\).
   - **수렴:** 오차 변동이 거의 없어지면 중단. 그때의 m, b가 학습된 모델.
4. **결과 해석:** 한 직선은 5개 점을 하나도 지나가지 않아도 됨. **최선** = 선택한 모델(직선)과 손실(MSE) 기준으로 **손실을 최소화한 파라미터**를 찾은 것.

정의(학습 = E로 P 개선)가 **실제로는** "목적함수 L 정의 → 초기 파라미터 → 반복적으로 그래디언트 반대 방향으로 파라미터 업데이트 → 수렴"이라는 **경사하강법**으로 구체화된다.

## 11. 전 과정 복습 및 향후 플랜

**복습 요약**
- **ML 1강:** 머신러닝 = 데이터 속 패턴 찾기. 톰 미첼 정의(T, E, P). 지도학습 = (x,y)로 y 예측, 오차 최소화. 선형회귀 \(\hat{y}=mx+b\), MSE, 경사하강법으로 m, b 업데이트. 목적함수·편미분·반대 방향. 한 직선이 점을 안 지나가도 됨 → 손실 최소화가 최선.
- **데이터사이언스:** 데이터 드리븐(원칙) vs 데사(과정·방법). 5단계: 컨셉 스터디 → 데이터 프리퍼레이션(수집·클리닝·리덕션·트랜스폼·인테그레이션) → 모델 플래닝(EDA) → 모델 빌딩 → 최종 리포트·리디렉션·디벨로핑. 문맥 발견이 목표.
- **니즈·예시:** 결정 A/B, 예측, 패턴 발견. AlphaFold(단백질 구조), 나우캐스팅(3D·딥러닝으로 40%→90%급 개선). 기존 통계로 못 하던 미식별·기회 요인을 데사+ML로 포괄.
- **요구 스킬:** ML(방법 선택·알고리즘·하이퍼파라미터), 수학적 모델링(함수·수치·개선), 통계, 프로그래밍(근본 필요), DB(수집·저장·효율). 진입은 쉬워 보여도 하면 할수록 딥.
- **예방정비:** 컨셉(베어링) → 데이터(센서·인위적 고장) → 플래닝(진동→주파수, 밴드패스·2D) → CNN → 현실 괴리(고장 희귀·불균형) → 생성 모델 등으로 보완 → 가설검정·논문.

**향후 플랜**
- **다음 강의:** 비지도 학습·분류(로지스틱 회귀 등)·다변수 선형회귀·정규화·교차검증 등으로 확장.
- **실습:** 선형회귀 경사하강법 코드 구현, 실데이터로 MSE·수렴 확인.
- **데사 연계:** ML 과목에서 배운 "러닝 방법·알고리즘·조절"을 데사 5단계(컨셉→프리퍼레이션→플래닝→빌딩→리포트) 안에서 적용하는 연습. 데이터 불균형·생성 모델·가설검정은 추후 심화.
