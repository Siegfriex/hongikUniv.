## 심층 브리핑

11강은 작은 MLP에서 `forward → loss → backward → update`를 손으로 완전히 전개했다. 오늘 12강은 같은 원리를 반복 가능한 단위로 접는 단계다. 지난주 코드는 특정 구조에 가까운 수식·shape를 직접 박아 넣었기 때문에, 층 수를 늘리거나 activation을 바꾸거나 분류 문제로 옮기는 순간 코드가 급격히 불편해진다. 오늘의 해결책은 **Layer 추상화**다.

핵심은 개별 가중치 미분을 외우는 것이 아니라, 각 층이 자기 local gradient만 책임지는 구조를 이해하는 것이다. `Network`는 층들을 순서대로 forward하고 역순으로 backward한다. 각 `Layer`는 위층에서 온 \(\partial L / \partial(\text{이 층 출력})\)을 받아, 자기 local 미분을 곱해 \(\partial L / \partial(\text{이 층 입력})\)을 아래층으로 넘긴다. 이 분업이 9개 파라미터짜리 Week 11 예제를 10만 개 파라미터의 MNIST 네트워크까지 그대로 확장시킨다.

이번 강의의 가장 큰 주안점은 “미리 정해 둔 네트워크를 계산하는 코드”에서 “**공통 메서드를 가진 층 객체들을 조립하는 코드**”로 관점이 바뀐다는 점이다. `Layer`는 실제 계산을 직접 하지 않는 약속이고, `Dense`, `ReLU`, `Sigmoid` 같은 구체 층이 `forward`, `backward`, `update`를 자기 방식으로 **오버라이드**한다. 그래서 `Network`는 현재 층이 Dense인지 ReLU인지 몰라도 `layer.forward(x)`라고만 호출하면 된다. 같은 메서드 이름을 호출하지만, 실제 실행되는 내용은 객체의 종류에 따라 달라진다.

## 1. 직전 복습: 2-2-1 Backprop의 일반 패턴

11강의 핵심 패턴은 아래 두 줄로 압축된다.

\[
\delta^{(l)} = (W^{(l+1)})^\top \delta^{(l+1)} \odot \sigma'(z^{(l)})
\]

\[
\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^\top,\quad
\frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}
\]

오늘은 이 식을 매번 손으로 펼치지 않고, 각 층의 `backward` 메서드가 담당하도록 추상화한다.

## 2. Layer Abstraction: `Layer`·`Dense`·activation

### 2.1 공통 인터페이스

| 구성 | 역할 |
|------|------|
| `Layer` | 모든 층의 공통 인터페이스: `forward`, `backward`, `update` |
| `Dense` | \(Z = XW^\top + b\), 파라미터 `W`, `b`와 gradient `dW`, `db` 보유 |
| `Sigmoid`, `ReLU` | element-wise activation. 파라미터는 없고 gradient만 아래로 전달 |
| `Softmax` | 추론용 확률 변환. 학습에서는 보통 `SoftmaxCE`와 결합 |
| `forward(x)` | 입력을 받아 출력과 cache 저장 |
| `cache` | backward에 필요한 \(x, z, a, W\) 등 중간값 |
| `backward(dout)` | 위층에서 온 gradient를 받아 `dW`, `db`, `dx` 계산 |
| `update(lr)` | 저장된 gradient로 파라미터 갱신 |

> **핵심:** Layer abstraction은 수학을 바꾸는 것이 아니라, 11강에서 손으로 쓴 chain rule 패턴을 코드 구조로 고정하는 것이다.

```python
class Layer:
    def forward(self, x):
        raise NotImplementedError

    def backward(self, grad_output):
        raise NotImplementedError

    def update(self, lr):
        pass
```

`Layer` 자체는 “계산 가능한 층”이라기보다 **계약서**다. 모든 구체 층은 적어도 아래 세 질문에 답해야 한다.

| 질문 | 메서드 | 의미 |
|------|--------|------|
| 이 층은 입력을 어떻게 출력으로 바꾸는가? | `forward(x)` | 순전파 계산 |
| 손실의 gradient가 위에서 내려오면, 아래층에는 무엇을 넘기는가? | `backward(grad_output)` | 역전파 계산 |
| 이 층이 가진 파라미터는 어떻게 갱신되는가? | `update(lr)` | 학습률 기반 업데이트 |

여기서 `Dense`, `ReLU`, `Sigmoid`는 모두 같은 메서드 이름을 갖지만, 내부 동작은 다르다. 이것이 오버라이드의 핵심이다.

| 클래스 | `forward`에서 하는 일 | `backward`에서 하는 일 | `update`에서 하는 일 |
|--------|------------------------|--------------------------|------------------------|
| `Dense` | 선형변환 \(XW^\top+b\) | `dW`, `db`, `dX` 계산 | `W`, `b` 갱신 |
| `ReLU` | 음수는 0, 양수는 통과 | 양수였던 위치만 gradient 통과 | 파라미터 없으므로 no-op |
| `Sigmoid` | 값을 0~1 사이로 압축 | \(\sigma(1-\sigma)\)만큼 gradient 조절 | 파라미터 없으므로 no-op |
| `Softmax` | logit을 확률분포로 변환 | 단독 사용보다 `SoftmaxCE` 결합 사용 | 파라미터 없으므로 no-op |

이 덕분에 `Network.forward`는 아래처럼 단순해진다.

```python
for layer in self.layers:
    x = layer.forward(x)
```

이 반복문은 “모든 층을 같은 방식으로 호출한다”는 뜻이다. 하지만 실제로는 첫 번째가 `Dense`면 선형변환이 실행되고, 다음이 `ReLU`면 activation이 실행된다. `Network`는 각 층의 세부 수식을 몰라도 된다.

### 2.2 Local Gradient 사고법

각 층은 전체 chain rule을 알 필요가 없다. 자기 입력과 출력 사이의 local 미분만 알고 있으면 된다.

\[
\frac{\partial L}{\partial(\text{이 층 입력})}
=
\frac{\partial(\text{이 층 출력})}{\partial(\text{이 층 입력})}
\times
\frac{\partial L}{\partial(\text{이 층 출력})}
\]

| Layer | local 미분 | `backward`가 하는 일 |
|-------|------------|----------------------|
| `Dense` | \(W\) | `grad_output @ W` |
| `ReLU` | \(x>0\)이면 1, 아니면 0 | `grad_output * mask` |
| `Sigmoid` | \(\sigma(x)(1-\sigma(x))\) | `grad_output * out * (1-out)` |

`backward`의 입력인 `grad_output`은 “다음 층 또는 loss가 이 층의 출력에 대해 계산한 gradient”다. 즉,

\[
\texttt{grad\_output}
=
\frac{\partial L}{\partial(\text{이 층 출력})}
\]

`backward`의 반환값은 아래층으로 넘길 gradient다.

\[
\texttt{return}
=
\frac{\partial L}{\partial(\text{이 층 입력})}
\]

따라서 각 층의 `backward`는 **위에서 받은 gradient에 자기 local 미분을 곱해 아래로 넘기는 함수**다. 이것이 chain rule의 분업이다.

### 2.3 Dense Layer

`neural_network.py`의 `Dense`는 배치 convention을 `(B, n_in)`으로 둔다.

\[
Z = XW^\top + b
\]

| 텐서 | shape |
|------|-------|
| \(X\) | `(B, n_in)` |
| \(W\) | `(n_out, n_in)` |
| \(b\) | `(n_out,)` |
| \(Z\) | `(B, n_out)` |

Forward에서 입력 `x`를 `self.x`에 저장하는 이유는 backward에서 \(\partial Z / \partial W\) 계산에 필요하기 때문이다.

```python
def forward(self, x):
    self.x = x
    return x @ self.W.T + self.b

def backward(self, grad_output):
    self.dW = grad_output.T @ self.x
    self.db = grad_output.sum(axis=0)
    return grad_output @ self.W
```

여기서 `grad_output`은 \(\partial L / \partial Z\)이고 shape은 `(B, n_out)`이다. 반환값은 이전 층으로 넘길 \(\partial L / \partial X\), 즉 `(B, n_in)`이다.

Dense의 forward는 “특징을 다른 좌표계로 선형 변환하는 단계”다. 입력 \(X\)가 `(B, n_in)`이고 \(W\)를 `(n_out, n_in)`으로 둔 이유는 출력 뉴런마다 자기 weight row를 하나씩 갖게 하려는 convention이다.

\[
z_{b,k} = \sum_{j=1}^{n_{in}} x_{b,j} W_{k,j} + b_k
\]

여기서 \(b\)는 batch마다 반복되어 더해진다. NumPy에서는 `self.b`의 shape이 `(n_out,)`이어도 `(B, n_out)` 출력에 자동 broadcast된다.

Backward의 세 결과는 서로 목적이 다르다.

| 값 | 수식 | shape | 목적 |
|----|------|-------|------|
| `dW` | \(\frac{\partial L}{\partial W}=dZ^\top X\) | `(n_out, n_in)` | 이 Dense 층의 weight 업데이트 |
| `db` | \(\frac{\partial L}{\partial b}=\sum_b dZ_b\) | `(n_out,)` | 이 Dense 층의 bias 업데이트 |
| 반환값 `dX` | \(\frac{\partial L}{\partial X}=dZ W\) | `(B, n_in)` | 앞쪽 layer로 gradient 전달 |

`update(lr)`는 `dW`, `db`를 사용해 파라미터를 실제로 움직인다.

\[
W \leftarrow W - \eta dW,\quad b \leftarrow b - \eta db
\]

여기서 빼는 이유는 gradient가 손실이 증가하는 방향을 가리키기 때문이다. 우리는 손실을 줄여야 하므로 그 반대 방향으로 이동한다.

### 2.4 Activation Layer

Activation layer는 파라미터가 없으므로 `update`가 할 일이 없다. 대신 forward 때 저장한 값으로 gradient 통과 여부나 크기를 조절한다.

| Activation | forward | backward |
|------------|---------|----------|
| `ReLU` | \(\max(0,x)\) | `grad_output * (x > 0)` |
| `Sigmoid` | \(\sigma(x)\) | `grad_output * out * (1-out)` |

ReLU는 양수 영역에서 gradient를 그대로 통과시키고, Sigmoid는 최대 0.25만 통과시킨다. 이 차이가 뒤의 vanishing gradient 실험으로 이어진다.

Activation은 Dense와 달리 학습되는 파라미터가 없다. 역할은 선형변환만 반복하면 결국 하나의 큰 선형변환과 같아지는 문제를 막고, 네트워크에 비선형성을 넣는 것이다.

ReLU:

\[
\operatorname{ReLU}(x)=\max(0,x)
\]

\[
\frac{d}{dx}\operatorname{ReLU}(x)=
\begin{cases}
1, & x>0\\
0, & x\le 0
\end{cases}
\]

Sigmoid:

\[
\sigma(x)=\frac{1}{1+e^{-x}}
\]

\[
\sigma'(x)=\sigma(x)(1-\sigma(x))
\]

`Sigmoid.forward`가 `self.out`을 저장하는 이유는 backward에서 \(\sigma'(x)\)를 계산할 때 다시 \(\sigma(x)\)를 계산하지 않고, 이미 구한 출력값을 재사용하기 위해서다.

```python
def backward(self, grad_output):
    return grad_output * self.out * (1.0 - self.out)
```

이 한 줄은 아래 수식을 그대로 코드화한 것이다.

\[
\frac{\partial L}{\partial x}
=
\frac{\partial L}{\partial \sigma(x)}
\cdot
\sigma(x)(1-\sigma(x))
\]

### 2.5 클래스별 메서드 입출력 정리

이번 강의에서 가장 중요한 것은 “같은 메서드 이름, 다른 내부 구현”이다. 아래 표가 그 차이를 고정한다.

| 클래스 | 메서드 | 입력 | 출력/저장 | 왜 필요한가 |
|--------|--------|------|-----------|-------------|
| `Dense` | `forward(x)` | `x: (B,n_in)` | `z: (B,n_out)`, `self.x` 저장 | 선형변환으로 feature를 새 표현으로 바꿈 |
| `Dense` | `backward(grad_output)` | `dZ: (B,n_out)` | `dW`, `db` 저장, `dX` 반환 | 자기 파라미터 gradient와 앞층 gradient를 동시에 계산 |
| `Dense` | `update(lr)` | learning rate | `W`, `b` 변경 | 학습된 방향으로 실제 파라미터 이동 |
| `ReLU` | `forward(x)` | pre-activation | `max(0,x)`, mask 저장 | 비선형성 추가, 양수 신호 통과 |
| `ReLU` | `backward(grad_output)` | 위층 gradient | mask가 1인 곳만 gradient 반환 | 음수였던 뉴런의 gradient 차단 |
| `ReLU` | `update(lr)` | learning rate | 변화 없음 | 학습 파라미터가 없음 |
| `Sigmoid` | `forward(x)` | pre-activation | \(\sigma(x)\), `self.out` 저장 | 값을 0~1 범위로 압축 |
| `Sigmoid` | `backward(grad_output)` | 위층 gradient | `grad_output * out * (1-out)` | sigmoid local 미분 적용 |
| `Sigmoid` | `update(lr)` | learning rate | 변화 없음 | 학습 파라미터가 없음 |
| `SoftmaxCE` | `forward(logits, y)` | logit, one-hot 정답 | loss scalar, `probs`, `y_true` 저장 | 분류 손실 계산 |
| `SoftmaxCE` | `backward()` | 없음 | \((p-y)/B\) 반환 | 분류 backprop 시작 gradient 생성 |

`SoftmaxCE`는 `Layer`라기보다 loss 함수다. 그래서 `Network.layers` 안에 들어가기보다, 마지막 `Dense`가 만든 logits를 받아 손실과 시작 gradient를 만든다.

## 3. Vectorized Backprop: batch dimension과 matrix shape

단일 샘플에서 \(\delta x^\top\) 로 계산하던 가중치 gradient는 배치에서는 행렬곱으로 모인다. 오늘 자료의 convention은 `X @ W.T + b`이므로 `dW`는 아래처럼 계산한다.

\[
dW = dZ^\top X
\]

배치 평균은 `MSELoss.backward()`나 `SoftmaxCE.backward()`에서 이미 `/B`로 처리하므로, `Dense.backward()`에서는 합산 형태를 그대로 사용한다.

| 단계 | Week 11 단일 샘플 | Week 12 mini-batch |
|------|-------------------|--------------------|
| 입력 shape | `(n_in,)` | `(B, n_in)` |
| Dense forward | `W @ x + b` | `X @ W.T + b` |
| Dense `dW` | `outer(grad, x)` | `grad.T @ X` |
| Dense `db` | `grad` | `grad.sum(axis=0)` |
| Loss | \(\frac{1}{2}(y-\hat{y})^2\) | \(\frac{1}{B}\sum (y-\hat{y})^2\) |

핵심은 batch dimension을 0번째 축으로 두는 것이다. 그러면 NumPy broadcasting과 행렬곱을 통해 코드 구조가 거의 변하지 않는다.

## 4. Network 조립과 mini-batch 학습

`Network`는 layer list를 순서대로 보관한다. forward는 앞에서 뒤로, backward는 뒤에서 앞으로 순회한다.

```text
Forward:  x -> Layer1 -> Layer2 -> ... -> LayerL -> loss
Backward: loss_grad -> LayerL -> ... -> Layer2 -> Layer1 -> dx
```

`fit` 함수는 데이터를 mini-batch로 나누어 `forward → loss → backward → update`를 반복한다.

| 코드 요소 | 수업에서 확인할 포인트 |
|-----------|------------------------|
| `Network.add(layer)` | Keras `Sequential`처럼 층을 순서대로 쌓는 구조 |
| `Network.forward` | 각 layer의 `forward`를 순차 실행 |
| `Network.backward` | `reversed(self.layers)`로 역전파 |
| `MSELoss.backward` | \((y_{pred}-y_{true})/N\) 로 배치 평균 gradient 생성 |
| `SoftmaxCE.backward` | \((softmax(logits)-y)/N\), 분류 학습용 안정적 결합 |
| `fit` | mini-batch 단위 학습 루프 |

```python
net = Network()
net.add(Dense(784, 128))
net.add(ReLU())
net.add(Dense(128, 10))

loss_fn = SoftmaxCE()

logits = net.forward(x_batch)
loss = loss_fn.forward(logits, y_batch)
grad = loss_fn.backward()
net.backward(grad)
net.update(lr=0.01)
```

Epoch는 전체 데이터 1회 통과를 뜻한다. 하나의 epoch는 여러 mini-batch로 나뉘며, 각 mini-batch마다 forward/backward/update가 한 번씩 실행된다.

### 4.1 왜 `add` 메서드를 쓰는가

`Network.add(layer)`는 층을 리스트에 추가하는 메서드다.

```python
def add(self, layer):
    self.layers.append(layer)
    return self
```

단순히 `self.layers.append(layer)`를 직접 호출해도 동작은 가능하다. 그런데 `add`를 두는 이유는 네트워크 조립 방식을 하나의 공식 인터페이스로 만들기 위해서다.

| 방식 | 의미 |
|------|------|
| `net.add(Dense(784,128))` | 네트워크에 새 층을 하나 쌓는다 |
| `net.add(ReLU())` | 앞 Dense 뒤에 activation을 붙인다 |
| `net.add(Dense(128,10))` | 마지막 logit 출력층을 붙인다 |

즉 `add`는 “층 리스트에 어떤 순서로 쌓을 것인가”를 코드로 표현한다. 이 순서가 곧 모델 구조다.

```python
net = Network()
net.add(Dense(784, 128))
net.add(ReLU())
net.add(Dense(128, 64))
net.add(ReLU())
net.add(Dense(64, 10))
```

위 코드는 수식으로 쓰면 다음 합성함수다.

\[
f(x)=
W_3\,\operatorname{ReLU}
\left(
W_2\,\operatorname{ReLU}(W_1x+b_1)+b_2
\right)+b_3
\]

정확히는 배치 convention 때문에 \(XW^\top+b\) 형태지만, 구조적으로는 Dense와 ReLU가 순서대로 합성된 함수다.

### 4.2 왜 `for`문을 사용하는가

층이 3개로 고정되어 있으면 아래처럼 쓸 수도 있다.

```python
x = dense1.forward(x)
x = relu1.forward(x)
x = dense2.forward(x)
```

하지만 이 방식은 층 수가 바뀔 때마다 코드를 다시 써야 한다. `for`문을 쓰면 층 수와 종류가 바뀌어도 `Network.forward` 코드는 그대로다.

```python
def forward(self, x):
    for layer in self.layers:
        x = layer.forward(x)
    return x
```

이 반복문은 다음을 보장한다.

| 장점 | 설명 |
|------|------|
| 임의 깊이 | 층이 2개든 20개든 같은 코드로 forward |
| 임의 종류 | `Dense`, `ReLU`, `Sigmoid`가 섞여도 같은 메서드 호출 |
| 조립 가능성 | 모델 구조는 `add` 순서로만 결정 |
| Keras 연결 | `Sequential` 방식과 동일한 사고방식 |

여기서 중요한 점은 `for`문이 수학적으로는 **합성함수의 순차 적용**이라는 것이다.

\[
x_0 = X,\quad x_1 = L_1(x_0),\quad x_2 = L_2(x_1),\quad \dots,\quad x_L = L_L(x_{L-1})
\]

### 4.3 왜 backward는 `reversed()`인가

Forward가 \(L_1 \to L_2 \to L_3\) 순서였다면, chain rule은 손실에서 가까운 \(L_3\)부터 거꾸로 적용된다.

\[
\frac{\partial L}{\partial x_0}
=
\frac{\partial x_1}{\partial x_0}
\frac{\partial x_2}{\partial x_1}
\frac{\partial x_3}{\partial x_2}
\frac{\partial L}{\partial x_3}
\]

계산 순서로 보면 오른쪽 끝에서 시작해야 한다.

```python
def backward(self, grad):
    for layer in reversed(self.layers):
        grad = layer.backward(grad)
```

여기서 `grad` 변수는 매 층을 통과할 때 의미가 바뀐다.

| 시점 | `grad`의 의미 |
|------|---------------|
| loss 직후 | \(\partial L/\partial(\text{마지막 층 출력})\) |
| 마지막 층 backward 후 | \(\partial L/\partial(\text{이전 층 출력})\) |
| 중간층 backward 후 | 더 앞쪽 층으로 넘길 gradient |
| 첫 층 backward 후 | \(\partial L/\partial X\), 입력에 대한 gradient |

이 구조 때문에 `Network`는 각 층의 미분 공식을 몰라도 된다. 각 층이 자기 `backward`만 올바르게 구현하면, 전체 backprop은 자동으로 조립된다.

### 5.1 Vanishing Gradient 실험

Sigmoid의 미분은 최대값이 0.25다. 깊은 네트워크에서 비슷한 크기의 값이 층마다 곱해지면 첫 층까지 도달하는 gradient가 급격히 작아진다.

\[
0.25^{10} \approx 9.5 \times 10^{-7}
\]

슬라이드의 실험은 동일한 10층 네트워크를 Sigmoid와 ReLU로 각각 구성하고, forward/backward 1회 뒤 첫 번째 `Dense` 층의 `dW` 평균 절댓값을 비교한다.

| 활성화 | 예상 첫 층 gradient scale | 해석 |
|--------|---------------------------|------|
| Sigmoid | 약 `1e-6` | 거의 0에 가까워 학습이 정체되기 쉬움 |
| ReLU | 약 `1e-3` | 양수 영역에서 gradient가 비교적 보존됨 |

ReLU가 현대 딥러닝의 기본 활성화로 쓰이는 이유가 여기서 나온다. 다만 음수 영역이 계속 0이면 뉴런이 죽는 Dying ReLU 문제가 생길 수 있고, Leaky ReLU, ELU, GELU 등이 그 보완책으로 등장한다.

### 5.2 Iris 분류

Iris의 의미는 “Week 11의 도구가 실제 데이터에서도 작동한다”는 빠른 확인이다.

## 6. 분류와 회귀: 출력층·손실·gradient 선택

| 구분 | 분류 | 회귀 |
|------|------|------|
| 예시 | MNIST 숫자 인식 | 집값 예측, Week 11 XOR 회귀식 출력 |
| 출력층 | Softmax 확률분포 | Linear output, activation 없음 |
| 손실 | Cross Entropy | MSE |
| target | one-hot vector | 실수값 |
| 시작 gradient | \(p-y\) | \(\hat{y}-y\) |

Softmax와 Cross Entropy를 결합하면 gradient가 매우 간단해진다.

\[
p_i = \frac{\exp(z_i)}{\sum_j \exp(z_j)}
\]

\[
L = -\sum_i y_i \log p_i
\]

\[
\frac{\partial L}{\partial z} = p-y
\]

`SoftmaxCE`는 수치 안정성을 위해 logit에서 행별 최댓값을 뺀 뒤 softmax를 계산한다. 이는 overflow를 막기 위한 표준적인 처리다.

### 6.1 Loss 함수가 하는 일

Loss 함수는 모델 출력이 정답과 얼마나 다른지 하나의 스칼라로 압축한다. Backprop은 스칼라 손실 \(L\)에서 시작해 모든 파라미터에 대한 gradient를 계산한다.

회귀에서 MSE는 다음처럼 쓴다.

\[
L
=
\frac{1}{2B}\sum_{b=1}^{B}\lVert \hat{y}_b-y_b\rVert^2
\]

미분하면 시작 gradient는 다음과 같다.

\[
\frac{\partial L}{\partial \hat{y}}
=
\frac{\hat{y}-y}{B}
\]

그래서 `MSELoss.backward()`는 `self.diff / self.N`을 반환한다.

```python
def backward(self):
    return self.diff / self.N
```

분류에서는 출력값을 단순한 실수로 보면 안 된다. 클래스별 점수인 logit을 확률분포로 바꾸고, 정답 클래스의 확률이 높아지도록 학습해야 한다. 이때 쓰는 조합이 Softmax + Cross Entropy다.

### 6.2 Softmax는 activation인가, loss인가

Softmax 자체는 activation에 가깝다. logit \(z\)를 클래스 확률 \(p\)로 바꾼다.

\[
p_i=\frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}}
\]

Softmax의 출력은 아래 조건을 만족한다.

\[
0\le p_i\le 1,\quad \sum_i p_i=1
\]

따라서 MNIST처럼 “10개 클래스 중 하나”를 고르는 문제에서는 출력층을 확률분포로 해석할 수 있다. 하지만 학습에는 확률만으로 부족하다. “정답 클래스의 확률이 얼마나 낮은가”를 벌점으로 만드는 손실이 필요하다. 그 손실이 Cross Entropy다.

\[
L=-\sum_{i=1}^{K}y_i\log p_i
\]

one-hot target이면 정답 클래스 \(c\)만 \(y_c=1\)이고 나머지는 0이므로,

\[
L=-\log p_c
\]

즉 정답 클래스 확률 \(p_c\)가 1에 가까우면 손실은 0에 가까워지고, \(p_c\)가 작으면 손실은 커진다.

### 6.3 왜 Softmax와 Cross Entropy를 같이 묶는가

Softmax와 Cross Entropy를 따로 미분하면 식이 복잡해 보인다. 그런데 두 개를 결합하면 logit에 대한 미분이 매우 단순해진다.

\[
\frac{\partial L}{\partial z_i}=p_i-y_i
\]

배치 평균까지 포함하면 코드에서는 다음이 된다.

```python
def backward(self):
    return (self.probs - self.y_true) / self.N
```

이 결합의 장점은 두 가지다.

| 이유 | 설명 |
|------|------|
| 미분이 단순함 | 시작 gradient가 \(p-y\) 하나로 끝난다 |
| 수치적으로 안정적 | `log_softmax` 형태로 계산하면 overflow/underflow를 줄인다 |

`neural_network.py`의 `SoftmaxCE.forward`는 그래서 `shifted = logits - max(logits)`를 먼저 계산한다. Softmax는 모든 logit에 같은 상수를 빼도 확률이 변하지 않는다.

\[
\frac{e^{z_i-c}}{\sum_j e^{z_j-c}}
=
\frac{e^{-c}e^{z_i}}{e^{-c}\sum_j e^{z_j}}
=
\frac{e^{z_i}}{\sum_j e^{z_j}}
\]

따라서 행별 최댓값을 빼면 확률은 그대로 두고, \(\exp(z)\)가 너무 커지는 문제만 줄일 수 있다.

### 6.4 마지막 Dense 뒤에 Softmax layer를 붙이지 않는 이유

MNIST 예시에서 네트워크는 보통 마지막에 `Dense(64,10)`까지만 둔다. 즉 출력은 확률이 아니라 logit이다.

```python
net.add(Dense(64, 10))
loss_fn = SoftmaxCE()
```

Softmax는 `SoftmaxCE` 안에서 처리한다. 이렇게 하는 이유는 학습 시 필요한 것이 “확률값 자체”보다 “logit에서 바로 계산한 안정적인 cross entropy와 gradient”이기 때문이다. 추론할 때 확률이 필요하면 `predict_proba` 또는 별도 `Softmax`를 쓰면 된다.

정리하면:

| 상황 | 권장 구조 |
|------|-----------|
| 학습 | `Dense(..., num_classes)` + `SoftmaxCE` |
| 추론 확률 확인 | logits에 softmax 적용 |
| 회귀 | 마지막 `Dense(..., output_dim)` + `MSELoss` |

## 7. Keras와의 일대일 대응

오늘 만든 구조는 Keras의 `Sequential` 설계와 같은 철학을 가진다.

| 우리 코드 | Keras 관점 |
|-----------|------------|
| `Network()` | `Sequential()` |
| `net.add(Dense(...))` | `model.add(Dense(...))` |
| `ReLU()` | `Activation("relu")` 또는 layer activation |
| `SoftmaxCE()` | `CategoricalCrossentropy(from_logits=True)`에 가까운 역할 |
| `fit(...)` | `model.fit(...)` |

Framework가 추가로 제공하는 것은 추상화 자체가 아니라, 그 위의 자동화다.

| Framework 기능 | 의미 |
|----------------|------|
| Autograd | `backward()`를 직접 작성하지 않고 계산 그래프에서 자동미분 |
| GPU/TPU | NumPy 연산을 CUDA/accelerator로 가속 |
| Optimizer | SGD 외 Adam, AdamW, RMSprop 등 |
| Regularization | BatchNorm, LayerNorm, Dropout 등 |
| 고급 layer | Convolution, RNN, Transformer 등 |
| 운영 기능 | checkpoint, 저장/로딩, 분산학습, 배포 |

## 9. 오늘의 핵심·헷갈림·다음 연결

### 핵심 3개

1. **Layer = 조립 가능한 블록.** `forward`, `backward`, `update`만 통일하면 Dense, ReLU, Sigmoid, Softmax 계열을 같은 방식으로 다룰 수 있다.
2. **Network = 층의 리스트.** forward는 순서대로, backward는 역순으로 돌리면 chain rule이 코드 구조가 된다.
3. **Mini-batch = 같은 수학의 행렬화.** 단일 샘플의 `outer(grad, x)`가 `grad.T @ X`로 확장된다.

### 헷갈리기 쉬운 포인트

1. `W @ x` convention과 `X @ W` convention을 섞지 않기.
2. activation backward와 affine/linear backward를 구분하기.
3. 배치 평균 `/B`가 loss gradient에서 처리되는지, layer에서 처리되는지 일관되게 정하기.
4. 분류에서는 Softmax+CE의 시작 gradient가 \(p-y\), 회귀에서는 MSE의 시작 gradient가 \(\hat{y}-y\)임을 구분하기.

### 다음 연결

- ReLU 이후에는 Dying ReLU, initialization, normalization, dropout, optimizer 개선으로 이어진다.
- Keras/PyTorch로 넘어가면 오늘 직접 작성한 `backward`가 autograd로 대체된다. 하지만 layer stack, forward pass, loss, optimizer라는 구조는 그대로 유지된다.

## 10. 노트북 인텔리전스 브리핑

`week12_examples.ipynb`는 슬라이드의 추상 개념을 실습 순서로 다시 배열한 보조 강의록이다. 핵심은 “구현체를 한 번에 보여주는 것”이 아니라, **Layer라는 공통 인터페이스가 실제 코드 실행에서 어떻게 살아나는지**를 단계별로 확인하게 만드는 데 있다.

| 노트북 파트 | 직접 대응되는 본문 개념 | 강의상 역할 |
|-------------|--------------------------|-------------|
| 예제 1: Dense 하나 | `Dense.forward`, `Dense.backward`, `dW/db/dX` | Layer 메서드 입출력의 최소 확인 |
| 예제 2: ReLU와 Sigmoid | activation local gradient | 파라미터 없는 층도 `forward/backward`가 필요함을 확인 |
| 예제 3: XOR | `Network.add`, 순방향 for loop, 역방향 loop | Week 11의 고정 MLP를 Layer 시스템으로 재현 |
| 예제 4: Vanishing | Sigmoid derivative 최대 0.25, ReLU gradient 통과 | activation 선택이 학습 가능성에 미치는 영향 확인 |
| 예제 5: Iris | `SoftmaxCE`, one-hot, classification accuracy | 작은 실제 분류 문제에서 구조 검증 |
| 예제 6: MNIST | mini-batch, deep network, parameter count | 9개 편미분에서 10만 개 파라미터로 확장 |

이 노트북을 읽는 기준은 셀별 출력값보다 **각 셀이 어떤 객체의 어떤 메서드를 호출하는지**다. 예를 들어 `dense.forward(X_batch)`는 Dense의 forward 오버라이드가 실행되는 장면이고, `net.forward(X_xor)`는 `Network`가 내부 layer list를 순회하며 각 layer의 forward를 차례로 호출하는 장면이다. `net.backward(grad)`는 그 반대 방향으로 `reversed(self.layers)`를 돌며 chain rule을 조립한다.

따라서 이 노트북은 본 강의의 핵심 명제를 직접 검증한다.

> 같은 이름의 메서드 `forward`, `backward`, `update`를 각 층이 자기 방식으로 구현하면, `Network`는 층의 종류를 몰라도 임의 구조의 신경망을 학습시킬 수 있다.

### 11.4 Cell 4 — Dense forward 직접 실행

**직접 인용**

```python
# 4 입력 → 3 출력 Dense layer
dense = Dense(n_in=4, n_out=3, seed=0)

print(f"W shape: {dense.W.shape}")
print(f"b shape: {dense.b.shape}")
print(f"\n초기 W:\n{dense.W}")

# Forward: 미니배치 5개 샘플
X_batch = np.random.randn(5, 4)  # (5, 4)
z = dense.forward(X_batch)        # (5, 3)
print(f"\n입력 shape: {X_batch.shape}")
print(f"출력 shape: {z.shape}")
```

**강의 연결:** `Dense(n_in=4, n_out=3)`은 \(W\in\mathbb{R}^{3\times4}\), \(b\in\mathbb{R}^3\)를 만든다. `X_batch`는 샘플 5개, feature 4개이므로 shape이 `(5,4)`다. forward는

\[
Z=XW^\top+b
\]

를 계산하므로 출력은 `(5,3)`이 된다. 이 셀의 핵심은 “Dense forward는 feature dimension을 `n_in`에서 `n_out`으로 바꾼다”는 점이다.

### 11.5 Cell 5 — Dense backward 직접 실행

**직접 인용**

```python
# Backward: 임의의 grad_output 줘서 dW, db 계산
grad_out = np.ones_like(z)  # (5, 3)
grad_in = dense.backward(grad_out)

print(f"grad_output shape: {grad_out.shape}")
print(f"grad_input shape:  {grad_in.shape}  (이전 층으로 전파)")
print(f"\ndW shape: {dense.dW.shape}  (자신의 W에 대한 gradient)")
print(f"db shape: {dense.db.shape}")
```

**강의 연결:** `grad_out`은 \(\partial L/\partial Z\) 역할을 하는 가짜 upstream gradient다. Dense backward는 세 가지를 만든다.

\[
dW=dZ^\top X,\quad db=\sum_b dZ_b,\quad dX=dZW
\]

`grad_in`은 다음 update에 쓰는 값이 아니라 앞쪽 layer로 넘기는 gradient다. 반대로 `dense.dW`, `dense.db`는 이 Dense가 자기 파라미터를 업데이트하기 위해 저장하는 값이다.

### 11.6 Cell 6 — Dense 관찰 요약

**직접 인용**

```markdown
**관찰**:
- forward는 `(5, 4)` → `(5, 3)`으로 변환
- backward는 `(5, 3)` → `(5, 4)` (반대 방향)
- dW는 W와 같은 shape `(3, 4)`

이것이 모든 Layer의 공통 패턴입니다.
```

**강의 연결:** 이 관찰이 오늘의 shape 검증 기준이다. forward는 입력을 출력으로 보낸다. backward는 출력 쪽 gradient를 입력 쪽 gradient로 되돌린다. 파라미터가 있는 layer는 자기 파라미터와 같은 shape의 gradient를 저장한다.

**직접 인용**

```markdown
---
## 예제 2: Activation Layer (ReLU와 Sigmoid)
```

**강의 연결:** Activation layer는 파라미터가 없지만 `Layer`다. 즉 `update`는 비어 있어도 `forward/backward`는 반드시 필요하다. 이유는 activation이 chain rule에서 local gradient를 결정하기 때문이다.

### 11.8 Cell 8 — ReLU와 Sigmoid forward/backward 비교

**직접 인용**

```python
# ReLU 테스트
relu = ReLU()
x = np.array([[-2, -1, 0, 1, 2]], dtype=float)  # (1, 5)
out = relu.forward(x)
print(f"ReLU forward:  {x.flatten()} → {out.flatten()}")

# Backward: 음수 입력은 gradient 차단
grad = np.ones_like(out)
back = relu.backward(grad)
print(f"ReLU backward: grad_in = {back.flatten()}  (음수 위치는 0)")

print()

# Sigmoid 테스트
sig = Sigmoid()
out_sig = sig.forward(x)
print(f"Sigmoid forward:  {out_sig.flatten().round(3)}")

back_sig = sig.backward(np.ones_like(out_sig))
print(f"Sigmoid backward: {back_sig.flatten().round(3)}  (최댓값 0.25)")
```

**강의 연결:** ReLU는 음수 입력을 0으로 만들고, backward에서도 음수였던 위치의 gradient를 0으로 막는다.

\[
\operatorname{ReLU}'(x)=
\begin{cases}
1,&x>0\\
0,&x\le0
\end{cases}
\]

Sigmoid는 출력이 0~1 사이이고, backward에서 \(\sigma(x)(1-\sigma(x))\)를 곱한다. 이 값은 최대 0.25라서 깊은 네트워크에서는 gradient가 계속 작아질 수 있다.

### 11.10 Cell 10 — XOR 네트워크 조립과 직접 학습 루프

**직접 인용**

```python
# XOR 데이터
X_xor = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
Y_xor = np.array([[0], [1], [1], [0]], dtype=float)

# 네트워크 조립 (Keras 스타일!)
net = Network()
net.add(Dense(2, 4, seed=42))
net.add(ReLU())
net.add(Dense(4, 1, seed=43))

loss_fn = MSELoss()

# 학습 루프 — 미니배치를 통째로 forward/backward
history = []
for epoch in range(2000):
    pred = net.forward(X_xor)
    loss = loss_fn.forward(pred, Y_xor)
    grad = loss_fn.backward()
    net.backward(grad)
    net.update(lr=0.1)
    history.append(loss)

# 결과 확인
print("학습 후 예측:")
pred = net.forward(X_xor)
for x, y, p in zip(X_xor, Y_xor, pred):
    print(f"  x={x}, 정답={y[0]}, 예측={p[0]:.4f}")

# Loss curve
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(history, color='#065A82', linewidth=1.5)
ax.set_xlabel('Epoch'); ax.set_ylabel('MSE Loss')
ax.set_title('XOR train (Layer abstract version)')
ax.set_yscale('log'); ax.grid(alpha=0.3)
plt.show()
```

**강의 연결:** `net.add`가 모델 구조를 만든다.

\[
2 \rightarrow 4 \rightarrow 1
\]

학습 루프는 오늘 전체 framework의 최소형이다.

1. `net.forward(X_xor)`: 모든 layer forward
2. `loss_fn.forward(pred, Y_xor)`: scalar loss 계산
3. `loss_fn.backward()`: 시작 gradient 생성
4. `net.backward(grad)`: 모든 layer backward
5. `net.update(lr=0.1)`: 파라미터 있는 layer만 update

여기서 `MSELoss`를 쓰는 이유는 XOR 출력이 하나의 실수값처럼 다뤄지는 회귀형 예제이기 때문이다.

**직접 인용**

```markdown
---
## 예제 4: Sigmoid vs ReLU — Vanishing Gradient 실험

10층 네트워크에서 첫 층의 gradient 크기가 어떻게 다른지 직접 측정합니다.
```

**강의 연결:** 이 예제는 activation이 단순한 출력 변환이 아니라 학습 가능성을 좌우하는 local gradient라는 점을 보여준다.

### 11.13 Cell 13 — 동일 깊이 네트워크에서 첫 층 gradient 비교

**직접 인용**

```python
def make_deep_net(activation_class, n_layers=10, hidden=20):
    """동일한 깊이의 네트워크를 두 가지 활성화로."""
    np.random.seed(0)  # 동일한 초기화
    net = Network()
    net.add(Dense(hidden, hidden))
    for _ in range(n_layers - 1):
        net.add(activation_class())
        net.add(Dense(hidden, hidden))
    return net

# 두 네트워크 만들기
net_sig  = make_deep_net(Sigmoid, n_layers=10)
net_relu = make_deep_net(ReLU,    n_layers=10)

# 동일한 입력 + 임의 gradient → 첫 층의 dW 절댓값 비교
x = np.random.randn(32, 20)
y_dummy = np.random.randn(32, 20)

for name, net in [('Sigmoid', net_sig), ('ReLU', net_relu)]:
    out = net.forward(x)
    grad = (out - y_dummy) / len(x)
    net.backward(grad)

    first_dense = net.layers[0]  # 첫 Dense layer
    grad_norm = np.abs(first_dense.dW).mean()
    print(f"{name:8s} 첫 층 gradient 평균 절댓값: {grad_norm:.2e}")
```

**강의 연결:** `activation_class`를 인자로 받는 구조가 중요하다. 같은 네트워크 생성 함수가 `Sigmoid`와 `ReLU`를 바꿔 끼울 수 있다. 이것이 class와 override 기반 설계의 장점이다.

Sigmoid가 10층에서 약해지는 이유는 local gradient가 반복해서 곱해지기 때문이다.

\[
\sigma'(x)\le0.25
\]

\[
(0.25)^{10}\approx9.5\times10^{-7}
\]

ReLU는 양수 영역에서 local gradient가 1이므로, 적어도 그 구간에서는 gradient가 훨씬 덜 줄어든다.

### 11.14 Cell 14 — 층별 gradient 시각화

**직접 인용**

```python
# 시각화: 층별 gradient 크기 (모든 층의 dW를 측정)
def measure_layer_grads(net):
    """각 Dense layer의 dW 평균 절댓값 리스트."""
    return [np.abs(L.dW).mean() for L in net.layers if isinstance(L, Dense)]

grads_sig = measure_layer_grads(net_sig)
grads_relu = measure_layer_grads(net_relu)

fig, ax = plt.subplots(figsize=(10, 5))
layer_idx = np.arange(1, len(grads_sig) + 1)
ax.semilogy(layer_idx, grads_sig, 'o-', color='#C0392B', linewidth=2.5,
            markersize=10, label='Sigmoid')
ax.semilogy(layer_idx, grads_relu, 's-', color='#27AE60', linewidth=2.5,
            markersize=10, label='ReLU')
ax.set_xlabel('Layer index (1=1st layer, 10=last layer)')
ax.set_ylabel('|dW|.mean() (log scale)')
ax.set_title('gradient of each layer')
ax.legend(fontsize=12); ax.grid(alpha=0.3, which='both')
plt.tight_layout(); plt.show()

ratio = grads_relu[0] / grads_sig[0]
print(f"\nReLU 첫 층 gradient는 Sigmoid보다 약 {ratio:.0f}배 큼")
```

**강의 연결:** `isinstance(L, Dense)`는 layer list 안에서 파라미터가 있는 층만 골라내는 코드다. ReLU와 Sigmoid는 `dW`가 없기 때문에 Dense만 측정한다. `semilogy`를 쓰는 이유는 gradient 크기가 지수적으로 차이 나기 때문이다.

**직접 인용**

```markdown
**관찰**:
- Sigmoid: 첫 층의 gradient가 거의 0 (vanishing!)
- ReLU: 모든 층에서 일정한 크기의 gradient 유지
```

### 11.18 Cell 18 — Iris 네트워크와 SoftmaxCE 학습

**직접 인용**

```python

net = Network()
net.add(Dense(4, 8))
net.add(ReLU())
net.add(Dense(8, 3))

loss_fn = SoftmaxCE()  # Softmax + CrossEntropy 결합

# 학습 — fit() 함수 사용
history = fit(net, X_train, Y_train, loss_fn,
              epochs=100,
              batch_size=16,
              lr=0.05,
              verbose=True)

# 정확도 평가
train_acc = (net.forward(X_train).argmax(axis=1) == Y_train.argmax(axis=1)).mean()
test_acc  = (net.forward(X_test).argmax(axis=1)  == Y_test.argmax(axis=1)).mean()

print(f"\n최종 결과:")
print(f"  Train accuracy: {train_acc:.1%}")
print(f"  Test accuracy:  {test_acc:.1%}")
```

**강의 연결:** 마지막 `Dense(8,3)`은 확률이 아니라 logit을 출력한다. Softmax는 `SoftmaxCE` 내부에서 처리한다. 이 구조가 중요한 이유는 학습 시 gradient를 안정적으로

\[
\frac{\partial L}{\partial z}=\frac{p-y}{B}
\]

로 만들 수 있기 때문이다.

### 11.24 Cell 24 — MNIST mini-batch 학습과 test accuracy 기록

**직접 인용**

```python
# Mini-batch 학습 — fit() 사용 + 매 epoch 마다 test accuracy 측정
import time

def fit_with_test_acc(net, X, Y, X_test, Y_test, loss_fn,
                       epochs=10, batch_size=64, lr=0.01):
    """교재의 fit()에 test accuracy 기록을 추가한 버전."""
    n = len(X)
    history = {'loss': [], 'test_acc': []}

    for epoch in range(epochs):
        idx = np.random.permutation(n)
        epoch_loss = 0
        n_batches = 0

        for start in range(0, n, batch_size):
            b = idx[start:start + batch_size]
            logits = net.forward(X[b])
            loss = loss_fn.forward(logits, Y[b])
            net.backward(loss_fn.backward())
            net.update(lr)
            epoch_loss += loss
            n_batches += 1

        avg_loss = epoch_loss / n_batches
        test_acc = (net.forward(X_test).argmax(axis=1) == Y_test.argmax(axis=1)).mean()
        history['loss'].append(avg_loss)
        history['test_acc'].append(test_acc)

        if (epoch + 1) % 2 == 0:
            print(f"Epoch {epoch+1:2d}: loss={avg_loss:.4f}, test_acc={test_acc:.1%}")

    return history

t0 = time.time()
history = fit_with_test_acc(net, X_train, Y_train, X_test, Y_test, loss_fn,
                             epochs=10, batch_size=64, lr=0.01)
print(f"\n총 학습 시간: {time.time() - t0:.1f}초")
print(f"최종 test 정확도: {history['test_acc'][-1]:.1%}")
```

**강의 연결:** 이 셀은 `fit`의 확장판이다. 구조는 동일하지만 epoch마다 test accuracy를 추가로 기록한다. 내부의 핵심 네 줄은 변하지 않는다.

```python
logits = net.forward(X[b])
loss = loss_fn.forward(logits, Y[b])
net.backward(loss_fn.backward())
net.update(lr)
```

이 네 줄이 오늘 수업의 실전 학습 루프다.

### 11.26 노트북 전체 흐름의 최종 연결

노트북 전체는 아래 한 문장으로 요약된다.

> `Layer`의 공통 메서드가 제대로 설계되면, Dense 하나의 shape 확인에서 시작해 XOR, Iris, MNIST까지 같은 학습 루프가 유지된다.

실습의 반복 패턴은 항상 같다.

\[
\text{Data} \rightarrow \text{Network.forward} \rightarrow \text{Loss.forward}
\rightarrow \text{Loss.backward} \rightarrow \text{Network.backward}
\rightarrow \text{Network.update}
\]

이 구조가 오늘 강의의 결론이다. Framework로 넘어가도 바뀌는 것은 구현 편의성이다. `backward`를 사람이 직접 쓰지 않고 autograd가 계산해 줄 뿐, layer stack, forward pass, loss, gradient, optimizer라는 개념적 골격은 그대로 유지된다.
